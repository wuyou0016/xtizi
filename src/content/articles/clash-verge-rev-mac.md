faqs:
  - q: 怎么知道我的 Mac 是 Apple 芯片还是 Intel？
    a: 点屏幕左上角的苹果菜单，选“关于本机”。看到“芯片”一栏写着 Apple 的 M 系列，就是 Apple 芯片；看到“处理器”一栏写着 Intel，就是 Intel 机型。也可以在终端输入 uname -m，输出 arm64 对应 Apple 芯片，输出 x86_64 对应 Intel。选安装包时以此为准。
  - q: 打开时提示已损坏或无法验证开发者，怎么办？
    a: 先回到官方发布页重新下载，排除下载不完整或文件来源不对的可能。确认来源是官方仓库后，到系统设置的隐私与安全性页面，在安全性区域找到被拦截的应用，选择仍要打开。较旧的 macOS 也可以右键点应用选择打开，具体以你系统上的实际提示为准。
  - q: 系统代理开了，终端里的命令为什么还是不走代理？
    a: 系统代理只管遵守系统设置的应用，浏览器大多遵守，但 curl、git、npm 这类命令行工具通常不读取它，而是读环境变量里的代理设置。要让它们走代理，要么在终端里单独设置代理环境变量，要么改用 TUN 模式接管更多流量，两种办法按需选一种。
  - q: 菜单栏里找不到 Clash Verge Rev 的图标？
    a: 先确认客户端确实在运行，可以在活动监视器里搜索它的名称。图标找不到的常见原因是菜单栏图标太多，被屏幕刘海或其他应用挤到了看不见的位置，可以退出几个不常用的菜单栏应用后再看。也可以直接从应用程序文件夹重新打开主窗口操作。
  - q: 想让它开机自动启动，该怎么设？
    a: 先看客户端设置页里有没有开机自启一类的开关，打开即可。也可以在系统设置的通用里找登录项，把客户端添加进去。两个入口选其一，不要同时开。开机自启后记得检查系统代理是否随之打开，网络环境变化时它可能需要你手动重新确认。

Clash Verge Rev Mac 版和 Windows 版的差别，不在软件本身，而在系统：要先分清芯片、要过一道“未知开发者”的放行、设置系统代理时还会碰到授权弹窗。这篇教程把这些 macOS 特有的环节讲透，再接上通用的订阅导入、选节点和验证。客户端版本与官方地址见页面顶部数据卡，正文不写版本号，界面文字以你当前版本为准。

## 开始前：先确认芯片型号和订阅格式

需要准备的东西不多，但第一项很容易选错：

| 准备项 | 怎么确认 | 为什么重要 |
| --- | --- | --- |
| 芯片类型 | 苹果菜单进入“关于本机”，看芯片还是处理器；或在终端执行 `uname -m` | 决定下载哪个安装包 |
| 机场订阅 | 后台订阅链接标明是 Clash 格式 | 格式不对导入后没有节点，判断方法见 [Clash 机场怎么选](/zhinan/clash-jichang/) |
| 其他代理软件 | 先退出，并关闭它设置的系统代理 | 避免互相覆盖网络设置 |
| 管理员账户 | 当前用户能输入登录密码 | 授权弹窗需要 |

终端里 `uname -m` 的结果：输出 arm64 是 Apple 芯片，输出 x86_64 是 Intel。

## Clash Verge Rev Mac 安装：选包、拖入应用程序、首次放行

下载只走官方发布页：[github.com/clash-verge-rev/clash-verge-rev/releases](https://github.com/clash-verge-rev/clash-verge-rev/releases)。客户端的介绍和同类对比见 [Clash Verge Rev 下载](/xiazai/clash-verge-rev/)，这里讲操作。

1. 打开发布页，确认条目标着 Latest，而不是 Pre-release。
2. 在 Assets 里找 macOS 的磁盘映像文件。文件名里区分 Apple 芯片和 Intel 的标记，一般是 arm64 或 aarch64 对应 Apple 芯片，x64 对应 Intel，以发布页的实际文件名为准。
3. 选错的后果：给 Intel 机型下了 Apple 芯片的包，会提示不兼容；给 Apple 芯片下了 Intel 包，可能靠转译运行，速度和耗电都不如原生包。拿不准就回到上一节重新确认。
4. 双击打开磁盘映像，把应用图标拖进“应用程序”文件夹，然后弹出磁盘映像。
5. 从“应用程序”里启动。第一次大概率会被拦住，处理方式见下面。

首次放行：

- 提示“无法验证开发者”或“无法检查是否包含恶意软件”时，到系统设置的“隐私与安全性”页面，滚到安全性区域，找到被拦截的应用，选择“仍要打开”，再输入登录密码确认。
- 较早的 macOS 可以在应用上右键选择“打开”再确认；较新的系统需要走设置页这条路，以你系统的实际提示为准。
- 提示“已损坏”时，先怀疑下载不完整或来源不对，回官方发布页重新下载，不要用来历不明的所谓“修复脚本”。

## 授权：系统代理和 TUN 为什么会弹窗要密码

第一次打开客户端后，你可能会遇到几类授权请求。看清它在要什么，比无脑输入密码更重要：

| 场景 | 它在做什么 | 怎么处理 |
| --- | --- | --- |
| 首次打开系统代理开关 | 修改 macOS 的网络代理设置 | 弹窗提到修改网络设置时，确认应用名称是 Clash Verge Rev 再授权 |
| 开启 TUN 或安装服务模式 | 创建虚拟网卡，需要更高权限的辅助服务 | 同上，授权后按客户端提示完成 |
| 系统弹出网络或本地网络相关权限请求 | 允许应用访问网络 | 选择允许 |

几条原则：

- 弹窗上写的应用名称对不上，就取消。
- 只开系统代理时，不必为了 TUN 提前授权，需要时再开。
- 授权后想撤销，可以在客户端里关闭对应开关，或到系统设置里删除相关项，具体入口随系统版本而变。

## Mac Clash 怎么用：导入订阅并选中配置

客户端不带节点，节点来自订阅。步骤如下：

1. 在主窗口左侧找到名为“订阅”或“配置”的页面（英文版常见叫法是 Profiles）。
2. 把机场后台复制的 Clash 订阅链接粘贴到输入框，格式示例如下，请换成你自己的：`https://example.com/你的订阅链接`
3. 点击导入。列表里会出现一张新的配置卡片。
4. 点一下这张卡片，让它处于选中状态。导入不等于启用，漏掉这一步，代理页会没有节点。
5. 回到“代理”页面，应当能看到策略组和节点。

通用的导入原理，见 [订阅链接怎么用](/jiaocheng/dingyue-daoru/)。订阅更新失败的排查见 [订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)。

## 选节点与模式：窗口里选，菜单栏里切

在“代理”页顶部有规则、全局、直连三种模式；日常保持规则模式，国内走直连，其余走代理，区别见 [规则、全局、直连怎么选](/jiaocheng/guize-quanju-zhilian/)。

选节点的思路：

- 想手动指定，就在策略组里点选具体节点。
- 想省事，用自动选择或故障转移这类组，让客户端按延迟测试结果挑。
- 延迟测试得到的是连通时间，不是下载速度，别拿它当速度判断依据，见 [节点测速怎么看](/jiaocheng/jiedian-cesu/)。

Mac 上的一个便利是菜单栏图标：点击后通常可以直接切换模式、开关系统代理，不必每次都打开主窗口。菜单项的叫法以当前版本为准。

然后是系统代理与 TUN 的选择：

| 对比项 | 系统代理 | TUN 模式 |
| --- | --- | --- |
| 管到的范围 | 遵守系统代理的应用，如浏览器 | 更多流量，包括命令行工具 |
| 授权 | 修改网络设置时的授权 | 额外的服务或虚拟网卡授权 |
| 建议 | 日常先用这个 | 命令行或个别应用不走代理时再开 |

系统代理在 macOS 里是按网络服务分别保存的，切换了 Wi-Fi 或有线网络后，值得回头确认一次。更多对比，见 [系统代理怎么设置](/jiaocheng/xitong-daili/) 和 [TUN 模式是什么](/jiaocheng/tun-moshi/)。

## 怎么确认设置真的生效了

1. **看终端的系统代理配置。** 打开终端，执行：

```
scutil --proxy
```

输出里 HTTPEnable、HTTPSEnable 或 SOCKSEnable 为 1，并带有本机地址和端口，说明系统代理已开启。端口以客户端显示的为准。

2. **看系统设置里的代理页。** 进入系统设置的网络，选中当前正在用的网络，打开详细信息里的代理页，应当能看到对应协议已勾选。
3. **看客户端的连接页。** 打开网页，回到客户端的“连接”页面，应当能看到对应请求，国内网站走直连，需要代理的网站走某个节点。
4. **做一次对照。** 切到直连，需要代理的网站应当打不开；切回规则，恢复访问。

| 现象 | 常见原因 | 先查什么 | 详细排查 |

| 开了代理，命令行不走 | 命令行不读系统代理 | 是否单独设了代理环境变量，或改用 TUN | [终端怎么走代理](/jiaocheng/zhongduan-daili/) |

| TUN 开不了 | 授权未完成或与其他软件冲突 | 是否安装了服务并授权 | [TUN 模式开不了](/paicha/tun-moshi-shibai/) |
| 退出后上不了网 | 系统代理残留 | 先关系统代理再退出 | [关掉梯子后上不了网](/paicha/guan-tizi-meiwang/) |
