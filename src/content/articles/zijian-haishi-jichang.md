  - q: 自建梯子一定比买机场便宜吗？
    a: 不一定。自建要付服务器租金，如果你只有一个人用、只需要一个地区，成本可能确实更低；但要多个地区，就得租多台，成本很快上升，还要加上你花在搭建和维护上的时间。算账时把时间也算进去，才是公平的对比。
  - q: 自建节点需要什么基础？
    a: 至少要会通过 SSH 登录服务器，能读懂基本的日志，了解端口、防火墙和系统更新的概念。搭建本身有现成的教程可参考，难点在后续：服务端要定期更新，出现被封、连不上、性能问题时要自己排查。没有这些基础，买机场更省心。
  - q: 自建的 IP 会比机场的干净吗？
    a: 自建节点的 IP 是你独享的，不会被其他用户滥用拖累，这是优势。但它多数是机房 IP，部分服务对机房 IP 的审核更严格，而且一旦被标记，你没有别的节点可以换。机场是多人共享出口，各有利弊。
  - q: 租服务器搭梯子会不会违反服务商条款？

自建梯子还是买机场，可以用一句话概括：自建是拿时间和技术换可控，买机场是拿钱换省心。没有哪个选项天然更好，关键看你有没有时间、会不会排查问题、需要几个地区。这篇用对照表把成本、维护和风险摆开，再画出两类人的画像，最后教你做决定前的核对。

## 自建梯子到底要做哪些事

很多人把自建想成“装个软件”，其实它是一个长期的维护工作。以 VPS 搭建梯子为例，大致有这些环节：

1. **租一台境外服务器。** 选地区、选配置、选付费方式，并先读服务商的条款。
2. **安装服务端软件。** 常见的是 Xray、sing-box 这类开源项目，具体步骤以它们的官方文档为准，可参考[Project X 文档](https://xtls.github.io/)和[sing-box 官方文档](https://sing-box.sagernet.org/)。
3. **选协议并配置。** 协议决定客户端兼容性和抗干扰能力，选择思路见[机场协议怎么选](/zhinan/jichang-xieyi/)。
4. **设置防火墙和端口。** 服务器暴露在公网上，需要只开放必要端口，并使用密钥登录。
5. **在客户端里配置节点。** 把服务端的地址、端口、密钥填入客户端，或者生成分享链接导入。
6. **持续维护。** 定期更新系统和服务端软件，监控流量，应对 IP 被封、连不上等问题。

前五步是一次性的，第六步才是真正的长期成本。很多人自建的时候兴致勃勃，几个月后线路出问题，才发现自己没有时间或能力排查。本文不写具体命令，因为命令会随版本变化，抄过时的教程反而容易出错。

### 自建时最容易低估的三件事

- **服务器自身的安全。** 公网上的服务器会不断被扫描，也不断有人尝试登录。使用密钥登录、关闭不需要的端口、及时更新系统，是最基本的要求，疏忽的后果是服务器被他人控制或滥用。
- **配置的备份与迁移。** 服务器出问题或 IP 被标记时，你要能在较短时间内在新服务器上恢复同样的服务。没有备份配置、没有记下搭建过程，重建会很痛苦。
- **流量与账单的监控。** 不同服务商对流量和带宽的计费规则不同，有的超出额度会限速或另外收费。自建后要定期看用量，避免月底才发现异常。

这三件事没有一件特别难，但都需要持续投入。它们也正是机场替你承担的部分，套餐费里其实包含了这份人力。

## 自建梯子和买机场的对照表：自建节点到底省不省

| 对比项 | 自建节点 | 买机场 |
| --- | --- | --- |
| 金钱成本 | 服务器租金，按机型和地区不同，一个地区一台 | 套餐费，含多个地区，按流量和周期计费 |
| 时间成本 | 搭建加持续维护，需要自己排障 | 注册导入即用，维护由服务商负责 |
| IP 被封后的处理 | 自己换 IP 或重建服务器，是否收费因服务商而异 | 服务商更换节点或线路 |
| 线路质量 | 取决于你租的机房和线路，普通机型多为普通国际线路 | 取决于套餐线路类型，可能有中转或专线 |
| 隐私 | 日志在你手里，但服务器租用商知道你的账号和付款信息 | 服务商可见域名和流量，见[梯子安全吗](/zhinan/tizi-anquan-ma/) |
| 多地区节点 | 一台一个地区，多地区需租多台 | 套餐通常含多个地区 |
| 单点风险 | 一台服务器出问题，整条线路就断 | 节点多，单个节点失效可切换 |
| 设备数 | 通常没有人为限制，受服务器性能限制 | 受套餐设备数限制 |
| 流量 | 受服务器租用商的流量或带宽规则限制 | 受套餐流量限制，注意倍率 |

另外补一条没写进表里的前提：表中的自建一栏默认只有你一个人使用。如果要给家人朋友共用，设备数、流量和被滥用的风险都会上升，维护责任也随之变重，这时买机场往往更合适。

读这张表要避免一个误区：不要因为某一行看起来“自建占优”就下结论。“金钱成本”那一行最能说明问题：自建的服务器租金看起来是固定的小额，但要覆盖多个地区、多个设备、足够的线路质量时，成本会叠加；买机场的套餐费看起来较高，却包含了别人替你承担的维护、线路和多地区。

## IP 与线路：自建的出口干净吗

自建最吸引人的一点是“独享 IP”。你的出口只有你自己用，不会被别的用户滥用拖累。这在登录一些对出口敏感的服务时，确实可能减少误触发验证的情况，相关现象可以看[谷歌一直要验证码](/paicha/google-yanzhengma/)。

但这个优势有三个前提：

- **它多半是机房 IP。** 普通服务器租用商的 IP 一般属于机房网络，部分服务对机房 IP 的审核更严格。是否更像家庭网络的原生 IP，取决于服务商和 IP 段，概念见[原生 IP 是什么](/zhinan/yuansheng-ip/)，不要想当然。
- **一旦被标记，没有第二条路。** 机场有一批节点可以换，自建只有一个出口。IP 被标记后，你只能申请换 IP 或重建服务器，是否收费因服务商而异。
- **线路取决于机房。** 普通国际线路在晚间高峰时可能拥堵，部分服务商提供优化线路但价格更高。机场也有类似的线路分级，两者没有天然的优劣，要看你买的具体档位，选梯子目前没有任何测速数据，不能替你下结论。

此外，一台服务器对应一个地区。如果你只需要一个地区，这很划算；需要两三个地区时，自建就要租两三台，成本和维护量都成倍增加。

## 隐私：自己掌握不等于匿名

自建常被认为“更隐私”，因为日志在你自己手里，没有第三方看你的流量。这有一定道理，但要补两点：

1. **服务器租用商知道你是谁。** 账号注册信息和付款记录都在它那里，服务器的 IP 也与你绑定。自建节点并不匿名，只是把“信任谁”的问题从机场换成了租用商。
2. **你得自己负责安全。** 服务端软件存在漏洞、配置不当、密钥泄露，都可能让节点被他人滥用或探测。机场有专人维护，自建要靠你自己。

买机场时，服务商技术上能看到你访问的域名、流量大小和时间，但看不到 HTTPS 的加密内容，详情见[梯子安全吗](/zhinan/tizi-anquan-ma/)。两种方式在隐私上没有绝对的高下，区别在于你选择信任哪一方、愿意承担哪些责任。

## 谁适合自建梯子，谁适合买机场

别把这个选择变成技术优越感的比拼，按处境选：

**更适合自建的人：**
- 熟悉 Linux 基本操作，能通过 SSH 排查问题。
- 只需要一个地区，或者愿意为多个地区付多份租金。
- 愿意每月花一点时间做更新和检查。
- 对出口独享有明确需求，或者想学习原理。

**更适合买机场的人：**
- 不想维护服务器，希望注册导入即用。
- 需要多个地区的节点，用于不同服务。
- 设备多、使用场景杂，不想管协议和端口。
- 没有时间排查问题，出了事希望有客服可问。

**两者结合的做法：** 用机场做日常主力，自建一个节点做备用或特定用途，反之亦可。这样互相兜底，但要多维护一份。主力加备用的思路，可以看[备用机场要不要买](/zhinan/beiyong-jichang/)。

如果你还拿不定主意，用[选梯子向导](/gongju/xuan-tizi-xiangdao/)回答几个问题。

## 决定之前，自己怎么核对

做决定前，按下面的步骤自己算一遍、查一遍：

1. **读服务器租用商的条款。** 查看服务条款和可接受使用政策里对代理用途的规定。有的明确限制，违反可能被停机。条款读不懂就不要租。
2. **估算一年的总成本。** 自建总成本等于服务器租金加上其他开支，再加上你的时间成本；买机场就是套餐费折算成年。时间成本最容易被忽略，可以给自己一个时薪粗略折算。
3. **自测技能。** 你能不能独立通过 SSH 登录服务器、查看日志、修改配置、重启服务？有一项不会，说明维护会比较吃力。
4. **做小规模试验。** 如果租用商支持短期计费，先租最短周期试一个月，别一次买一年。
5. **确认退路。** 自建的节点被封或服务器出问题，你有没有备用方案？至少留一个机场的短周期套餐，作为兜底。
6. **在你常用的时段试一下。** 无论自建还是机场，晚高峰的表现只能自己验证。

六步里大部分都能过关，再决定是否自建；半数以上没把握，就先买机场，学习成本留到以后。

## 下一步：先买机场摸清需求，再决定要不要自建

对多数新手，更稳妥的顺序是：

- **先买一个短周期套餐。** 用[梯子推荐](/tuijian/)里的资料横向比较，选一家试用一到两周，搞清楚自己的流量、地区和设备需求。
- **了解协议和 IP 的基本概念。** 读[机场协议怎么选](/zhinan/jichang-xieyi/)和[原生 IP 是什么](/zhinan/yuansheng-ip/)，这些概念自建时一定会用到。
- **有基础后，再考虑自建。** 把自建作为备用或补充，而不是一上来就替代全部。
- **想先搞清楚买机场的方法**：从[梯子怎么选](/zhinan/tizi-zenme-xuan/)开始。

自建与买机场不是二选一的对立，而是不同阶段的不同工具。需求清楚了，选择自然就清楚。
