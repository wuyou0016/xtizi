faqs:
  - q: v2rayN 能导入 Clash 格式的订阅吗？
    a: 不能保证。v2rayN 最常用的是通用订阅格式，也就是一串分享链接编码后的内容；Clash 专用的 YAML 格式是否被识别，取决于当前版本和机场提供的格式，以官方说明为准。导入后节点为空或数量不对，多半是格式不匹配，可以让机场提供通用订阅，或参考订阅转换的方法。
  - q: 延迟测试显示超时或负数，节点就是坏的吗？
    a: 不一定。超时只说明这次测试没在限定时间内完成，原因可能是节点本身、你的本地网络、系统时间不对或者测试方式不合适。先区分是全部节点都超时，还是个别超时：全部超时多半是本地或订阅层面的问题，个别超时才更可能是节点的问题。
  - q: 系统代理的几个模式，日常选哪个？
    a: 日常选自动配置系统代理，让 v2rayN 在运行时替你设置 Windows 的代理，退出时再清除。清除系统代理用于确认问题是不是出在代理上，不改变系统代理则是你自己在别处管理代理设置时才用。各项的叫法以当前版本为准。
  - q: 打开 v2rayN 闪退或提示缺少运行环境怎么办？

这份 v2rayN 教程针对 Windows：从解压启动，到新增订阅、测节点、选系统代理模式、设置路由，最后确认代理真的在工作。v2rayN 的特点是功能全、选项多，界面信息密度高，新手最容易卡在两处：分不清延迟测试和测速、不知道路由该选哪个预设。下面把这两处讲透。客户端版本和官方地址见页面顶部数据卡，正文不写版本号，界面叫法以当前版本为准。

## 准备与安装：v2rayN 教程的第一步

先确认三件事：

| 准备项 | 怎么确认 | 说明 |
| --- | --- | --- |
| 订阅格式 | 机场后台订阅链接的格式说明 | v2rayN 最常用通用格式，Clash 专用格式能否识别以官方说明为准，判断方法见 [V2Ray 机场怎么选](/zhinan/v2ray-jichang/) |
| 处理器架构 | Windows 设置的系统关于页，看系统类型 | 决定下载 x64 还是 ARM 版 |
| 运行环境 | 看发布页对各安装包的说明 | 有的包需要先装系统运行库，有的自带 |

客户端本身的介绍和同类对比，见 [v2rayN 下载](/xiazai/v2rayn/) 页，这里讲操作。

1. 打开官方发布页 [github.com/2dust/v2rayN/releases](https://github.com/2dust/v2rayN/releases)，确认条目标着 Latest。
2. 按架构和运行环境要求挑出压缩包，下载。
3. 在普通文件夹里解压，比如你自己建的工具目录。配置文件通常保存在程序所在目录，所以不要放进需要管理员权限才能写入的系统保护目录。
4. 双击主程序启动。第一次启动可能出现防火墙提示，选择允许；安全软件拦截时，先确认文件来自官方发布页，再处理。
5. 启动成功后，托盘区会出现图标，主窗口中间是服务器列表，此时还是空的。

内核方面，本站收录的 v2rayN 使用 Xray 与 sing-box 两类内核，通常不用手动管理，能否切换以当前版本设置为准。想了解背景，看 [V2Ray 是什么](/zhinan/v2ray-shi-shenme/)。

## v2rayN 订阅：新增分组、更新、查看节点

v2rayN 把每个订阅放进一个“分组”，节点按分组归类，方便你同时用多个订阅。

1. 在菜单里找“订阅分组”，进入“订阅设置”（具体叫法以当前版本为准）。
2. 点添加，填两个主要字段：备注，随便起，比如“主力”；地址，粘贴机场的订阅链接，格式示例：`https://example.com/你的订阅链接`
3. 其余选项如自动更新、分组筛选，保持默认即可，用熟练后再调。
4. 确认保存，回到主窗口，通过菜单执行“更新订阅”。
5. 更新完成后，服务器列表里会出现该分组下的节点，可以按分组切换查看。

更新订阅通常有两个入口：通过代理更新、不通过代理更新。区别在于更新请求的走法：

| 入口 | 适用情况 |
| --- | --- |
| 不通过代理更新 | 第一次导入，或订阅地址能直接访问时 |
| 通过代理更新 | 订阅地址需要走代理才能访问，且你已经有一个能用的节点 |

第一次导入时，你手里还没有可用节点，所以先用不通过代理的方式。更新失败的排查见 [订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)，通用的导入原理见 [订阅链接怎么用](/jiaocheng/dingyue-daoru/)，格式不兼容时的处理见 [订阅转换](/jiaocheng/dingyue-zhuanhuan/)。

## 选节点：测延迟和测速不是一回事

在服务器列表里右键，会看到几种测试入口。它们回答的问题不同：

| 测试 | 测的是什么 | 能说明什么 | 不能说明什么 |
| --- | --- | --- | --- |
| TCP 延迟（有的版本提供） | 能否与节点建立连接 | 节点端口大致可达 | 实际能否转发数据 |
| 真连接延迟 | 经节点发出一次真实请求并等待响应 | 节点当前能转发，响应有多快 | 持续下载的速度 |
| 测速 | 经节点下载一段数据 | 吞吐量的大致水平 | 会消耗流量，结果随时间和线路波动 |

挑节点的顺序：

1. 先对整个分组做一次真连接延迟测试，把明显超时的排除。
2. 在剩下的里面选延迟较低的几个，作为候选。
3. 真要比速度，对候选节点分别测速，并换到不同时段多测几次。
4. 测速会消耗套餐流量，别对整个分组批量测速。

延迟数字的含义和局限，见 [节点测速怎么看](/jiaocheng/jiedian-cesu/) 和术语页 [延迟](/cidian/yanchi/)。本站没有自己的测速数据，这里只教方法。

## v2rayN 设置：系统代理的几种模式

主窗口上有个切换系统代理的下拉项，常见有三种选择：

| 选项（常见叫法） | 行为 | 什么时候用 |
| --- | --- | --- |
| 自动配置系统代理 | v2rayN 运行时设置 Windows 的代理，退出时清除 | 日常使用 |
| 清除系统代理 | 关闭 Windows 的代理设置 | 排查问题，确认是否由代理引起 |
| 不改变系统代理 | v2rayN 不碰系统设置 | 你自己在别处管理代理，或只想让个别应用走代理 |

操作顺序：

1. 先在服务器列表里选中一个测试通过的节点，双击或按菜单设为当前使用。
2. 再把系统代理切到自动配置。
3. 本地代理的端口会显示在界面下方的状态栏，数字以客户端显示为准，不需要记。

如果需要接管命令行工具和不走系统代理的应用，可以看 Tun 模式，开启通常需要管理员权限，条件与风险见 [TUN 模式是什么](/jiaocheng/tun-moshi/)；系统代理的原理，见 [系统代理怎么设置](/jiaocheng/xitong-daili/)。

## 路由设置：绕过大陆预设怎么用

路由决定哪些流量走代理、哪些直连，对应国内站点不绕远路。v2rayN 把常用方案做成了预设，常见的有：

| 预设（常见叫法） | 行为 | 适合 |
| --- | --- | --- |
| 绕过大陆 | 大陆域名和 IP 直连，其余走代理 | 日常使用，推荐起步 |
| 全局 | 所有流量走代理 | 临时排查，或规则判断不准时 |
| 黑名单 | 只有列表里的站点走代理，其余直连 | 只想让少数站点走代理 |

设置步骤：

1. 在主窗口找到路由相关的下拉项，或进入“路由设置”窗口。
2. 选中“绕过大陆”预设，设为启用。
3. 路由判断依赖地理数据文件，文件过期会让一部分站点判断出错，更新入口通常在检查更新相关菜单里，以当前版本为准。
4. 想自己写规则，等熟悉了再进入自定义路由，写法思路见 [分流规则怎么写](/jiaocheng/fenliu-guize/)。

## 怎么确认设置真的生效了

1. **看 Windows 的代理设置。** 打开 Windows 设置，进入“网络和 Internet”下的“代理”页，系统代理为自动配置时，应当能看到手动代理已开启，地址是本机。
2. **用 PowerShell 查。** 执行下面这条，ProxyEnable 为 1 表示开着，ProxyServer 是代理地址：

```
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | Select-Object ProxyEnable, ProxyServer
```

3. **看 v2rayN 的日志窗口。** 主窗口下方通常有消息或日志区域，访问网页时能看到请求记录，注明走的是代理还是直连。
4. **对照验证。** 分别打开一个国内网站和一个需要代理的网站，都能打开。再把系统代理切到清除，需要代理的网站应打不开，说明刚才确实是代理在起作用。
5. **换路由再试。** 切到全局，国内网站依然能打开，只是可能变慢；切回绕过大陆，又恢复。
