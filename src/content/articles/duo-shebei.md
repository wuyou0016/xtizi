梯子设备数不是一个简单的数字。套餐页写着“3 台设备”，机场实际限制的可能是同时在线的 IP 数，也可能是注册过的设备数，还有些根本不限设备、只按流量计费。弄清是哪一种，才知道家里几个人、几台手机电脑能不能一起用。下面逐一讲清，并告诉你怎么在规则内安排共用。

## 梯子设备数怎么限制：三种常见口径

机场限制设备的方式，大体分三种。下表把三种口径的计数方式、常见误解和超限后的典型表现放在一起：

| 口径 | 怎么计数 | 常见误解 | 超限后常见的表现 |
| --- | --- | --- | --- |
| 同时在线 IP 数 | 按同一时间使用订阅的公网 IP 个数，同一个 IP 下的多台设备可能只算一个 | 以为是设备台数 | 部分节点连不上，或订阅被临时限制 |
| 注册设备数 | 按客户端注册或识别出的设备个数 | 换了新手机，忘了把旧设备解绑 | 提示设备数已满，需要在面板里解绑 |
| 不限设备，按流量计 | 不管几台设备，只扣流量额度 | 以为不限设备就可以随便共享 | 额度很快用完，条款里仍可能禁止转售或共享 |

这里有一个重要提醒：站内数据表里“设备数”这一栏，很多机场是空白的。空白只说明我们没有核实到，**不代表不限制**。设备条款以机场官网和服务条款为准，不要凭空假设。

你在套餐页上看到的“设备数”还可能叫别的名字，如“同时在线”“并发”“终端数”。遇到模糊说法，就按上面三种口径逐个对号入座，问客服确认。套餐页上其他参数怎么读，见[机场怎么选](/zhinan/jichang-zenme-xuan/)。

## 套餐写 3 台，为什么多设备同时在线仍可能超限

数字和实际情况之间，有几个常见的落差：

- **IP 会变。** 手机在 Wi-Fi 和移动网络之间切换，公网 IP 会随之改变。按 IP 计数的机场，可能把同一部手机的前后两个 IP 都算进去。
- **一人多地。** 你在家里和办公室两个地点同时在线，就是两个 IP，哪怕是同一个人用。
- **旧设备没退出。** 换新手机后，旧手机上的客户端仍然保持着订阅，在后台偶尔联网也会占名额。
- **路由器后面是一整个家。** 路由器上运行代理，家里所有设备共用一个出口 IP。按 IP 计数时它可能只算一个，但流量会成倍增长，也有些机场在条款里限制路由器使用。局域网共享的具体做法，见[局域网共享代理](/jiaocheng/juyuwang-gongxiang/)。
- **共享出口的网络。** 部分运营商网络会让很多用户共用同一个出口 IP，计数结果可能和你的预期不一致。

这些情况的共同点是：**数字背后的计数方式决定实际能用几台。** 所以与其纠结“3 台够不够”，不如先问清计数口径。

下面按常见设备列一张示意表，帮你对照自己的家庭情况。注意这是示意，具体怎么计数仍以你的机场为准：

| 设备或场景 | 可能怎么占用名额 | 建议 |
| --- | --- | --- |
| 手机，常在 Wi-Fi 与移动网络间切换 | 按 IP 计数时可能先后占用多个 IP | 观察出门前后是否出现掉线或提示 |
| 电脑 | 通常一台设备对应一个 IP | 长时间不用时退出客户端 |
| 平板、电视盒子 | 容易被遗忘，后台仍可能联网 | 不用的设备及时从客户端里删除订阅 |
| 路由器 | 全屋设备共用一个出口 | 先确认条款是否允许 |
| 虚拟机、模拟器 | 可能被识别成额外的设备 | 避免和宿主机同时开启 |

做完这张表，你对自己的梯子设备数需求就有了一个比较具体的数字，下单时也不容易买少。

## 家人多设备同时在线，怎么安排才不超出限制

目标是在套餐规则内合理分配，而不是想办法绕过限制。按下面步骤走：

1. **先弄清口径。** 读条款或问客服：设备数是按 IP 还是按注册设备算？
2. **列出同时在线的最大场景。** 比如晚上你开电脑、爸妈各一部手机、孩子一台平板，高峰时同时有几台？
3. **同一个屋檐下，优先考虑共用一个出口。** 如果条款允许，用一台电脑或路由器共享，比每台设备各自导入订阅更省名额。
4. **每个人在自己的设备上导入，不要多处同时登录同一个客户端。**
5. **别把订阅链接留在聊天记录里。** 导入完成之后，不要把链接发到家庭群反复转发。
6. **约定流量用量。** 多个人共用一个套餐，流量会被叠加消耗，看视频的人尤其要有数。估算方法见[梯子流量](/zhinan/tizi-liuliang/)。
7. **需求超出套餐，就升级或再买一份。** 比起冒险超限，多花一点钱更划算。

如果你们家用户很多、设备很杂，建议先把需求写下来，再对照套餐页筛选，而不是先买再凑合。可以用[选梯子向导](/gongju/xuan-tizi-xiangdao/)按人数和用途筛一遍。

## 梯子共享给外人，为什么不值得

“朋友问我借一下”“同学凑合用几天”，是梯子共享最常见的开头。但订阅链接不是一张门票，而是你账号的凭证，把它交出去，风险由你承担。

| 风险 | 怎么发生 | 后果 |
| --- | --- | --- |
| 流量被耗尽 | 对方不知节制，看视频、下载大文件 | 你自己的额度提前见底 |
| 设备或 IP 超限 | 多地多个 IP 同时在线 | 节点被限制，严重时账号被封停 |
| 订阅二次扩散 | 对方再转发给别人 | 链接被公开滥用，你无法控制 |
| 责任归属 | 对方在你的订阅上做了违反条款的事 | 账号在你名下，后果由你承担 |

如果你已经把链接发出去了，现在最该做的是在面板里**重置订阅链接**，然后只给自己的设备重新导入。具体做法和日常保护，见[订阅链接泄露了怎么办](/bikeng/dingyue-xielou/)。订阅链接本身是什么，可以看词典里的[订阅链接](/cidian/dingyue/)。

如果别人真的需要用，最好的办法是让他自己买一份。很多机场的月付价格不高，各自独立也更省心。

还有一种情况值得单独说：家人之间共用。这和分享给外人不同，因为你清楚对方是谁、在哪里用、用多少。但原则是一致的：订阅链接始终由你保管，设备由你登记，流量由你监控。真正的风险往往不在家人，而在链接被转发之后失去控制。

## 设备超限有什么表现，怎么自查

被限制时，你通常不会看到一个明确的提醒，而是遇到下面这些现象：

- 订阅更新失败，或者更新后节点数量变少。
- 部分节点突然连不上，换设备又可以。
- 客户端提示设备数已满。
- 流量消耗速度明显高于平时。
- 收到机场的邮件或公告，要求处理异常使用。

自查按这个顺序：

1. 回想最近是否新增过设备，比如新手机、新电脑、借给别人用的平板。
2. 登录官网面板，看有没有在线设备或 IP 的列表。如果有，把不认识或不用的设备解绑。
3. 检查是否把同一条订阅导入到了多个客户端，或者路由器上还开着代理。
4. 如果你怀疑链接外泄，重置订阅链接，再重新导入自己的设备。
5. 订阅更新还是失败，排查办法见[订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)。

自查的核心是**把名额还给真正在用的设备**。多数问题就出在旧设备、闲置设备或者外泄的链接上。

## 下单前，用四个问题核对设备条款

设备数写得再清楚，也不如向客服确认一遍。下单前可以问：

- 设备数是按同时在线的 IP 数计，还是按注册设备数计？
- 通过路由器或局域网共享给多台设备使用，条款是否允许？
- 超出限制时的处理方式是什么：限速、断开，还是封停？
- 面板里能否查看和解绑在线设备？

把回答截图保存。如果客服的答复和官网条款矛盾，以条款为准，同时在下单前就问清楚。回答含糊的机场，建议再看看别的候选。

## 下一步：按人数和设备清单选套餐

1. 列一张清单：谁用、用几台设备、同时在线最多几台。
2. 想让家里设备共用一个出口，先读[局域网共享代理](/jiaocheng/juyuwang-gongxiang/)，再向客服确认条款是否允许。
3. 到[梯子推荐](/tuijian/)里筛出候选，下单前用四个问题核对设备条款。
4. 买最短周期，试用期里用多设备同时测一次，看是否触发限制。
5. 订阅链接一律自己保管，需要给别人用就让对方自己买。

规则内的合理安排，比事后补救更省钱，也更省心。
