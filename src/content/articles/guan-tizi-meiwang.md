关闭梯子后上不了网，几乎都是因为设置还指着一个已经不存在的东西：系统代理仍然指向客户端已关闭的本地端口，或者 TUN 模式留下的虚拟网卡和 DNS 设置没有还原。最直接的办法是重新打开客户端，先关系统代理再退出；不行就到系统里手动清除。下面按设备分别讲检查位置。

## 关闭梯子后上不了网的三类原因

客户端开启系统代理时，会把“代理服务器地址和端口”写入系统设置，让浏览器等程序把请求发给它。正常退出时，客户端应该把这项设置还原。但客户端崩溃、被强制结束、被安全软件终止，或者电脑意外关机时，这一步可能没来得及做。系统还在把请求发往那个端口，端口却已经没人监听，网页就打不开了。系统代理的原理见[系统代理怎么设置](/jiaocheng/xitong-daili/)。

| 现象 | 最可能的原因 | 看哪一节 |
| --- | --- | --- |
| 浏览器提示代理服务器拒绝连接，或类似的英文错误 | 系统代理还开着，指向已经关闭的本地端口 | 先试重开客户端，再看分设备的几节 |
| 浏览器打不开，某些应用却正常 | 只有读取系统代理的程序受影响 | 同上 |
| 所有程序都没网 | 虚拟网卡、路由或 DNS 没有还原；安卓上还可能是开着“始终开启的 VPN” | 安卓和 iPhone、TUN 的几节 |
| 只有终端里的命令（git、npm 等）不行 | 终端环境变量里残留了代理 | 浏览器、终端和 TUN 的一节 |
| 客户端启动时提示端口被占用 | 有别的程序占着端口 | [端口占用](/paicha/duankou-zhanyong/) |

浏览器的报错文字因浏览器而异，以你看到的为准。重点不是背文字，而是意识到：这种代理残留是你本机设置的问题，和机场、节点没有关系。

## 先试这个：重新打开客户端，先关系统代理再退出

不用动系统设置，先试这个：

1. 重新启动梯子客户端。
2. 在客户端里把系统代理开关关闭，如果开了 TUN，也一并关闭。
3. 正常退出客户端。
4. 试着打开几个国内网站。

恢复了，说明就是系统代理没关。客户端启动不起来，或者开关关不掉，再往下看分设备的手动清除方法。

## Windows：三处设置要逐个检查

**第一处：系统代理。** 它有两个入口，指向的是同一份设置，任选其一：

- 设置里的网络和 Internet，进入代理页面，把手动设置代理里的“使用代理服务器”关闭，并检查“使用设置脚本”是否被写入了地址。
- 控制面板里的 Internet 选项，连接选项卡，局域网设置，取消“为 LAN 使用代理服务器”和“使用自动配置脚本”的勾选。

想用命令行确认，可以查询注册表里的开关：

```
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable
reg query "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyServer
```

ProxyEnable 的值为 0x1 表示代理开着，ProxyServer 是它指向的地址和端口。想直接关掉，在图形界面里操作更稳妥。熟悉命令行的话，也可以只改这一个开关：

```
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Internet Settings" /v ProxyEnable /t REG_DWORD /d 0 /f
```

改完后重启浏览器。

**第二处：WinHTTP 代理。** 这是另一套独立的设置，主要影响基于 WinHTTP 的程序和部分系统服务，用 netsh 管理，命令的完整说明见[Microsoft Learn：Windows 代理设置](https://learn.microsoft.com/en-us/windows/win32/winhttp/netsh-exe-commands)。先查看：

```
netsh winhttp show proxy
```

如果显示直接访问、没有代理服务器，说明这里没有残留。如果显示了一个代理地址，可以重置：

```
netsh winhttp reset proxy
```

这条命令一般需要以管理员身份运行命令提示符。

**第三处：DNS 与虚拟网卡。** 如果用过 TUN 模式，看一下网络适配器列表里是否还留着虚拟网卡，再看当前网卡的 DNS 服务器是不是被改成了一个陌生的地址：

```
ipconfig /all
ipconfig /flushdns
```

虚拟网卡在客户端退出后仍然存在时，可以在网络适配器里禁用它，或者重启电脑。

## macOS：在网络设置里逐个关掉四类代理

图形界面：打开系统设置里的网络，选中当前正在使用的连接，进入详细信息，找到代理。把网页代理（HTTP）、安全网页代理（HTTPS）、SOCKS 代理和自动代理配置全部关闭。菜单名称以你的系统版本为准。

命令行：先列出网络服务的名字，再逐项查看。

```
networksetup -listallnetworkservices
networksetup -getwebproxy "Wi-Fi"
networksetup -getsecurewebproxy "Wi-Fi"
networksetup -getsocksfirewallproxy "Wi-Fi"
```

命令里的 Wi-Fi 要换成上一条命令列出的、你正在使用的服务名称。显示为开启、并指向一个本地地址的，就是残留。关闭的命令如下：

```
networksetup -setwebproxystate "Wi-Fi" off
networksetup -setsecurewebproxystate "Wi-Fi" off
networksetup -setsocksfirewallproxystate "Wi-Fi" off
networksetup -setautoproxystate "Wi-Fi" off
```

这些命令可能需要管理员权限，必要时在前面加 sudo。如果 DNS 被改成了陌生的地址，可以先查看，再恢复为自动获取：

```
networksetup -getdnsservers "Wi-Fi"
sudo networksetup -setdnsservers "Wi-Fi" Empty
```

## 安卓和 iPhone：VPN 与 Wi-Fi 代理各查一遍

手机上的梯子客户端多以系统 VPN 的方式运行，残留的位置和电脑不同。

**安卓**：

1. 进入设置里的网络和互联网，找到 VPN。看是否有遗留的 VPN 配置，并留意“始终开启的 VPN”和“禁止没有 VPN 的连接”这两项。后一项打开时，只要客户端没有运行，所有网络都会被系统阻断，看起来就是关梯子没网。关闭它们，或者重新打开客户端。
2. 点开当前连接的 Wi-Fi，进入修改网络的高级选项，把代理改成无。
3. 菜单名称因手机品牌和系统版本而异。

**iPhone**：

1. 进入设置里的 VPN 页面，或通用里的 VPN 与设备管理，看 VPN 开关是否还开着，是否有遗留的配置。客户端已经删除但配置还在时，可以在这里删掉。
2. 进入无线局域网，点当前网络旁边的信息按钮，找到配置代理，选关闭。

四个平台的检查位置对照如下：

| 系统 | 检查位置 | 要关闭或清除的项目 |
| --- | --- | --- |
| Windows | 设置的代理页、Internet 选项的局域网设置、netsh winhttp | 使用代理服务器、使用设置脚本、WinHTTP 代理 |
| macOS | 网络设置里的代理页 | 网页代理、安全网页代理、SOCKS、自动代理配置 |
| 安卓 | VPN 设置、当前 Wi-Fi 的代理选项 | 始终开启的 VPN 与阻止无 VPN 连接、Wi-Fi 手动代理 |
| iPhone | VPN 设置、当前 Wi-Fi 的配置代理 | 遗留的 VPN 配置、Wi-Fi 手动代理 |

## 浏览器、终端和 TUN：系统代理之外的三个残留点

系统代理清掉了还是不行，再检查这三处：

**浏览器自己的代理设置。** 多数浏览器默认跟随系统代理，但 Firefox 有独立的网络设置，可以在设置里选择不使用代理或使用系统代理。另外，管理代理的浏览器扩展也可能自己改了设置，临时禁用扩展看看。

**终端环境变量。** 终端里的命令不读系统代理，而是读环境变量。查看当前终端有没有残留：

```
env | grep -i proxy
```

Windows 命令提示符里用 `set | findstr /i proxy`。有输出时，在当前终端里把对应变量清掉；如果它写在 shell 的启动文件里，还要从文件中删掉。终端代理的完整做法见[终端怎么走代理](/jiaocheng/zhongduan-daili/)。

**TUN 的虚拟网卡和 DNS。** TUN 模式下，客户端会创建一块虚拟网卡，并改动路由和 DNS。异常退出时这些改动可能没被清理，表现为所有程序都没有网。处理的顺序是：重新打开客户端，把 TUN 开关关一次，再正常退出；不行就重启电脑，或者在网络适配器里禁用虚拟网卡。TUN 的原理见[TUN 模式是什么](/jiaocheng/tun-moshi/)，开不了 TUN 的情况另有[排查](/paicha/tun-moshi-shibai/)。

## 关闭梯子后上不了网，怎么确认已经修好

按下面几步确认，每一步都能独立看到结果：

1. 重启浏览器，打开几个国内网站。
2. 回到系统的代理设置页面，确认相应的开关都已经关闭。
3. 用命令行确认网络本身是通的：

```
curl -I https://DOMESTIC_SITE
```

DOMESTIC_SITE 换成任意一个国内网站的域名。能返回一行 HTTP 状态，说明网络是通的。

4. 重新打开客户端，把系统代理开关打开再关闭一次，确认可以正常打开和关闭。

| 现象 | 说明什么 | 下一步 |
| --- | --- | --- |
| 国内网站恢复，国外网站打不开 | 本机网络正常了，梯子本来就没开 | 正常，需要时再打开客户端 |
| 仍然提示代理服务器拒绝连接 | 还有一处代理没有清除 | 回头检查 Internet 选项里的脚本、浏览器自己的设置 |
| 所有程序仍然没有网 | 不是代理的问题，可能是网卡、路由或 DNS，或者本来就没有网络 | 重启网卡和路由器，检查 DNS |
| 每次关梯子之后又复现 | 退出方式不对，或客户端设置有问题 | 看下一节的预防办法 |

## 下一步：把退出顺序固定下来，再回到总排查

**预防比修复省事。**

- 退出客户端之前，先在客户端里关闭系统代理和 TUN，再正常退出。不要直接结束进程。
- 有的客户端提供退出时自动还原系统代理的选项，可以打开，名称以版本为准。
- 同一时间只运行一个代理类的软件，其他代理、VPN、加速软件会互相抢端口和网卡。
- 公司或学校的电脑，代理设置可能由统一策略下发，改之前先确认。

**修好之后，如果开着梯子也连不上，**按[梯子连不上的六步排查](/paicha/tizi-lianbushang/)走一遍。确认是服务商的问题，再到[机场推荐](/tuijian/)里对照，先用月付验证后决定要不要换。
