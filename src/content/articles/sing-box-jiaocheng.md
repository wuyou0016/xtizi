sing-box 教程要先讲清一个和其他客户端不同的事实：sing-box 不靠“订阅”工作，而靠一份 JSON 配置文件。官方图形客户端提供“远程配置”，可以从一个链接下载这份文件并定期更新，但前提是链接返回的内容本身就是 sing-box 能读的配置。机场给的是通用格式或 Clash 格式时，需要另寻他路。下面按这个思路，讲各平台怎么导入、配置文件长什么样、怎么检查。

## sing-box 教程第一步：分清内核和客户端

sing-box 既是一个通用的代理内核，也有官方提供的图形客户端。再加上一批基于它的第三方应用，搜索资料时很容易混在一起。

| 平台 | 官方提供什么 | 获取与运行方式 |
| --- | --- | --- |
| 安卓 | 官方图形客户端 | 发布页或应用商店等渠道，以官方文档的客户端页面为准 |
| iPhone、Mac | 官方图形客户端 | 通过 App Store 等渠道，iPhone 上常需外区账号，见[外区 Apple ID 怎么准备](/jiaocheng/waiqu-apple-id/) |
| Windows、Linux | 官方 sing-box for Desktop，或命令行内核 | 以官方文档的客户端页为准，命令行内核可从[官方仓库](https://github.com/SagerNet/sing-box)的发布页下载 |

客户端的获取渠道和界面会变，请以[官方文档里的客户端页面](https://sing-box.sagernet.org/clients/)为准。内核与各平台客户端的下载入口，汇总在[sing-box 下载页](/xiazai/sing-box/)。

另一类是第三方客户端，例如 Hiddify、Karing、NekoBox for Android。它们使用 sing-box 作为内核，但自己做了界面，并且通常能直接解析机场的订阅，对新手门槛低得多。“内核”和“客户端”的分工，见[代理内核](/cidian/neihe/)这条术语。如果你只是想把订阅导入用起来，可以先看[Hiddify 使用教程](/jiaocheng/hiddify-jiaocheng/)，不必直接面对配置文件。

## sing-box 配置文件里有什么：六个顶层区块

打开一份 sing-box 配置，最外层是几个并列的区块。读懂这张表，你就能看出任何一份配置的大致结构。

| 区块 | 作用 | 新手要不要碰 |
| --- | --- | --- |
| log | 日志级别与输出位置 | 排查问题时调高级别 |
| dns | 域名解析的服务器与策略 | 谨慎，解析出错会导致网页打不开 |
| inbounds | 入口：本地代理端口、TUN 虚拟网卡 | 图形客户端通常自动处理 |
| outbounds | 出口：节点本身，以及把节点编成组的选择类、测速类出口 | 订阅里的节点就在这里 |
| route | 路由规则：什么流量走哪个出口，什么直连 | 国内外分流在这里决定 |
| experimental | 缓存、外部控制接口等附加功能 | 不清楚用途时别动 |

几点需要注意。

- **节点和策略组都放在出口里。** 与 Clash 不同，sing-box 没有单独的策略组区块，而是用特定类型的出口把节点编成组，类型名以官方文档为准。策略组的通用概念见[策略组怎么用](/jiaocheng/celue-zu/)。
- **字段随版本调整。** 旧配置放到新内核上，可能报字段错误或行为变化。[官方文档的迁移说明](https://sing-box.sagernet.org/migration/)会列出改动，升级前对照看一遍。
- **每个字段的写法**，都以[官方配置文档](https://sing-box.sagernet.org/configuration/)对应的版本为准，本文不逐项展开。

配置里包含节点的地址和密码，等同账号凭证。贴到论坛或问题区求助之前，先把这些字段替换成占位内容。

## 官方图形客户端怎么导入：用“远程配置”

官方图形客户端（安卓、苹果平台，以及桌面端），导入订阅走“配置”页里的远程配置，桌面端的界面以官方文档为准。按钮叫什么随版本而变，但流程是固定的：

1. 打开应用，进入配置相关的页面（常见叫法“配置”或 Profiles），点加号新建。
2. 配置类型选“远程”（Remote），而不是本地。
3. 填名称，在链接栏粘贴 `https://example.com/你的订阅链接`，要求这个链接返回的是 sing-box 格式。
4. 如果有自动更新的开关或间隔，按需打开。
5. 保存并更新，成功后回到首页选中这份配置，点启动。首次启动时，安卓会弹出系统的 VPN 权限窗口，苹果设备则提示添加 VPN 配置，都点允许。

配置类型大致有这几种，以界面为准：

| 类型 | 内容来源 | 适合谁 |
| --- | --- | --- |
| 远程 | 一个返回 sing-box 配置的链接 | 机场提供了 sing-box 格式的订阅 |
| 本地 | 你手动粘贴或导入的配置文件 | 自己写或别人发来的配置 |
| 同步类 | 通过系统云服务同步的配置，部分平台才有 | 需要在多台设备间共用 |

怎么判断链接返回的是不是 sing-box 格式？在浏览器里直接打开它，看返回内容的开头：

| 返回内容的样子 | 说明 | 能否用于远程配置 |
| --- | --- | --- |
| 以花括号开头的 JSON 文本 | 很可能就是 sing-box 配置 | 可以尝试 |
| 一整段看不出含义的字母数字串 | 通用分享链接格式的订阅 | 不能直接用，得先转成 JSON 或换客户端 |
| 含有 proxies、rules 字样的缩进文本 | Clash 格式的订阅 | 不能，需要转换或换客户端 |

这一步只花几十秒，却能避免很多无谓的排查。

## 机场没有 sing-box 订阅怎么办：三条路的取舍

这是 sing-box 用户最常遇到的拦路虎。可选的做法如下：

| 方案 | 做法 | 风险与代价 |
| --- | --- | --- |
| 向机场要 sing-box 格式 | 查看机场后台的订阅格式选项，或联系客服 | 几乎没有风险，但不是所有机场都提供 |
| 换用兼容多格式的客户端 | 选择基于 sing-box 内核、能直接解析订阅的第三方应用，如[Hiddify](/xiazai/hiddify/)和[Karing](/xiazai/karing/) | 要重新熟悉一个界面，具体支持的格式以各自官方说明为准 |
| 使用订阅转换 | 把订阅链接交给转换服务，得到 sing-box 配置 | 链接经过第三方，可能泄露或被篡改，转换后字段可能丢失 |

决策可以这样走：

- 你只想用起来，不想研究配置：选第二条，直接换客户端。
- 你喜欢掌控配置、愿意长期维护：先试第一条，没有再考虑第三条。
- 必须转换时：优先在自己掌控的环境里做，并在转换后检查节点数量和关键字段有没有丢失。转换这条路的利弊单独写在[订阅转换是什么](/jiaocheng/dingyue-zhuanhuan/)，地址一旦外泄要怎么补救，看[订阅链接泄露了怎么办](/bikeng/dingyue-xielou/)。

不要为了迁就 sing-box 而把订阅链接交给来路不明的转换网站。通用的订阅知识见[订阅链接怎么用](/jiaocheng/dingyue-daoru/)。

## 桌面端用命令行：先校验，再运行

Windows 和 Linux 上，最直接的用法是运行内核。把配置文件放在内核旁边，先校验再启动：

```
sing-box check -c config.json
sing-box run -c config.json
```

check 命令只检查配置的语法和字段是否合法，不会真的联网。有报错时，输出会指出出问题的位置，改到不再报错再运行。

几点注意：

- **TUN 入口通常需要更高权限。** 在 Windows 上用管理员身份运行终端，在 Linux 和 Mac 上用具备相应权限的账户，概念见[TUN 模式是什么](/jiaocheng/tun-moshi/)。
- **本地代理端口以配置为准。** 如果你在入口里开了本地代理端口，浏览器和其他程序要指向这个端口，数字以你的配置为准。
- **从最小的配置开始。** 先只写一个入口、一个节点和一条路由，确认能通，再逐步添加 DNS 和规则。一次写太多，出错时无从查起。
- **要长期使用的话**，想想你是否真需要手写配置。命令行方式灵活，但维护成本由你自己承担。

## 验证生效与常见卡点

按下面的顺序核对。

1. **校验配置。** 命令行用户先跑 check，图形客户端用户看导入后有没有报错提示。
2. **看日志。** 把日志级别调到能看到出站信息，访问一个网站后确认请求走了哪个出口。
3. **对比出口 IP。** 启动服务前后各查一次出口 IP，与日志里显示的出口互相印证；两边一致，才能说这份配置确实在转发流量。
4. **国内外各试一个。** 国内网站应当直连，国外网站应当走代理。国内网站变慢，多半是路由规则没有把它分出去，见[开了梯子国内网站变慢](/paicha/guonei-wangzhan-man/)。
5. **断开再看。** 停止服务，国外网站应当打不开，否则还有别的代理在生效。

卡点汇总：

| 症状 | 常见原因 | 先试什么 |
| --- | --- | --- |
| 远程配置解析错误 | 链接返回的不是 sing-box 格式 | 用浏览器打开链接，看开头 |
| 升级后配置报字段错误 | 版本间字段调整 | 对照迁移说明，或换最小配置重来 |
| 启动后完全不能上网 | DNS 或路由写错，TUN 权限不足 | 退回到最小配置，逐步添加 |
| 节点全部超时 | 订阅过期、系统时间不准 | 检查机场套餐和系统时间，见[节点超时怎么办](/paicha/jiedian-chaoshi/) |
| 部分网站走了错误的出口 | 路由规则顺序不对 | 调整规则顺序，规则按从上到下命中 |

配置校验通过、日志也没有报错却依然不通，就转去[梯子连不上怎么办](/paicha/tizi-lianbushang/)，从外围网络重新排查。

## 下一步：按你的目标，选一条最短的路

- **想先用起来：** 不必直接面对配置文件，按这篇 sing-box 教程的第一节了解区别后，改用[Hiddify 使用教程](/jiaocheng/hiddify-jiaocheng/)里的一键导入。
- **想理解配置并长期维护：** 读官方文档的配置部分，从一份最小配置开始，每次只加一个功能。
- **关心协议怎么选：** 先看[机场协议怎么选](/zhinan/jichang-xieyi/)，再确认套餐支持什么。
- **还没有机场：** 从[机场推荐](/tuijian/)开始，买之前确认套餐提供 sing-box 或你所选客户端能解析的订阅格式。

sing-box 的官方客户端只认自家格式，所以买机场前先确认能否拿到 sing-box 格式的地址；下方数据块仅作资料，价格以官方页面为准。
