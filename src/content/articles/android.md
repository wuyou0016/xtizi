## APK 架构怎么选：arm64-v8a、armeabi-v7a 还是 universal

安卓梯子下载时让人犹豫的第一件事，是同一个版本在发布页上放着好几个 APK。它们的区别在处理器架构。

| 文件名里的字样 | 面向的设备 | 怎么选 |
| --- | --- | --- |
| arm64-v8a | 64 位 ARM 处理器，近些年的安卓手机基本都是 | 首选 |
| armeabi-v7a | 32 位 ARM 处理器，较老的机型 | 只有老机型才选 |
| x86、x86_64 | 模拟器和少数平板、电视盒子 | 一般用不到 |
| universal、all | 打包了全部架构，体积更大 | 拿不准时选它 |

选错架构不会损坏手机。系统会提示“应用未安装”或“与设备不兼容”，换一个对应架构的文件重装即可，这不代表安装包本身有问题。

有的项目还会在文件名里区分发行渠道或功能变体，含义以发布页的说明为准。看不懂就选架构对得上、文件名里没有额外后缀的那个。发布页上的 Source code 压缩包是源代码，不是安装包。

## 安装未知应用的授权，和国产系统的“风险应用”提示

从浏览器下载 APK 后点安装，会依次遇到两类提示，含义不同。

**第一类是“安装未知应用”的授权。** 从 Android 8 开始，这项权限按来源单独授予：你授权的是“这个浏览器”或“这个文件管理器”可以发起安装，而不是让整台手机对所有来源敞开。装完之后，可以回到同一个设置页把授权收回，不影响已经装好的应用。

**第二类是定制系统自己加的安全提示。** 国产系统常在安装界面显示“风险应用”“未经安全检测”“建议前往应用商店下载”之类的文字，有的还要求输入锁屏密码、登录账号或等待一段倒计时。这类提示的依据多是两点：安装包不是来自系统自带商店；应用属于会建立 VPN 连接的类别。它们描述的是“来源和类别”，不是“检测到了恶意代码”。

怎么判断该不该继续：

1. 文件确实来自数据表列出的官方仓库发布页，提示只说“来源未知”或“存在风险，建议商店下载”：属于来源类提示，核对完下一节的几项后，是否继续由你决定。
2. 提示里明确写出了具体的病毒名称或恶意行为：先停下，重新从官方发布页下载并核对校验值，再看官方仓库的问题反馈里有没有人报告同样的情况。
3. 系统提示“前往应用商店安装”并给出跳转按钮：不要点。跳过去安装的是商店里的同名应用，不是你下载的这一个。

选梯子不提供关闭系统安全检查的操作步骤。上面这些提示都可以在不改动系统安全设置的前提下，按安装界面给出的选项处理。

## 为什么不要用第三方应用市场里的同名 App

这些客户端都是开源的，任何人都能拿到源码重新打包。应用市场、下载站、网盘里的同名安装包，可能出现下面几种情况：

- **被加了东西**。广告组件、额外的权限申请、预置的订阅或节点，都可能在重新打包时加进去。你的全部流量都要经过这个应用，这一点比普通应用敏感得多。
- **只是名字像**。图标和名称与官方客户端接近，实际是另一款闭源产品，行为无从核对。
- **版本滞后**。重新打包的版本常常停在很久以前，内核的修复和新协议都跟不上。
- **之后无法正常更新**。安卓要求覆盖安装的新旧两版使用同一个签名。从市场装的版本签名与官方不同，之后就没法直接用官方 APK 覆盖升级。

所以安卓梯子下载这一步不要图省事。带“内置节点”“免订阅”“去广告版”字样的安装包同理，风险见 [破解版梯子](/bikeng/pojie-kehuduan/)。

## 怎么核对装上的是官方构建

下面的清单可以自己逐项做：

1. **核对地址**。下载页面的地址应当是 GitHub 上对应组织和仓库的 releases 页，与数据表里的官方地址逐字符一致。例如 [v2rayNG 官方发布页](https://github.com/2dust/v2rayNG/releases) 与 [FlClash 官方发布页](https://github.com/chen08209/FlClash/releases)。
2. **核对文件名**。版本号与数据表一致，架构与你的手机一致。
3. **核对校验值**。发布说明里提供了 SHA256 时，用文件管理器自带的校验功能，或把文件传到电脑上计算后比对。
4. **用覆盖安装验证签名**。以后有新版本时，直接安装官方发布页的新 APK。能顺利覆盖升级，说明前后两版签名一致；提示签名冲突，说明之前那版不是同一个来源。同一款应用的 Google Play 版和仓库版签名也可能不同，固定用一个渠道，不要混装。
5. **看权限**。代理客户端需要的是建立 VPN 连接、发送通知，部分需要相机来扫二维码。通讯录、短信、通话记录这类权限与代理功能无关，被索要时要警惕。

## 首次连接的 VPN 请求与后台保活

第一次点“连接”或“启动”，系统会弹出一个连接请求，询问是否允许这个应用建立 VPN 连接。这是安卓提供给应用接管设备流量的标准接口，机制见 [Android 开发者文档：VpnService](https://developer.android.com/reference/android/net/VpnService)。同意后，状态栏会出现一个钥匙形状的图标。系统同一时间只允许一个应用占用这个接口，所以两款客户端不能同时连接。

连上之后要解决的是“别被系统清掉”。定制系统为了省电，会在锁屏后限制后台应用，代理客户端一旦被清，网络就断了。通常要做三处设置，入口名称以你的系统为准：

1. 把客户端的电池策略设为“不限制”或加入省电白名单。
2. 允许它自启动和后台活动。
3. 在最近任务界面把它锁定，避免一键清理时被带走。

另外两个安卓特有的功能值得知道：

- **分应用代理**。只让选中的应用走代理，或让选中的应用不走。银行、支付类应用可以排除在外。设置方法见 [v2rayNG 教程](/jiaocheng/v2rayng-android/) 和 [FlClash 教程](/jiaocheng/flclash-android/)。
- **热点共享**。手机开热点时，连上热点的设备默认不会跟着走代理，需要另外的做法，见 [局域网共享代理](/jiaocheng/juyuwang-gongxiang/)。
