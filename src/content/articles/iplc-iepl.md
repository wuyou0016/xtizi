IPLC 和 IEPL 是两个经常出现在专线机场宣传页上的缩写，它们都指运营商出租的点对点国际专线，区别在接入与承载技术。对买机场的人来说，更值得问的不是“用哪个缩写”，而是专线带宽是否够、卖给了多少人。下面把这两个词、以及围绕它们的几种常见说法，逐个拆开。

## IPLC 和 IEPL 分别是什么：全称与共同点

先看全称：

- **IPLC**，International Private Leased Circuit，国际专用线路。
- **IEPL**，International Ethernet Private Line，国际以太网专线。

两者的共同点是：都是由电信运营商提供、租给企业客户的**点对点**线路，连接的是两个固定端点，例如一端在境内某机房、另一端在境外某机房。线路的这一段不经过公共互联网路由，这是它们被称为“专线”的原因。

在机场的结构里，专线用在哪个位置？看[中转机场](/zhinan/zhongzhuan-jichang/)里的三种路径图：它出现在“境内入口”和“境外落地”之间。你的设备到入口的那一段，仍然是普通的运营商网络。

所以，“买了 IPLC 机场”，意思通常是“这家机场的入口与落地之间租用了一条 IPLC 线路”，而不是“你的电脑到境外全程走专线”。词典里有这两个词的简短解释：[IPLC](/cidian/iplc/)、[IEPL](/cidian/iepl/)。

## IPLC 专线和 IEPL 专线的区别：接入与承载

两个词在行业里的叫法并不完全统一，不同运营商、不同年代的产品文档对它们的界定略有出入。下面是一般性的对比，具体以服务商的书面说明为准。

| 对比项 | IPLC | IEPL |
| --- | --- | --- |
| 全称 | 国际专用线路 | 国际以太网专线 |
| 产品思路 | 传统的点对点电路租用 | 以以太网接口提供的点对点专线 |
| 接入方式的一般描述 | 偏传统的传输网接口 | 以太网接口，更接近数据网络 |
| 带宽划分 | 按预定的带宽等级 | 通常划分更灵活 |
| 共同点 | 点对点、独立于公网路由、由运营商租用 | 点对点、独立于公网路由、由运营商租用 |
| 对机场用户的直接影响 | 难以直接感知 | 难以直接感知 |

最后一行是关键。接入与承载技术的差别，属于线路建设层面的事，用户在客户端里看到的是延迟和速度，看不到底层技术。能不能感受到差别，取决于带宽规格和承载的用户数，而不是缩写本身。

还要区分几个容易被混叫成“专线”的东西：

- **国际互联网接入类产品**：向运营商租的是上网出口，数据仍进入公网路由，性质上不同于点对点专线。
- **私有网络类产品**：多个站点接入同一张隔离网络，也不是 IPLC 或 IEPL 那种两点直连。
- **普通公网隧道**：服务商在两台服务器之间自己建立的加密隧道，走的是公网，不属于任何专线产品。

服务商把这些统称为“专线”，在营销上并不稀奇，所以值得追问一句：具体是哪种产品？

## 对机场用户来说，IPLC 和 IEPL 的差别没有带宽和超售重要

假设有两条规格相同的线路，一条是 IPLC，一条是 IEPL，体感会差别很大吗？一般不会。决定体验的因素，大致按重要程度排列是：

1. 专线上承载的**总带宽**，与卖给这条线路的**用户数量**之比。
2. 你到入口的那一段网络，包括你所在城市、运营商、使用时段。
3. 入口和落地节点自己的服务器负载。
4. 接入与承载技术（IPLC 或 IEPL）这一项。

排序是一般规律，不是定论，但它说明一件事：把预算花在缩写上，不如花在弄清带宽比上。

举一个虚拟的例子来理解。假设套餐 A 和套餐 B 租用的线路规格相同，A 把线路只卖给少量用户，B 卖给多得多的用户。即便 A 用的是 IPLC、B 用的是 IEPL，晚高峰时 B 的拥挤风险通常更高，原因不在缩写，而在每个用户分到的份额。这个例子只用来说明逻辑，不代表任何真实套餐。

专线的成本逻辑也要看清。专线是按带宽租的，价格固定，机场的收入来自卖出的套餐。同样一条线路，卖的人越多，每个人分摊的成本越低，套餐也越便宜；但线路上的实际带宽是固定的，卖得太多，高峰时就会拥挤。这个机制叫超售，展开解释见[超售与限速](/bikeng/chaoshou-xiansu/)。

所以，当一个标着专线的套餐价格明显低于同类时，不妨先问一个问题：这条专线是怎么摊薄成本的？超低价的成因，在[一元机场靠谱吗](/bikeng/dijia-jichang/)里有系统的拆解。

## 内网专线、企业级专线、BGP 入口：宣传词拆解

套餐页上的词，有些有明确的技术含义，有些是营销用语。下面逐个看，注意“你能不能验证”这一列。

| 宣传词 | 可能在说什么 | 你能否自己验证 | 可以追问什么 |
| --- | --- | --- | --- |
| “企业级专线” | 专线是按企业客户的规格租用的，有商业合同 | 不能 | 线路来自哪类产品，带宽规格是多少 |
| “内网专线” | 入口与落地之间走私有链路，不经公网；也可能是服务商内部互联的说法 | 部分，可确认存在境内入口 | 具体是哪一段链路，由谁提供 |
| “BGP 入口” | 入口位于支持多运营商接入的机房，一个地址对多个运营商都可达 | 部分，可观察不同网络下是否都能连 | 入口是否按运营商分设 |
| “IPLC / IEPL 直达” | 入口到落地使用上述专线产品 | 不能 | 能否提供书面说明 |
| “全程专线” | 极可能是误导，你到入口那一段永远是普通网络 | 不能验证，但逻辑上不成立 | 全程的起点和终点分别在哪 |
| “独享带宽” | 为你保留的带宽，或是整条线路只给少数用户 | 不能 | 独享的具体含义和人数 |

其中，BGP 入口值得多说一句。BGP 是互联网上用来交换路由信息的协议，“BGP 入口”描述的是入口服务器**接入侧**的属性，也就是你从不同运营商都能比较顺利地连上它，与入口之后是不是专线是两回事。想了解这个词，可以看[BGP](/cidian/bgp/)条目。

如果一家机场的所有说法都带有“企业级”“内网”“独享”这类词，却没有任何可核对的具体信息，不妨把它们视为营销用语，而不是质量承诺。

## 哪些能自己验证，哪些只能问

用户能做的验证，集中在“结构”层面。

**可以验证：**

1. 节点服务器地址在境内还是境外。把节点地址解析成 IP，再查 IP 归属地。
2. 连上节点后，出口 IP 在哪里。如果节点地址在境内、出口在境外，说明存在境内入口。
3. 在不同运营商网络下，是否都能连上同一个入口，这能间接说明“BGP 入口”的说法是否成立。
4. 不同时段的使用记录：特别是晚间高峰，是否出现规律性的拥挤。

**无法验证：**

1. 入口到落地之间是公网隧道，还是 IPLC、IEPL 专线。
2. 专线的带宽规格，以及它承载的用户数量。
3. 专线是机场自己租用的，还是通过别的服务商转租的。

对第二类问题，唯一的办法是向服务商提问，并且观察回答的质量。回答具体、能给出书面说明，或者在公告里明确写过线路变更的，信息透明度更高；回答只剩“放心，都是专线”的，信息几乎等于零。

可以直接发给客服的问题包括：

- 入口到落地的链路类型是什么，是不是专线产品，能否书面说明。
- 专线一般按什么规格租用，大概服务多少用户。
- 专线故障时，是否有备用线路自动切换。
- 不同线路的节点，流量倍率是否不同。

把这些问题连同回答存档，将来出现纠纷或质量下降时，是你自己的依据。其他需要核对的参数，见[机场怎么选](/zhinan/jichang-zenme-xuan/)。

## 什么人值得为专线付费

专线贵，花这笔钱要有对应的需求。可以用下面几条做判断：

- **晚上集中使用，且断线影响工作**：专线或质量较高的中转，值得纳入考虑。同时准备一家备用机场，避免所有依赖都押在同一条线路上。
- **主要是白天零散使用**：普通线路多半足够，不必为专线付溢价。
- **对出口 IP 类型有要求**：专线与出口 IP 无关，应当去看落地 IP 的属性，见[原生 IP](/zhinan/yuansheng-ip/)。
- **预算紧张**：优先保住流量和设备数，线路档次可以后面再升级。

## 现在可以做的三步

1. **先分清自己属于哪种需求。** 回答两个问题：什么时段用，断线的代价多大。
2. **对照资料筛选候选。** 到[专线机场](/tuijian/zhuanxian/)看公开资料里标注了专线的套餐，再逐项核对上文的追问清单。
3. **用短周期验证。** 买最短周期，用上文的结构验证方法确认入口与出口，并在晚间高峰使用几天，再决定是否续费。

专线是一个值得了解的概念，但它不是质量的同义词。弄懂 IPLC 和 IEPL 的含义只是第一步，看清带宽、超售和透明度，才是真正能帮你省钱的部分。
