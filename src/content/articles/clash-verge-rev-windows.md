faqs:
  - q: Clash Verge Rev 在 Windows 上需要管理员权限吗？
    a: 日常使用系统代理一般不需要。需要管理员权限的是 TUN 模式，它要创建虚拟网卡，客户端通常通过安装服务模式来完成授权，安装时会弹出系统的用户账户控制提示。是否需要、叫什么名字，以当前版本界面为准。不开 TUN 的话，普通权限就能正常使用。
  - q: Clash Verge Rev 订阅导入成功，代理页却空空如也，先查哪里？
    a: 先确认复制的是 Clash 格式的订阅链接，并且完整、没有多余空格。再看套餐是否过期、流量是否用尽，可以把链接放进浏览器看是否有内容返回。链接本身正常却仍为空时，再检查是否导入后忘了把这份配置设为当前使用的配置。
  - q: 系统代理和 TUN 模式先开哪个？
    a: 先开系统代理。它设置简单，浏览器等遵守系统代理的应用就能用。只有发现某些应用不走代理，比如部分游戏、命令行工具，才需要考虑 TUN。两者不建议同时开，出问题时更难判断是哪一层的原因，先单独用一种验证。
  - q: 退出 Clash Verge Rev 之后电脑上不了网怎么办？
    a: 多半是系统代理开关没有随退出被清除，Windows 仍在把流量发往一个已经没人监听的本地端口。重新打开客户端关闭系统代理，或在 Windows 代理设置里手动把代理开关关掉，网络就会恢复。以后退出前先关闭系统代理开关。
  - q: 一个订阅能同时在几台电脑上使用？
    a: 取决于机场套餐对设备数量的限制，客户端本身没有限制。同一个订阅链接导入多台设备并不违反客户端规则，但可能超出套餐允许的同时在线设备数，具体以你购买的套餐说明为准，超出时通常的表现是部分设备被限速或断开。

这篇 Clash Verge Rev 教程只做一件事：让一台 Windows 电脑从零开始，走到“浏览器能正常访问需要代理的网站”。顺序是准备、安装、导入订阅、选节点与模式、打开系统代理、验证，最后列出常见卡点。客户端的版本号和官方地址见页面顶部的数据卡，正文不写具体版本，界面文字以你电脑上的当前版本为准。

## 开始前：这份 Clash Verge Rev 教程需要你准备什么

动手前先确认下面几项，缺哪一项就先补哪一项：

| 准备项 | 要求 | 怎么确认 |
| --- | --- | --- |
| 机场订阅 | 套餐提供 Clash 格式的订阅链接 | 到机场后台找订阅链接，看格式说明；判断方法见 [Clash 机场怎么选](/zhinan/clash-jichang/) |
| Windows 系统 | Windows 10 或 11 | 按 Win 加 I 打开设置，在系统关于页查看 |
| 处理器架构 | 多数是 x64，少数是 ARM | 同一个关于页的“系统类型” |
| 其他代理软件 | 先退出或关闭系统代理 | 同时开两个会争抢系统代理设置，容易互相覆盖 |
| 网络 | 能正常访问发布页下载安装包 | 打不开发布页时先排查网络本身 |

订阅链接是你的账号凭证，不要发给别人，也不要贴到公开的群和工单里。万一已经贴到了公开的地方，补救办法写在 [订阅链接泄露了怎么办](/bikeng/dingyue-xielou/)。

## 安装：从官方发布页选对安装包

下载只走官方发布页：[github.com/clash-verge-rev/clash-verge-rev/releases](https://github.com/clash-verge-rev/clash-verge-rev/releases)。客户端本身的介绍、校验方法和同类对比，见 [Clash Verge Rev 下载](/xiazai/clash-verge-rev/) 页，这里只讲安装操作。

1. 在发布页确认条目标着 Latest，不是 Pre-release。
2. 在 Assets 里找 Windows 对应的文件，文件名里会标明 x64 或 arm64，与上一节查到的架构一致。
3. 安装程序和免安装压缩包两种形态，是否都提供以发布页为准。想长期使用，选安装程序；只想临时试用，可以选免安装形态，解压到一个固定的文件夹再运行。
4. 运行安装程序。如果出现“Windows 已保护你的电脑”的提示，先回头确认下载来源是官方发布页，来源无误再选择“更多信息”后继续运行。
5. 安装后首次启动。Windows 防火墙可能询问是否允许访问网络，选择允许；界面依赖系统的网页渲染组件，安装程序提示补装时按提示处理，以实际提示为准。

打开后看到英文界面时，到设置里找语言选项切换，不需要另找汉化版。

## Clash Verge Rev 怎么用：导入订阅并启用配置

客户端不带节点，节点全部来自你的订阅。这一步是整个流程里最关键的一步。

### 第一步：找到订阅管理页

在左侧导航里找名为“订阅”或“配置”的页面（英文版常见叫法是 Profiles），点进去，页面上会有一个输入框，用来粘贴订阅地址。

### 第二步：粘贴并导入

把机场后台复制的 Clash 订阅链接粘贴进输入框，示例格式如下，请替换为你自己的链接：

`https://example.com/你的订阅链接`

点击“导入”或类似按钮。稍等片刻，订阅页会多出一张卡片，标题、最近一次更新的时间，以及机场附带的用量信息（有的话）都写在上面。

### 第三步：选中这张卡片

导入成功不等于正在使用。点一下刚导入的配置卡片，让它进入选中或高亮状态，这才是“当前使用的配置”。很多人在这里漏掉，结果代理页一个节点也没有。

### 第四步：确认节点已经出现

回到“代理”页面（英文版常见叫法是 Proxies），应当能看到策略组和下面的一串节点。看到了，说明订阅解析成功。没有节点时，先看后面的“常见卡点”一节。

### 第五步：设置自动更新

订阅里的节点会变动，卡片上通常有更新按钮和更新间隔的设置。可以手动点一次更新，间隔设置是否提供、怎么设，以当前版本为准。更新失败时的排查，见 [订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)；各客户端通用的导入原理，见 [订阅链接怎么用](/jiaocheng/dingyue-daoru/)。

## 选节点和模式：规则、全局、直连怎么选

在“代理”页面顶部，一般有一组模式切换：规则、全局、直连。三者区别如下：

| 模式 | 行为 | 什么时候用 |
| --- | --- | --- |
| 规则模式 | 按订阅里的规则分流，国内走直连，其余走代理 | 日常使用，保持这个就行 |
| 全局模式 | 所有流量都走你选中的节点 | 临时排查，或规则没覆盖到某个站点时 |
| 直连模式 | 请求全部绕开节点，效果等同没开代理 | 做对照实验，让网页在无代理的状态下再试一遍 |

日常放在规则模式。各模式的细节，见 [规则、全局、直连怎么选](/jiaocheng/guize-quanju-zhilian/)。

选节点时：

1. 在策略组里点开，会看到“自动选择”“手动选择”之类的组名，组名由订阅决定，不同机场不同。
2. 想自己指定节点，就在手动选择那一组里点选；想省事，就选自动选择或故障转移那一组，策略组的用法见 [策略组怎么用](/jiaocheng/celue-zu/)。
3. 页面上常有一个测延迟的按钮。它显示的是客户端到节点的连通时间，不是实际下载速度，数字怎么看见 [节点测速怎么看](/jiaocheng/jiedian-cesu/)。

## 打开系统代理，还是开 TUN 模式

客户端设置页里一般有“系统代理”和“TUN 模式”两个开关，作用层级不同：

| 对比项 | 系统代理 | TUN 模式 |
| --- | --- | --- |
| 原理 | 修改 Windows 的代理设置，让遵守该设置的应用走代理 | 创建虚拟网卡，接管更多流量 |
| 权限要求 | 一般不需要管理员权限 | 通常需要，客户端可能引导安装服务模式 |
| 能管到的应用 | 浏览器等遵守系统代理的程序 | 包括部分不遵守系统代理的程序 |
| 出问题时 | 容易定位 | 涉及驱动和路由，排查更复杂 |
| 建议 | 先用这个 | 发现有应用绕开代理时再用 |

操作顺序：

1. 先只打开系统代理开关，模式保持规则。
2. 先别急着动别的，浏览器里国内站、境外站各刷一次，看页面能不能正常出来。
3. 确实有应用不走代理，再看 [TUN 模式是什么](/jiaocheng/tun-moshi/)，按里面的条件决定是否开启。

两种方式的完整对比，见 [系统代理怎么设置](/jiaocheng/xitong-daili/)。

## 怎么确认设置真的生效了

别只凭客户端里开关是亮的就判断成功，用三个角度交叉验证：

1. **看 Windows 自己的代理设置。** 在 Windows 设置的“网络和 Internet”里找到“代理”页：手动代理的开关处于打开状态，地址指向本机，端口号和 Clash Verge Rev 里显示的相同，这就是系统代理已经被写入的证据。
2. **用 PowerShell 查注册表。** 想要更精确，可以在 PowerShell 里执行下面这条，ProxyEnable 为 1 表示系统代理开着，ProxyServer 是代理地址：

```
Get-ItemProperty "HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings" | Select-Object ProxyEnable, ProxyServer
```

3. **看客户端的连接页。** 在左侧导航里找“连接”页面，打开一个网页后，列表里会出现对应请求，能看到它走了哪条规则、哪个节点。国内网站应当显示直连，需要代理的网站应当显示某个节点。
4. **做一次对照。** 先切到直连，看境外站点是否加载失败，再切回规则，看它是否恢复。两次结果不同，说明代理确实在起作用。

三项都符合，才算真的生效。

## 常见卡点对照

| 现象 | 常见原因 | 先查什么 | 详细排查 |
| --- | --- | --- | --- |
| 订阅导入报错 | 复制时丢了字符、给的不是 Clash 格式、套餐已到期 | 把链接贴进浏览器地址栏，看有没有内容返回 | [订阅更新失败](/paicha/dingyue-gengxin-shibai/) |
| 所有节点都显示超时 | 电脑自身的网络、系统时钟偏差，或节点整体不可用 | 先看是整组超时，还是只有个别节点超时 | [节点超时](/paicha/jiedian-chaoshi/) |
| 提示端口被占用 | 另一个程序占着同一个端口 | 关掉其他代理软件，或在设置里改端口 | [端口被占用](/paicha/duankou-zhanyong/) |
| TUN 开不了 | 权限、驱动或与其他软件冲突 | 是否装了服务模式并授权 | [TUN 模式开不了](/paicha/tun-moshi-shibai/) |
| 退出后上不了网 | 系统代理残留 | 先关系统代理开关，再退出 | [关掉梯子后上不了网](/paicha/guan-tizi-meiwang/) |
| 个别应用不走代理 | 该应用绕开了系统代理 | 看连接页里有没有它的请求 | [某个 App 不走代理](/paicha/app-buzou-daili/) |
| 国内网站变慢 | 分流没生效，国内流量绕了出去 | 确认处于规则模式 | [国内网站变慢](/paicha/guonei-wangzhan-man/) |

另外两点单独说：部分微软商店应用默认访问不了本机代理，Windows 有回环豁免的机制，客户端可能提供入口，以当前版本为准；系统时间不对会导致证书类报错，见 [证书与时间](/paicha/zhengshu-shijian/)。
