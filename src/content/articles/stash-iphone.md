Stash 教程可以先抓住一个关键点：它是 iPhone 上最贴近 Clash 使用习惯的应用，订阅被当作一份完整的配置来下载，里面的节点、策略组、规则都由这份配置决定。所以学 Stash 怎么用，重心不是点哪个按钮，而是看懂配置里的策略组。下面从前提说起，依次讲导入、授权、模式、策略组和验证。

## Stash 教程第一步：先说清它是什么，以及和小火箭的区别

想装上 Stash，得先有一个外区 Apple ID：它是付费应用，大陆区商店里搜不到。它不是 Mihomo 内核的移植版，而是对 Clash 配置兼容的自有实现，所以搜索资料时常见“iOS Clash”这个说法来指代这类应用。

| 对比项 | Stash | Shadowrocket（小火箭） |
| --- | --- | --- |
| 配置风格 | 沿用 Clash 风格，订阅是一份完整配置 | 以节点列表加自有配置文件为主 |
| 订阅格式偏好 | Clash 格式 | 通用分享链接格式更常用 |
| 策略组 | 配置里定义，界面里直接操作 | 通过分组与规则文件实现 |
| 是否付费 | 付费，价格以 App Store 页面为准 | 付费，价格以 App Store 页面为准 |
| 适合谁 | 订阅是 Clash 格式、想用策略组分流的人 | 订阅是通用格式、想要界面简单的人 |

这张表概括的是定位，不是优劣。小火箭那边的步骤见[小火箭使用教程](/jiaocheng/shadowrocket-iphone/)。Stash 也有 Mac 版本，本文只讲 iPhone，Mac 版的获取方式以 App Store 页面为准。

对 Clash 本身还不熟悉的话，先读[Clash 是什么](/zhinan/clash-shi-shenme/)，了解为什么今天说的 Clash 多指 Mihomo 内核和兼容它的客户端。

## 准备：外区 Apple ID 与 Clash 格式订阅

动手前确认三件事：

1. **账号。** 外区 Apple ID 怎么注册、怎么切换，单独写在[外区 Apple ID 怎么准备](/jiaocheng/waiqu-apple-id/)里，这里不重复。选梯子不教购买共享账号，也不推荐使用，来源不明的账号随时可能出问题。
2. **应用。** 在 App Store 里打开[Stash 的官方页面](https://apps.apple.com/us/app/stash-rule-based-proxy/id1596063349)，价格以该页面为准，本文不写金额。页面顶部数据卡显示的官方地址与下载说明，也可对照[Stash 下载页](/xiazai/stash/)。
3. **订阅。** 在机场后台选 Clash 格式的订阅地址，形如 `https://example.com/你的订阅链接`。有的机场面板还提供专门的 Stash 选项，有就优先选它。通用的订阅概念见[订阅链接怎么用](/jiaocheng/dingyue-daoru/)。

订阅链接等同账号凭证，不要发到群里，也不要贴进任何在线转换工具。

## Stash 配置怎么导入：订阅就是一份完整配置

Stash 里的“配置”就是一份 Clash 风格的文件。机场的订阅地址返回的内容，通常包含三块：

| 配置段落 | 里面是什么 | 在界面里对应哪里 |
| --- | --- | --- |
| 节点列表 | 机场提供的全部节点 | 代理或节点页面 |
| 策略组 | 把节点编成组，决定怎么选 | 代理页里的各个组 |
| 规则 | 哪些域名、地址走哪个组或直连 | 规则页面，通常只读查看 |

按下面的顺序把订阅装进 Stash，按钮叫什么以实际界面为准。

1. 打开应用，进入与配置相关的页面（常见叫法“配置”）。
2. 选择从链接下载配置。
3. 粘贴 `https://example.com/你的订阅链接`，给配置起个名字，确认下载。
4. 下载完成后列表里多出这份配置，点它，把 Stash 的当前配置切换过去。
5. 想刷新节点，在这份配置的详情里选更新。较新版本通常提供自动更新选项。

除了链接，通常还可以通过本地文件导入配置，适合别人给你发来的配置文件。文件方式的内容不会随机场变化，需要你自己维护。

这里有一个要提防的地方。机场给的 Clash 配置往往面向 Mihomo 内核编写，其中可能带有 Stash 不支持的字段或较新的协议。表现为下载时报错，或者个别节点和规则不生效。遇到这种情况，不要急着换客户端，先向机场确认有没有适合 Stash 的选项，再看官方说明里列出的兼容范围。订阅更新出问题的常见原因，见[订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)。

## 首次连接与出站模式

配置选好以后，回到首页，点连接开关。系统会弹出窗口，大意是应用想添加 VPN 配置，这是 iOS 的网络扩展机制，应用要建立隧道必须得到许可。同意之后 iOS 还会核实是不是本人在操作，用锁屏密码或面容、指纹确认即可。成功后开关打开，状态栏出现 VPN 标记。

点连接毫无动静，或者授权完马上又断开，常见原因是系统里残留着旧的 VPN 配置，或者另一个代理类应用抢先占着通道。先退出别的应用，再去系统设置的 VPN 与设备管理里清掉旧配置，然后重新连接。

连接之后，首页或代理页里能切换“出站模式”（常见叫法）。它与 Clash 的三种模式一一对应：

| 出站模式 | 流量怎么走 | 什么时候用 |
| --- | --- | --- |
| 规则 | 自上而下匹配配置里的规则，先命中的决定出口 | 平时一直放在这个模式 |
| 全局 | 不再看规则，一切流量交给同一个出口 | 用来判断问题出在规则还是节点 |
| 直连 | 所有流量不走代理 | 判断问题是否由代理造成 |

三种模式的取舍见[规则、全局、直连模式怎么选](/jiaocheng/guize-quanju-zhilian/)。第一次用，保持规则模式。

## 策略组怎么用：选择、自动测速与故障转移

策略组是 Stash 的核心。它把一批节点编成一个组，规则命中后，流量交给某个组，再由组决定走哪个节点。常见的组类型有四种。

| 类型 | 行为 | 你要做什么 |
| --- | --- | --- |
| 手动选择 | 由你点一个节点或另一个组作为出口 | 点选 |
| 自动测速 | 定期测试组内节点，选延迟最低的 | 一般不用操作 |
| 故障转移 | 按顺序使用，当前节点不通才换下一个 | 一般不用操作 |
| 负载均衡 | 在多个节点之间分摊连接 | 一般不用操作 |

下面是一段虚拟的配置片段，节点名纯属举例，用来展示组是怎么嵌套的：

```
proxy-groups:
  - name: 节点选择
    type: select
    proxies: [自动测速, 故障转移, 节点甲, 节点乙]
  - name: 自动测速
    type: url-test
    proxies: [节点甲, 节点乙]
    url: https://example.com/测试地址
    interval: 300
  - name: 故障转移
    type: fallback
    proxies: [节点甲, 节点乙]
    url: https://example.com/测试地址
    interval: 300
```

看这段配置可以读出几件事：

- 手动选择组“节点选择”里，既可以点具体节点，也可以点另外两个组，组可以嵌套。
- 自动测速组靠一个测试地址和时间间隔去探测节点，选出的是“测试地址上延迟最低”的节点，不等于访问你真正要用的网站时延迟也是最低。
- 故障转移组只在当前节点探测失败时才换，所以它适合做“保底”，不适合追求低延迟。

实际操作时，在代理页找到规则最终指向的那个主组（名称常见为“节点选择”之类），点其中一个选项。想让某类流量走单独的出口，例如把 AI 工具固定到某个地区，需要配置里有对应的组，并且规则把这类域名指向它。策略组的原理和更多用法见[策略组怎么用](/jiaocheng/celue-zu/)。

## 规则与自定义：订阅更新会覆盖你的手动修改

规则由配置里的规则段决定，写法和命中顺序见[分流规则怎么写](/jiaocheng/fenliu-guize/)。在 Stash 里，有两点需要特别注意。

1. **直接改订阅下载来的配置，更新时可能被覆盖。** 订阅更新会用远端内容替换本地文件，手改的内容随之丢失。
2. **想长期保留自己的修改，应该找订阅之外的办法。** Stash 较新的版本提供类似覆写的功能，用来在不动订阅文件的前提下追加规则或调整字段，是否可用以及写法以官方说明为准。

自定义之前，先想清楚是否真的需要。多数人用机场提供的规则就够用，贸然改动反而容易引入问题，例如规则顺序错了导致国内网站被送进代理。

## 验证生效与常见卡点

不要只看开关亮了，按下面的顺序核对：

1. **看状态栏。** 有 VPN 标记，说明系统隧道已建立。
2. **看当前组与节点。** 回到代理页，确认主组里选中的是你要的节点，而不是一个已超时的节点。
3. **对比出口 IP。** 在手机浏览器里查一次出口 IP，连接前后各一回，地址有变化才证明 Stash 的隧道确实在转发流量。
4. **切模式对比。** 出站模式切到直连，国外网站应打不开；切回规则，恢复正常。
5. **看请求记录。** Stash 若带有连接或请求记录页，随手打开一个网站再翻记录，能直接看到命中的规则以及最终落在哪个组。
6. **关掉再看。** 关掉 Stash 之后国外网站依旧能开的话，要去查是不是还有别的代理工具在运行。

卡点汇总：

| 症状 | 常见原因 | 先试什么 |
| --- | --- | --- |
| 配置下载失败或格式错误 | 链接错误或过期、含不兼容字段 | 浏览器打开订阅地址，向机场确认适配选项 |
| 点开关没有弹窗 | 其他 VPN 占用，或有残留配置 | 断开其他 VPN，删除旧配置后重试 |
| 已连接但网页打不开 | 主组选中的节点超时 | 换节点，见[节点超时怎么办](/paicha/jiedian-chaoshi/) |
| 国内网站变慢 | 出站模式是全局，或规则覆盖不全 | 切回规则模式，检查规则 |
| 自动测速组选出的节点不好用 | 测试地址上的延迟不代表你访问的网站 | 改用手动选择，自己挑 |

iPhone 上的排查顺序同样是先外后内，完整的检查清单放在[梯子连不上怎么办](/paicha/tizi-lianbushang/)。
