用 Claude 的人选梯子，关注点和刷视频的人不一样：带宽不重要，重要的是出口落在哪里，以及登录那几步里出口会不会变。Anthropic 按地区提供服务，中国大陆不在官方支持列表内。下面把选择拆成三件事：地区、登录链路、你用的是网页还是命令行，再给出买前买后的核对方法。

## 三个因素，决定 Claude 能不能用

| 因素 | 为什么重要 | 你能做什么 |
| --- | --- | --- |
| 出口地区 | 平台只看服务器收到的 IP 属于哪里，不在支持地区会直接提示不可用 | 对照官方支持地区页面，选列表内的地区 |
| 登录链路 | 登录要经过“点击登录、收邮件、点开链接”几步，中途出口变了容易被打回 | 把策略组固定到一个节点，同一个浏览器完成整个登录 |
| 使用方式 | 浏览器、手机 App、命令行走代理的方式不同，卡点也不同 | 按下面的表分别检查 |

官方的[支持国家和地区](https://www.anthropic.com/supported-countries)页面会变化，本站不另列名单。在支持地区之外使用，账号可能受到限制，这是平台规则，换节点和换机场都改变不了，也请遵守所在地法律法规。

流量不是问题。文字对话的数据量很小，估算各类用途的消耗可以看[梯子流量](/zhinan/tizi-liuliang/)。

## 地区：先排除，再固定

选地区的顺序是排除法：先去掉官方列表之外的地区，再在剩下的地区里选一个离你近的，并长期使用。同一个账号短时间内出现在几个国家，对多数平台都是异常信号，所以选定之后别来回切换。

两点容易被忽略：

- **节点名不等于出口位置。** 很多线路入口和出口不在同一处，决定地区的是出口，也就是[落地节点](/cidian/luodi/)。连上之后查一次公网 IP 的归属地，比相信节点名可靠。
- **同一地区的节点也有好坏。** 机场节点是很多人共用的，个别出口 IP 会被平台的防护拦住。这类问题和 ChatGPT 是同一类，成因在[ChatGPT 梯子](/changjing/chatgpt/)那篇讲过，这里不重复；对选购的意义是：同地区能换的节点越多，越不容易卡死。IP 的类型也有影响，可以参考[原生 IP](/zhinan/yuansheng-ip/)，但“原生”没有统一标准，别把它当通行证。

各地区节点的一般特点见[节点地区](/zhinan/jiedian-diqu/)。

## 登录链路：固定出口，别让策略组乱换

登录是 Claude 最容易出问题的一步，而且原因常常是出口在中途变了，而不是地区不对。比较稳的做法：

1. 先把客户端的策略组从“自动选择”改成手动固定一个节点。
2. 用同一个浏览器发起登录，并在这个浏览器里点开邮件链接，不要在邮件客户端内置的浏览器里点。
3. 从请求到完成登录，中途不要切换节点，也不要清除 Cookie。
4. 登录之后继续保持同一出口使用一段时间，观察是否仍被要求反复验证。

如果这样做之后仍然反复，再去看[Claude 用不了怎么办](/paicha/claude-yongbuliao/)里逐项排查的方法。

## 网页、手机、命令行：三种用法的卡点

| 用法 | 流量怎么走 | 要注意什么 |
| --- | --- | --- |
| 网页版 | 浏览器，通常跟随系统代理 | 规则模式下确认相关域名走了代理，规则集太旧可能漏域名；临时切全局模式可以快速对照 |
| 手机 App | App 自身，客户端以 VPN 方式接管 | 别被系统省电策略关掉后台；App 能否下载另看应用商店账号的地区 |
| 命令行与桌面程序 | 程序自身，不一定读系统代理 | 单独设置终端代理环境变量，或开启 TUN 模式 |

命令行和桌面程序是最常见的“浏览器能用、程序却超时”的来源，设置方法见[终端代理](/jiaocheng/zhongduan-daili/)和[TUN 模式](/jiaocheng/tun-moshi/)。网页版出现“能打开但登录转圈”时，多半是分流规则，见[Clash 规则模式](/jiaocheng/guize-quanju-zhilian/)。

## 买之前：套餐页上核对四项

选梯子没有任何机场访问 Claude 的测试数据，所以这里只给核对项，不给“哪家能用”的结论。

1. **节点地区和数量**：有没有官方支持列表内的地区，每个地区有几个节点。只有一个节点的，出问题时没有退路。
2. **出口 IP 的说明**：只写“原生 IP”一句口号的，按没有处理；写明哪些节点、怎么核对的，才有参考价值。
3. **周期**：能月付或有试用的优先，别第一次就买长周期。
4. **倍率和流量**：Claude 耗流量很少，小流量足够，但要看清你常用的节点倍率。

“支持 Claude”“解锁 AI”这类标注是商家自述，可以用来筛选，不能当作结论。如果还同时用别的 AI 工具，可以对照[ChatGPT 梯子](/changjing/chatgpt/)和[Gemini 梯子](/changjing/gemini/)，挑一个几家官方都支持的地区。

## 买之后：用五步自己验证

1. 连上打算长期用的节点，查一次公网 IP 的归属地，记下国家或地区。
2. 确认这个地区在 Anthropic 官方列表里；不同 IP 库的归属可能不一致，矛盾时以平台实际表现为准。
3. 固定节点，完整走一遍：请求登录、点开邮件链接、发几条消息。只能打开首页不算通过。
4. 让它写一段较长的内容，看流式输出是否中途停住；经常中断说明线路不稳，不是地区问题。
5. 同地区换一个节点重复第 3 步：一个行一个不行，问题在出口；都不行，再查地区和分流。打不开时先看一眼[Claude 状态页](https://status.anthropic.com/)，官方故障时换节点没用。

做完这五步，你对这家机场适不适合自己用 Claude 的判断，比任何推荐文章都更有依据。

## 下一步

- **只在网页上聊天**：小流量、可月付，重点看支持地区内的节点数量，可以从[机场推荐](/tuijian/)按地区字段筛选。
- **还没想好预算和设备数**：先用[选梯子向导](/gongju/xuan-tizi-xiangdao/)定下配置。
- **要在终端里用命令行工具**：先把终端代理或 TUN 配好，再测线路。
- **已经买了但打不开**：直接按排查文章的顺序查，不要先急着换机场。
