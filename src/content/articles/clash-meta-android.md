Clash Meta for Android 教程的核心只有一件事：在“配置”里新建一份 URL 类型的配置，把机场的 Clash 格式订阅填进去，再回到主页启动。这个应用常被简称为 CMFA，是基于 Mihomo 内核的安卓 Clash 客户端，界面朴素，功能集中在配置、代理、设置三块。下面按准备、导入、选节点、分应用、验证的顺序走完一遍。

## Clash Meta for Android 教程之前：先判断它适不适合你

CMFA 的特点是简单直接：没有花哨的页面，配置、代理、设置三个入口就能完成日常使用。是否选它，可以对照下表。

| 你的情况 | 判断 |
| --- | --- |
| 机场提供 Clash 格式的订阅 | 适合，这是它直接支持的格式 |
| 订阅只有通用分享链接格式 | 不太适合，建议改用能解析该格式的客户端，或向机场要 Clash 格式的地址 |
| 想要手机和电脑用同一套界面 | 可以看[FlClash 使用教程](/jiaocheng/flclash-android/)里的跨平台思路 |
| 在意项目是否持续更新 | 先去官方仓库看最近的提交与问题讨论，再决定 |

最后一行值得多说一句。开源客户端的维护状态会变化，选梯子无法替你预测它还能用多久。安装之前打开[官方仓库](https://github.com/MetaCubeX/ClashMetaForAndroid)，看一眼发布页和问题区的活跃程度，是个低成本的好习惯。页面顶部的数据卡也会显示它的版本和官方地址。

名字里的 Meta 指的就是 Mihomo 内核，这也解释了为什么这篇教程里 Clash、Meta、Mihomo 三个词会混着出现；它们之间的来龙去脉见[Clash 是什么](/zhinan/clash-shi-shenme/)。

## 安卓 Clash 怎么用：装好应用，备好订阅

安装包放在官方仓库的发布页，对应的下载说明见[Clash Meta for Android 下载页](/xiazai/clash-meta-for-android/)。安装前后留意这几件事：

1. **看文件名里的架构标记。** 近几年的手机多数是 64 位 ARM，选对应的包；不确定时，以发布页的说明为准。
2. **临时放行安装来源。** 安装时系统会提示当前应用无权安装未知应用，去设置里只对打开 apk 的那一个浏览器或文件管理器放行，用完立刻收回。
3. **不要装来路不明的“修改版”。** 原因见[破解版梯子软件能用吗](/bikeng/pojie-kehuduan/)。
4. **HarmonyOS NEXT 要先确认兼容性。** 它不直接兼容安卓 APK，参考[鸿蒙梯子下载](/xiazai/hongmeng/)。
5. **备好订阅链接。** 形如 `https://example.com/你的订阅链接`，在机场后台选 Clash 或 Mihomo 对应的那一项。通用的导入概念见[订阅链接怎么用](/jiaocheng/dingyue-daoru/)。

订阅链接等同账号凭证，复制时不要多带空格，也不要把含有它的截图发到群里。

## 新建配置：用 URL 导入订阅，并设好自动更新间隔

CMFA 里的“配置”就是一份完整的 Clash 配置，包含节点、策略组和规则。订阅导入，就是新建一份来源为 URL 的配置。

1. 打开应用，进入“配置”页（常见叫法），点右上角或底部的加号，选择“新配置”一类的入口。
2. 在类型里选 URL。除此之外一般还有从文件导入等选项，名称以当前版本界面为准。
3. 填写名称，粘贴订阅地址 `https://example.com/你的订阅链接`。
4. 填自动更新间隔，单位通常是分钟。不填或填零是否表示不自动更新，以界面的提示为准。
5. 点保存，应用开始下载配置。成功后列表里多出一项；只有轻点它、把它设为当前配置，代理页才会读到里面的策略组和节点。
6. 想手动刷新时，在这份配置的菜单里选更新。

自动更新间隔不是越短越好。节点信息通常不会分钟级变化，间隔过短只会增加机场服务器的压力和手机的耗电，设在几小时到一天之间已经够用。

另外要知道一个特性：URL 类型的配置每次更新都会用远端内容覆盖本地。你在编辑页里手动改过的内容，更新之后可能就丢了。所以不要在这类配置里手写关键内容，后面会讲更合适的做法。更新失败的常见原因，见[订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)。

## 代理页：策略组、节点和模式

配置生效后，回到主页点启动。第一次点启动，会跳出一个连接请求窗口，窗口里写的应用名应当是 Clash Meta，核对无误再点“确定”；不点的话，流量不会被接管。状态栏出现钥匙或 VPN 图标，说明服务起来了。

然后进入“代理”页。页面上方通常是一排策略组标签，点开某个标签，下面显示这个组里的节点。

| 策略组类型 | 行为 | 你要做什么 |
| --- | --- | --- |
| 手动选择 | 由你点一个节点作为出口 | 点选节点 |
| 自动测速选择 | 按延迟测试结果自动挑 | 一般不用操作 |
| 故障转移 | 当前节点不通时切换到下一个 | 一般不用操作 |
| 负载均衡 | 在多个节点之间分摊 | 一般不用操作 |

组的名称和数量由机场的配置决定。日常使用最多的是手动选择那一组，选定一个延迟数字正常的节点即可。各类型的含义见[策略组怎么用](/jiaocheng/celue-zu/)。

代理页上带有测延迟的按钮，点一下，各节点后面会出现数字。这些数字怎么读、哪些结论不能下，见[节点测速怎么看](/jiaocheng/jiedian-cesu/)。代理模式（规则、全局、直连）的切换入口通常在代理页或菜单里，位置以当前版本为准。三种模式的取舍见[Clash 规则、全局、直连模式怎么选](/jiaocheng/guize-quanju-zhilian/)。第一次用，保持规则模式。

## 访问控制：哪些应用走代理

访问控制一般放在“设置”下的网络相关选项里，常见叫法是“访问控制模式”。有三种选择：

| 模式 | 含义 | 适合 |
| --- | --- | --- |
| 允许所有应用 | 所有应用的流量都进入代理 | 默认值，省事 |
| 仅允许选中的应用 | 只有勾选的应用走代理 | 只想让浏览器、聊天工具等少数应用走梯子 |
| 不允许选中的应用 | 勾选的应用绕过代理 | 想把银行、支付、政务类应用排除 |

访问控制按应用整体生效，不管应用里访问的是国内还是国外网站。对 IP 变化敏感的国内应用，用最后一种模式把它们排除最省心。如果某个网站要分别对待，需要靠规则而不是访问控制。

设置页里还有几个网络选项，例如是否处理 IPv6、是否绕过私有网络等。这几项对日常使用影响不大，先放着不动；真要改，也一次只改一项，改完立刻测一下。

## 规则从哪来：它由配置决定，不由客户端决定

规则模式下，每个请求走代理还是直连，是配置里的规则一条条匹配出来的。这些规则来自订阅，而不是来自客户端。这有两个后果：

- 国内外分流是否正确，取决于机场提供的配置。国内网站走了代理变慢，问题多半在规则覆盖不全，而不是应用坏了。
- 想追加自己的规则，不能直接去改 URL 配置，因为更新会覆盖。可以看设置里是否提供覆写之类的功能，它常用来在不改订阅的前提下调整少数全局项，具体有哪些以界面为准。

如果你需要频繁维护自己的规则，建议先读[分流规则怎么写](/jiaocheng/fenliu-guize/)了解语法，再考虑能在订阅之外叠加规则的客户端，例如桌面端的 [Clash Party](/jiaocheng/clash-party-jiaocheng/)，它的覆写功能正是为这种需求设计的。

## 验证生效与常见卡点

按下面的顺序核对，比只看按钮是否变色可靠。

1. **看状态。** 状态栏有 VPN 图标，通知栏有应用的常驻通知。
2. **看主页流量。** 打开网页时，主页上的流量数字应当有变化。
3. **对比出口 IP。** 随便找一个能显示出口 IP 的网页，应用启动时记下地址，停止后刷新再看，前后不一样才说明流量确实经过了节点。
4. **验证访问控制。** 被勾选的应用应当表现出对应的网络环境，被排除的应用则保持原有环境。
5. **切模式对比。** 切到直连模式，国外网站应当打不开；切回规则模式，恢复正常。
6. **停止后复查。** 点停止再试一遍国外网站。要是依旧打得开，手机上就还有别的代理或 VPN 在接管流量，得先把它找出来。

常见卡点：

| 症状 | 常见原因 | 先试什么 |
| --- | --- | --- |
| 配置下载失败 | 订阅链接错误或过期、订阅域名打不开 | 用浏览器直接打开订阅地址 |
| 节点列表为空 | 订阅格式不是 Clash 格式 | 向机场要 Clash 格式的地址 |
| 点启动无反应 | 其他 VPN 类应用占用通道 | 断开其他 VPN，重启应用 |
| 已连接但打不开网页 | 节点超时、系统时间不准 | 换节点，校准时间，见[节点超时怎么办](/paicha/jiedian-chaoshi/) |
| 某个应用不走代理 | 访问控制没勾选，或应用自带网络设置 | 检查访问控制，见[某个 App 不走代理](/paicha/app-buzou-daili/) |
| 熄屏后断开 | 系统的省电策略停掉了后台应用 | 把电池使用设为不限制，允许后台运行 |

表里的办法都试过仍不行，问题就可能不在 CMFA 本身，换到[梯子连不上怎么办](/paicha/tizi-lianbushang/)里，从网络、订阅到节点逐层排除。

## 下一步：先跑通最小流程，再碰访问控制

- **刚开始用：** 照这篇 Clash Meta for Android 教程，先只做“新建配置、启动、选节点、验证出口 IP”，通了再设置自动更新和访问控制。
- **订阅不是 Clash 格式：** 与其折腾转换，不如换一个能解析的客户端，或者向机场要对应格式的地址。
- **还在比较客户端：** 到[客户端选择](/gongju/kehuduan-xuanze/)按系统和需求筛，或者看[安卓梯子下载](/xiazai/android/)里的对照。
- **还没有机场：** 从[机场推荐](/tuijian/)开始，买之前确认套餐提供 Clash 格式订阅，并先用月付试几天。
