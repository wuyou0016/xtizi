faqs:
  - q: 订阅链接和节点链接是一回事吗？
    a: 不是。节点链接是单个节点的分享地址，通常以协议名开头，只描述一个节点。订阅链接是一个网址，访问它会返回一批节点，甚至带上策略组和规则，并且内容会随套餐变化而更新。日常导入用的是订阅链接，单个节点链接一般只在临时添加某个节点时使用。
  - q: 订阅导入后一个节点都没有，是什么原因？
    a: 常见原因有四个：复制的不是订阅地址而是官网首页，地址被截断或带了空格，套餐已过期或流量用尽导致返回为空，以及客户端读不懂这份订阅的格式。先在浏览器里确认地址能返回内容，再检查格式是否与客户端匹配，仍不行就看订阅更新失败的排查文章。
  - q: 一个订阅链接可以同时放在几台设备上？
    a: 技术上同一个地址可以导入多台设备，但机场通常对同时在线的设备数有限制，超出可能被限制或封号。具体数量和规则以套餐页和服务条款为准。不要把自己的订阅地址分享给他人，一旦外泄，别人用掉的流量会记在你的账号上。
  - q: 订阅地址需要定期更新吗？
    a: 需要。节点会增减或更换，客户端只有重新拉取订阅才能同步。多数客户端提供自动更新间隔，也可以手动点击更新。如果发现昨天还能用的节点今天全部超时，先手动更新一次订阅再排查，这是成本最低的第一步。
  - q: 订阅链接泄露了怎么办？
    a: 先到机场面板里重置订阅，让旧令牌失效，再把新地址重新导入自己的设备。重置之后旧地址就取不到节点列表了。同时回想一下这个地址曾经发到过哪里，比如聊天记录、截图、第三方网站，避免同样的错误再次发生。

订阅链接怎么用？先给结论：在机场面板里复制那串订阅地址，粘贴到客户端的导入订阅入口，点击更新，节点列表就会出现在客户端里。这串地址本质上是一个带身份令牌的网址，客户端会定期访问它，拉取你账号名下最新的节点和规则。本文不绑定某一款客户端，讲的是各家通用的做法，以及导入之后该做什么。

## 订阅链接是什么：一个带令牌的网址

订阅链接，也常被叫作订阅地址，是机场为每个账号生成的一个网址。网址里带有只属于你的令牌，服务器靠它认出“这是谁的请求”，再返回这个账号当前可用的节点列表。

理解这一点，能解释三件常见的事：

- **节点不是写死在客户端里的。** 客户端保存的只是网址，节点列表每次更新时才重新下载。机场增减、替换节点，你点一次更新就能同步。
- **订阅地址不等于节点本身。** 它是取节点的钥匙，谁拿到这把钥匙，谁就能取到你的节点列表。
- **订阅会过期或失效。** 套餐到期、流量用尽，或者你在面板里重置了令牌，旧地址返回的内容就会变化，甚至变成空的。

如果你对“节点”“订阅”这些词本身还不熟，先看词典里的[订阅链接](/cidian/dingyue/)，以及[机场是什么意思](/zhinan/jichang-shi-shenme/)。

## 订阅地址在机场面板的哪里复制

面板的外观每家不同，入口常见的叫法有“订阅”“一键订阅”“复制订阅链接”“我的订阅”，具体名称以你所用的面板为准。一般的复制步骤是：

1. 登录机场的用户面板，进入首页或与订阅相关的页面。
2. 找到订阅地址或复制按钮。有的面板会按客户端类型给出多个按钮，选和你客户端对应的那一个。
3. 点击复制，先粘贴到一个临时的文本位置，确认它是以 `https://` 开头的完整网址，中间没有换行和多余的空格。
4. 不要自己修改网址里的任何字符，尤其是令牌部分。

复制时最常见的三个错误：复制了机场官网的首页地址而不是订阅地址；复制到一半被截断；粘贴时带进了首尾的空格或换行。导入失败时，先从这三项查起。

## 机场订阅有哪几类格式，客户端认哪一种

同样叫订阅，服务器返回的内容格式并不一样，客户端能不能读，取决于它认哪一种。

| 格式 | 返回的内容 | 常见的读取方 | 特点 |
| --- | --- | --- | --- |
| Clash / mihomo 配置（YAML） | 带节点、策略组、规则三块内容的整份配置 | Clash 系客户端 | 分流逻辑跟着订阅走，导入后就能按机场写好的规则用 |
| 通用订阅（base64 编码的链接列表） | 一批节点分享链接编码后的文本，只有节点，没有分流规则 | v2rayN、v2rayNG、Shadowrocket 等 | 分流规则需要在客户端里另外配置 |
| sing-box 配置（JSON） | sing-box 自己的配置文件 | sing-box 官方客户端等 | 格式要求严格，不是每个面板都提供 |

很多面板允许你按客户端类型选格式，有的通过不同的复制按钮，有的通过链接里的参数区分，写法因面板而异，以面板自己的说明为准。

想知道手里的地址返回的是哪一类，可以在自己电脑的浏览器里打开它。开头是 `proxies:` 之类的字段，就是 Clash 配置；是一长串看不出含义的字符，多半是 base64 通用订阅。看完不要把页面内容截图外发。

格式和客户端对不上时怎么办，见[订阅转换是什么](/jiaocheng/dingyue-zhuanhuan/)。注意先读那篇里的风险提示，再决定要不要动手。

## 各类客户端的导入入口在哪里

下表按功能描述入口位置，菜单名称会随版本变化，以你当前版本的界面为准。能读哪些格式，也以各客户端的文档为准。

| 客户端 | 一般能读的格式 | 导入入口的位置 |
| --- | --- | --- |
| Clash Verge Rev、Clash Party、Clash Nyanpasu | Clash / mihomo 配置 | 订阅或配置页面里的导入输入框，粘贴地址后确认 |
| FlClash | Clash / mihomo 配置 | 配置页里的添加按钮，选择通过链接导入 |
| ClashX Meta | Clash / mihomo 配置 | macOS 菜单栏图标里的配置菜单，远程或托管配置一类的入口 |
| Clash Meta for Android | Clash / mihomo 配置 | 配置页新建配置，选择从 URL 导入 |
| v2rayN | 通用订阅 | 订阅分组相关菜单里添加订阅，填入地址后更新订阅 |
| v2rayNG | 通用订阅 | 侧边菜单进入订阅分组设置新增一组，地址填好后手动更新一次 |
| NekoBox for Android | 通用订阅等 | 订阅或分组页面里的添加入口 |
| Hiddify、Karing | 可自动识别多种格式，范围以各自文档为准 | 首页的添加配置或添加订阅入口 |
| sing-box 官方客户端 | sing-box 配置 | 配置页里新建远程配置 |
| Shadowrocket | 通用订阅，其余格式以说明为准 | 首页右上角添加，类型选订阅 |
| Stash | Clash 配置 | 配置页里从链接下载配置 |
| OpenClash | Clash 配置 | 路由器后台插件的配置订阅页，添加订阅地址 |
| Mihomo 内核（命令行） | Clash / mihomo 配置 | 手写配置文件，用 proxy-providers 引用订阅 |

表里的 Shadowrocket 和 Stash 都要在外区 App Store 付费获取，账号怎么备，看[外区 Apple ID 怎么准备](/jiaocheng/waiqu-apple-id/)。

直接使用内核的读者，可以在配置文件里用订阅源的写法引用订阅。引用订阅的片段长这样，只表现结构，字段的含义去 [Mihomo 官方文档](https://wiki.metacubex.one/) 里查：

```yaml
proxy-providers:
  my-sub:
    type: http
    url: "https://sub.example.com/你的订阅路径"
    interval: 3600
    path: ./providers/my-sub.yaml
```

想按具体客户端一步步操作，可以看站内的 [Clash Verge Rev 使用教程](/jiaocheng/clash-verge-rev-windows/)、[v2rayN 使用教程](/jiaocheng/v2rayn-windows/)、[v2rayNG 使用教程](/jiaocheng/v2rayng-android/)和[小火箭使用教程](/jiaocheng/shadowrocket-iphone/)。还没有客户端的话，先到[下载中心](/xiazai/)按系统挑一个。

## 导入之后要做的三件事

订阅链接怎么用，不只是粘贴导入这一步，导入成功也不等于可以用了。按下面的顺序做三件事，后面少走很多弯路：

1. **先更新一次订阅。** 让客户端拉到最新的节点和规则。再顺手打开自动更新的选项，具体间隔以你的使用习惯为准，不必太频繁。
2. **测一遍延迟。** 用客户端自带的测试功能，把节点排个先后。延迟数字代表什么、不代表什么，见[节点测速怎么看](/jiaocheng/jiedian-cesu/)。
3. **选好模式再开代理。** 日常用规则模式，选法见[Clash 规则模式、全局模式、直连模式怎么选](/jiaocheng/guize-quanju-zhilian/)；接管流量的方式是系统代理还是 TUN，见[系统代理怎么设置](/jiaocheng/xitong-daili/)。

如果你拿到的是通用订阅，只有节点没有规则，第三步要多做一点：在客户端的路由或分流设置里，选一个适合自己的方案，让国内网站直连。

## 怎么确认订阅真的导入成功了

不要只看“导入成功”的提示，自己核对四项：

1. **节点数量。** 客户端里的节点数大致应该和面板里写的一致。数量明显偏少，可能是格式里有客户端不认的协议被跳过了。
2. **更新时间。** 配置列表里一般会显示上次更新时间，点更新后这个时间应当变化。
3. **流量和到期信息。** 部分客户端能显示剩余流量和到期时间，这些信息由服务器随订阅返回。显示不出来不代表出错，不同客户端支持不同。
4. **真实连接。** 选一个节点，打开代理，访问一个需要代理才能访问的网页。能打开才算通。

出现问题时，对照下表缩小范围：

| 现象 | 常见原因 | 先做什么 |
| --- | --- | --- |
| 导入时直接报错 | 地址不完整、格式客户端不认 | 重新复制，并确认格式类别 |
| 导入成功但没有节点 | 套餐过期、流量用尽或令牌已重置 | 登录面板核对套餐状态 |
| 节点比面板里少 | 部分协议客户端不支持 | 换支持更多协议的客户端或格式 |
| 之前能用，现在更新失败 | 订阅域名打不开、令牌失效 | 见[订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/) |

## 订阅链接怎么用才稳妥：地址等于账号钥匙，保管与多设备使用

订阅地址里的令牌，作用相当于账号密码。拿到它的人不需要登录，就能取到你的节点列表，用掉你的流量。所以日常要守住几条：

- 不要把订阅地址发在群里、论坛、截图或公开的笔记里。
- 不要把它粘贴进来路不明的网页或在线工具，转换格式时尤其要小心，原因见[订阅转换是什么](/jiaocheng/dingyue-zhuanhuan/)。
- 多台设备可以导入同一个地址，但要留意套餐对同时在线设备数的限制，见[梯子能几台设备同时用](/zhinan/duo-shebei/)。
- 怀疑地址外泄时，第一反应是去面板重置订阅令牌，随后只在自己的设备上换用新地址，完整流程在[订阅链接泄露了怎么办](/bikeng/dingyue-xielou/)。

1. 已经有订阅：照上面的表格找到你客户端的导入入口，导入后依次做更新、测延迟、选模式，再按[系统代理怎么设置](/jiaocheng/xitong-daili/)打开代理。
2. 导入失败：先按“确认导入成功”一节逐项核对，再看[订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)。
3. 还没有订阅：先到[梯子推荐](/tuijian/)按用途筛选候选，或用[机场目录](/jichang/)对照套餐，下单前自己核对退款和设备数规则。
4. 客户端还没装：到[下载中心](/xiazai/)按自己的系统挑一款，安装包只取官方仓库或应用商店里的那一份。
