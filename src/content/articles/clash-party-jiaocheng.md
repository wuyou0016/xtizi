Clash Party 教程要抓住三个概念：订阅是节点和规则的来源，覆写是你自己的修改层，内核决定实际干活的程序。Clash Party 就是原来的 Mihomo Party，基于 Mihomo 内核，以 Windows 为主，也提供 macOS 和 Linux 版本。多数人只需要导入订阅、选节点、开系统代理，覆写和虚拟网卡留到有需求时再用。

## Clash Party 教程第一步：弄清它和 Mihomo Party 的关系

项目改了名，但内核没变。你搜到的 Mihomo Party 教程，在大方向上依然适用，需要留意的只是菜单位置和名称可能有出入。它和 Clash Verge Rev 同属 Mihomo 内核的桌面客户端，定位相近，各自的界面风格不同，Verge 的用法可以对照[Clash Verge Rev 使用教程（Windows）](/jiaocheng/clash-verge-rev-windows/)。

Clash 这个名字的来历，以及它为什么如今指向 Mihomo 一系，这里不展开，读[Clash 是什么](/zhinan/clash-shi-shenme/)就够了。

| 项目 | 情况 |
| --- | --- |
| 内核 | Mihomo |
| 支持系统 | Windows、macOS、Linux |
| 订阅格式 | Clash 格式 |
| 特色功能 | 订阅管理、覆写、内核切换、虚拟网卡 |
| 本文侧重 | Windows，其他系统在差异处点到 |

## 安装与准备：官方仓库、订阅格式、管理员权限

先备齐三样东西。

| 准备项 | 具体要什么 | 为什么需要 |
| --- | --- | --- |
| 安装包 | [官方仓库](https://github.com/mihomo-party-org/clash-party)发布页的 Windows 安装包，通常有安装版和便携版，以发布页为准 | 避免装到仿冒版本 |
| 订阅链接 | 机场后台里选 Clash 格式的地址，形如 `https://example.com/你的订阅链接` | 节点和规则都来自它，通用概念见[订阅链接怎么用](/jiaocheng/dingyue-daoru/) |
| 管理员权限 | 用于后面的虚拟网卡 | 只开系统代理时不需要 |

安全软件拦下安装版或便携版时，同样只认官方仓库里的文件，来源对上了再放行。Windows 的整体软件对照，可以参考[Windows 梯子下载](/xiazai/windows/)。

第一次打开后，先看一遍主界面的侧边栏。和本文有关的是订阅、覆写、内核设置和连接这几处，名称随版本略有出入。不必每个都点，只要知道它们在哪里就够。

## 订阅管理：导入、更新与切换

1. 进入订阅页（常见叫法“订阅”或“配置”），找到导入入口。
2. 选择通过链接导入，粘贴 `https://example.com/你的订阅链接`，给它起个名字。
3. 订阅会以卡片的形式落在页面上，把它点选为生效的那一份，否则代理页里看不到它的节点。
4. 想刷新节点，在卡片上选更新。多数版本也有自动更新间隔的设置。

订阅卡片上通常能做这几件事，具体以界面为准：

| 操作 | 作用 | 备注 |
| --- | --- | --- |
| 更新 | 重新下载订阅内容 | 失败时见[订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/) |
| 编辑信息 | 改名称、更新间隔等 | 间隔别设得太短 |
| 查看配置 | 查看最终的配置文件 | 排查规则问题时有用 |
| 删除 | 移除这份订阅 | 不影响机场账号 |

两点经验：

- **订阅域名直连打不开时**，有的版本提供“更新订阅时使用代理”之类的选项，可以先用一个已经能用的订阅去拉另一个。是否提供以当前版本为准。
- **可以同时保存多个订阅**，例如主力加备用，随时点选切换。两个订阅同时在线是否受套餐设备数限制，要看套餐规则，见[梯子能几台设备同时用](/zhinan/duo-shebei/)。

## 覆写是什么：不改订阅，也能追加自己的规则

这是 Clash Party 最有价值的功能。先说它解决的问题：订阅下载来的配置是机场生成的，你手动改了其中某几行，下次订阅更新就会被远端内容整个替换，修改全部丢失。覆写是独立于订阅的另一层，每次生成最终配置时，会把你的修改重新叠加上去，所以订阅怎么更新，你的修改都在。

| 你想做的事 | 放在哪里 | 为什么 |
| --- | --- | --- |
| 获取机场提供的节点和规则 | 订阅 | 这是它的本职工作 |
| 某个域名强制直连，或固定走某个组 | 覆写，放在规则的最前面 | 规则按从上到下的顺序命中，放前面才优先 |
| 修改本地端口、DNS 等全局项 | 内核设置页 | 不需要手写 |
| 一次性、临时的改动 | 直接在代理页操作 | 不值得写成覆写 |

举个例子。你想让某个内部网站始终直连，可以在覆写里追加这样一条规则：

```
DOMAIN-SUFFIX,example.com,DIRECT
```

规则的含义是：域名以 example.com 结尾的请求直连。它应该放在规则列表的最前面才会优先命中，覆写里让内容“放在最前”的具体写法，各版本可能不同，以官方说明为准。规则的语法和命中顺序，见[分流规则怎么写](/jiaocheng/fenliu-guize/)。

覆写一般有两种形式：用 YAML 描述要追加或修改的字段，或者用脚本处理整份配置，后者适合有编程基础的人。较新的版本支持这两种，是否都提供以界面为准。覆写可以对所有订阅生效，也可以只绑定到某一个订阅。

使用覆写的几条纪律：

1. **一次只改一件事。** 出了问题才知道是哪一处引起的。
2. **改之前备份。** 把原来的内容复制到记事本里存好。
3. **写错会让配置生成失败。** 表现为内核启动不了、节点列表为空。先把覆写停用，确认恢复正常，再逐行检查。
4. **不要把含有密码的内容贴出去求助。**

## 内核与端口设置：稳定版优先

内核就是真正转发流量的程序，Clash Party 用的是 Mihomo。内核设置页里常见这些项目：

| 项目 | 作用 | 建议 |
| --- | --- | --- |
| 内核版本通道 | 在稳定版与预览版之间选择 | 优先稳定版 |
| 本地代理端口 | 浏览器和其他程序指向的端口 | 数字以客户端显示为准，冲突时再改 |
| 允许局域网连接 | 让同一网络中的其他设备使用本机代理 | 不需要就关闭，需要时见[局域网共享代理](/jiaocheng/juyuwang-gongxiang/) |
| IPv6 | 内核是否连同 IPv6 流量一起接管 | 没出现与 IPv6 有关的故障就保持原样 |
| 日志级别 | 日志详细程度 | 排查问题时调高，平时不必 |

内核的单独下载和说明，见[Mihomo 内核下载](/xiazai/mihomo/)。切换内核后无法启动，或者节点突然全部异常，先换回稳定版，再排查。

端口冲突是最常见的小问题：本机已经有别的程序占着客户端要用的端口，表现为内核启动失败或提示端口被占用。关掉另一个代理软件，或者在内核设置里改成别的端口，改完记得让浏览器和其他程序的代理地址同步。查找占用者的办法见[Clash 端口被占用怎么办](/paicha/duankou-zhanyong/)。

## 系统代理与虚拟网卡：什么时候该开 TUN

| 方式 | 影响范围 | 权限 | 适合 |
| --- | --- | --- | --- |
| 系统代理 | 遵循系统设置的程序，主要是浏览器和部分软件 | 不需要额外权限 | 日常浏览，首选 |
| 虚拟网卡（TUN） | 几乎所有出站流量，包括不读系统代理的程序 | 需要管理员权限，或按提示安装服务 | 某个程序不走代理时 |

概念和对照见[TUN 模式是什么](/jiaocheng/tun-moshi/)。开启虚拟网卡的建议流程：

1. 先在系统代理下确认已经能正常上网，这一步通不了就别急着上虚拟网卡。
2. 以管理员身份运行客户端，或者按界面提示授权服务模式（把后台服务装好，之后不用每次提权）。服务模式的名称和提示以当前版本为准。
3. 在内核设置或相关页面打开虚拟网卡。
4. 打开之后，在系统的网络适配器列表里应该能看到一块新的虚拟网卡。
5. 用此前不走代理的程序试一次。

出问题时先关掉虚拟网卡，退回系统代理。无法开启或开启后断网的排查，见[TUN 模式开不了怎么办](/paicha/tun-moshi-shibai/)。多数原因是权限不足、与其他 VPN 软件冲突，或者 DNS 设置被改乱了。

macOS 和 Linux 上的授权方式不同，系统会通过各自的方式提示输入密码或授权，按提示操作即可。

## 验证生效与常见卡点

1. **看系统代理状态。** 开启系统代理后，到 Windows 设置的代理页面，能看到地址和端口已经被写入，数字与客户端显示的一致。
2. **看连接页。** 打开一个网站，在连接记录里看它命中了哪条规则、走了哪个策略组和节点。
3. **对比出口 IP。** 出口 IP 查询页在客户端开启前后给出的地址应当不同，同时对照连接页里的节点，两边对得上才算数。
4. **验证覆写。** 如果添加了直连规则，访问对应网站，看连接记录里是否显示直连。
5. **关掉再看。** 退出客户端或关闭系统代理，国外网站应当打不开；若关掉客户端后上不了任何网站，见[关掉梯子后上不了网](/paicha/guan-tizi-meiwang/)。

卡点汇总：

| 症状 | 常见原因 | 先试什么 |
| --- | --- | --- |
| 导入订阅失败 | 链接错误或过期、订阅域名打不开 | 浏览器打开订阅地址，换网络，或用已有订阅代理更新 |
| 节点列表为空 | 订阅格式不对，或覆写写错 | 停用覆写，换 Clash 格式地址 |
| 内核启动失败 | 端口冲突、覆写错误、内核版本问题 | 改端口，停用覆写，换回稳定版 |
| 虚拟网卡无法开启 | 权限不足、其他 VPN 冲突 | 管理员运行或授权服务，关闭其他 VPN |
| 浏览器能用、某软件不行 | 软件不读系统代理 | 改用虚拟网卡，见[某个 App 不走代理](/paicha/app-buzou-daili/) |
