Clash 机场，说白了就是提供 Clash 格式订阅的机场。挑选时看的不是品牌名气，而是四件事：订阅能不能直接给 Clash 或 mihomo 格式、自带的规则好不好用、节点用的协议你的内核认不认、订阅更新稳不稳。下面逐项拆开，并教你在下单前后自己验证，不用只靠别人的推荐。

## Clash 机场是什么意思：看订阅格式，不看品牌

“Clash 机场”并不是一个独立的品类。它的意思是：这家机场给你的订阅，可以直接导入 Clash 系客户端使用。

要理解这件事，需要知道两个背景：

- Clash 系客户端读取的是 YAML 格式的配置文件，里面包含节点、策略组和规则。Clash 是什么、内核和客户端怎么分，见[Clash 是什么](/zhinan/clash-shi-shenme/)。
- 机场的订阅有两大类：一类是**通用订阅**，只有节点链接列表；一类是 **Clash 订阅**，直接生成完整配置。Clash 机场就是指能给出后一类订阅的机场。

所以，选 Clash 机场不是在找一个特殊的服务商，而是在**同样的候选里，加上一项“Clash 订阅是否可用”的检查**。如果你同时看过通用订阅的讲解，会发现两条路线的挑选要点很多是共通的，区别主要在订阅格式和客户端。

## 挑 Clash 机场看哪五件事

| 要点 | 为什么重要 | 怎么核对 |
| --- | --- | --- |
| 是否直接给 Clash 或 mihomo 订阅 | 直接给就不用转换，省事也更安全 | 看官网后台的订阅选项，或询问客服 |
| 自带规则的质量 | 规则决定国内是否直连、常用服务是否走对线路 | 导入后查看策略组和规则，实际访问验证 |
| 协议与内核兼容 | 较新的协议需要新内核，旧内核会忽略或报错 | 用 Mihomo 系客户端导入，看节点是否完整 |
| 订阅更新是否稳定 | 订阅拉不下来，节点和规则就无法刷新 | 手动更新几次，观察是否稳定成功 |
| 是否依赖第三方转换 | 转换过程可能泄露订阅，也可能出格式错误 | 优先选原生支持的机场 |

这五项里，前三项在下单前就能通过官网和客服问清，后两项要导入后才能验证。**整体上不存在满分机场，关键是看你的使用场景最需要哪几项。**

## Clash 订阅有哪几种形态，转换要小心

同样叫 Clash 订阅，来源不同，风险也不同：

| 形态 | 内容 | 由谁生成 | 需要注意 |
| --- | --- | --- | --- |
| 机场原生 Clash 订阅 | 完整的 YAML 配置 | 机场服务器 | 最省事，规则质量取决于机场 |
| 通用订阅加转换 | 把节点链接列表转换成 YAML | 第三方转换服务或本地工具 | 订阅可能泄露；转换结果可能格式有误 |
| 自己编写的配置 | 自己写的 YAML | 你自己 | 需要懂语法，也要自己维护 |

转换听起来方便，但要记住：**订阅链接是你账号的凭证**。把它交给不认识的转换服务，可能带来泄露风险。订阅转换的原理、风险和更稳妥的做法，见[订阅转换是什么](/jiaocheng/dingyue-zhuanhuan/)。万一链接已经外泄，处理办法见[订阅链接泄露了怎么办](/bikeng/dingyue-xielou/)。

## 协议与内核兼容：同一份订阅，为什么有的客户端节点是空的

这是 Clash 机场最容易遇到的坑。同一份订阅，在一个客户端里节点齐全，在另一个客户端里却缺了一半。原因多数在内核。

| 协议或特性 | 对内核的要求 | 不兼容时的常见现象 |
| --- | --- | --- |
| Shadowsocks、VMess、Trojan | 多数 Clash 系内核都支持 | 一般不会出问题 |
| VLESS，包括 Reality | 需要 Mihomo 内核 | 节点缺失，或提示不支持 |
| Hysteria2、TUIC 等 | 需要 Mihomo 内核 | 同上 |
| 其他较新的特性 | 以 Mihomo 官方文档为准 | 视具体特性而定 |

要点有三个：

- **选内核是 Mihomo 的客户端**，如 Clash Verge Rev、Clash Party、FlClash、Clash Meta for Android 等，它们对较新协议的支持更完整。具体支持范围以 [Mihomo 官方文档](https://wiki.metacubex.one/) 为准。
- **不要用旧教程里的停更软件。** 原版内核早已停更，它不认识新协议，导入新订阅时容易报错或丢节点。
- **iPhone 上的 Stash** 兼容 Clash 配置，但它支持的协议范围以它自己的说明为准，不一定与 Mihomo 完全一致。它是 App Store 付费应用，不在中国大陆区商店上架，需要其他地区的 Apple ID。

各协议的特点和适用场景，见[机场协议怎么选](/zhinan/jichang-xieyi/)。

## 订阅自带的规则：好不好用怎么看

Clash 订阅的一大优势是自带规则：国内网站直连，国外走代理，常用服务有专门的策略组。规则质量直接决定日常体验。

导入订阅之后，可以从这几个方面判断：

- 国内常用网站是否直连。如果开着代理国内网站明显变慢，通常是分流没做好。排查见[开了梯子国内网站变慢](/paicha/guonei-wangzhan-man/)。
- 是否有按用途划分的策略组，比如流媒体、AI、苹果服务。分组越清晰，你越容易单独调整。
- 规则是否含有需要联网更新的规则集。规则集更新失败会导致规则过期。
- 规则是否容易被你覆盖。很多 Clash 系客户端提供覆写或追加规则的功能，菜单名称随客户端而异，以当前版本为准。

规则的写法和原理，见[分流规则怎么写](/jiaocheng/fenliu-guize/)。新手先用机场自带规则，够用就不用改。

## 资料里 Clash 标注很少，没标注不等于不能用

页面下方有一块数据，会列出资料里明确标注支持 Clash 的机场。你会发现，这样的机场并不多。原因主要是：很多机场的官网并没有把订阅格式写清楚，我们的资料只收录了有明确说明的情况。

因此要这样理解：

- **标注了**：说明有来源写明支持 Clash，但仍建议你自己导入验证。
- **没标注**：只代表我们没有核实到，**不代表不支持**。
- **要用 Clash 但没标注的候选**：别排除，去官网后台和帮助文档里找订阅选项，或者直接问客服。

这类“资料里没有”的情况，没有捷径，只能自己验证。

## 买之前和买之后，怎么自己验证 Clash 订阅可用

按下面的顺序走一遍，花不了多少时间：

1. 在官网的帮助文档、套餐页里搜索 Clash、mihomo、订阅格式等字样。
2. 向客服问两个问题：是否提供 Clash 或 mihomo 格式订阅？是否包含 VLESS、Hysteria2 这类较新协议的节点？
3. 下单最短周期，不要一上来买长周期。
4. 在后台找到 Clash 订阅的复制入口，名称各家不同。
5. 用 Mihomo 系客户端导入，具体步骤见[订阅链接怎么用](/jiaocheng/dingyue-daoru/)和[Clash Verge Rev 使用教程](/jiaocheng/clash-verge-rev-windows/)。
6. 导入后检查三项：节点数量和官网一致吗？策略组和规则出现了吗？有没有“不支持”之类的提示？
7. 切换到规则模式，分别访问国内网站和国外网站，确认分流正常。
8. 手动更新订阅两三次，看是否稳定成功；晚高峰时段再测一次。

验证出口时，还可以借助 Cloudflare 提供的[连接信息检查页](https://one.one.one.one/help/)，它能显示当前连接所使用的网络等信息，具体含义以页面说明为准，可以辅助判断流量是否确实走了代理。

## 下一步：按你的客户端选订阅

1. 先确定客户端，Windows 和 macOS 用户可以从[Clash Verge Rev 下载](/xiazai/clash-verge-rev/)开始，其他系统到[下载中心](/xiazai/)按平台挑。
2. 到[梯子推荐](/tuijian/)里筛选候选，Clash 数据块只是起点，其余候选自己验证。
3. 拿不准订阅格式时，对照[V2Ray 机场怎么选](/zhinan/v2ray-jichang/)里通用订阅的讲解，两条路线选一条。
4. 买最短周期，按上面的八步验证，通过之后再续费。

如果验证中发现节点缺失或订阅更新失败，先查内核和订阅格式，再查线路，而不是急着换机场。
