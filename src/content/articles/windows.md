Windows 梯子下载的结论可以先说：按你手里的订阅格式定客户端类型，然后只去这款客户端的官方仓库发布页拿安装包。页面顶部的数据表已经列出本站收录的、支持 Windows 的客户端，官方地址、版本和发布日期都在表里，正文不再重复。下面讲表里看不出来的事：几款之间怎么选、安装包怎么挑、系统弹出的提示怎么理解、装完和卸载时各要留意什么。

## Windows 梯子软件分三类，先按订阅格式选

客户端本身不带节点，它只负责读取机场给你的订阅。所以挑软件的第一步不是看界面，而是看订阅格式。机场后台的“复制订阅”通常会区分 Clash 订阅和通用订阅，手里是哪种，就往哪一类里找。

| 类型 | 本站收录的 Windows 客户端 | 内核 | 对应的订阅格式 | 上手难度 | 适合谁 |
| --- | --- | --- | --- | --- | --- |
| Clash 系 | Clash Verge Rev、Clash Party、FlClash、Clash Nyanpasu | Mihomo | Clash 订阅（YAML 配置） | 低到中 | 想要规则分流和策略组、机场给了 Clash 订阅的人 |
| V2Ray 系 | v2rayN | Xray / sing-box | 通用订阅、单个节点的分享链接 | 中 | 机场主要给通用订阅，或经常要手动添加节点的人 |
| sing-box 系 | Hiddify、Karing | sing-box | 多种格式，以各客户端官方说明为准 | 低 | 想导入后少做设置的人 |
| 纯内核 | Mihomo（内核）、sing-box | 各自内核 | 自己编写配置文件 | 高 | 熟悉命令行、要完全掌控配置的人 |

几条决策路径：

- 如果你是第一次用，机场教程又以 Clash 为例：从 [Clash Verge Rev 下载](/xiazai/clash-verge-rev/) 开始，本站有配套的 Windows 教程。
- 如果机场只给了通用订阅，或者你要自己添加 VLESS、Trojan 这类单个节点：看 [v2rayN 下载](/xiazai/v2rayn/)。
- 如果你手机上已经在用 FlClash，想让电脑也是同一套界面：看 [FlClash 下载](/xiazai/flclash/)。
- 如果你打算改配置、做覆写：Clash Party 和 Clash Verge Rev 都有这类功能，差别见 [Clash Party 下载](/xiazai/clash-party/) 页里的对照。
- 如果完全拿不准：用 [客户端选择工具](/gongju/kehuduan-xuanze/) 按系统和订阅格式筛一遍。

三类客户端在“能不能连上”这件事上没有高下，差别在操作习惯。不同内核支持的协议范围不完全相同，机场用了较新的协议时，以机场教程点名的客户端为准。电脑端的整体思路见 [电脑梯子](/zhinan/diannao-tizi/) 一文。

## 安装版还是便携版，x64 还是 arm64

打开任意一款客户端的发布页，Assets 列表里通常有十几个文件。对 Windows 用户有用的只有一两个，其余是给别的系统准备的。

| 文件名里的特征 | 含义 | 该不该选 |
| --- | --- | --- |
| x64、amd64、win64 | 面向 Intel、AMD 的 64 位处理器 | 多数 Windows 电脑选这个 |
| arm64、aarch64 | 面向 ARM 处理器 | 只有 ARM 架构的 Windows 设备才选 |
| setup、installer、.msi | 安装版 | 想要开始菜单入口、卸载入口和应用内更新时选 |
| portable、.zip、.7z | 便携版，解压即用 | 没有管理员权限，或想放在固定文件夹里随时删掉时选 |
| .dmg、.deb、.rpm、.AppImage、.apk | macOS、Linux、安卓的安装包 | 不选 |
| Source code | 源代码压缩包 | 不选 |

拿不准处理器架构时，打开“设置 → 系统 → 系统信息”，看“系统类型”一行：写着“基于 x64 的处理器”就选 x64，写着“基于 ARM 的处理器”就选 arm64。

安装版和便携版的差别主要在三处：

1. **文件放在哪**。安装版会写入程序目录并注册卸载入口；便携版的全部内容都在你解压的那个文件夹里。
2. **权限**。安装版在安装或启用部分功能时会请求管理员权限；便携版日常运行一般不需要，但开启 TUN 这类功能时同样会请求。
3. **更新**。安装版通常能在应用内检查并覆盖更新；便携版往往要你自己下载新包替换，配置是否保留以各项目说明为准。

便携版有两个常见错误。一是直接在压缩软件的预览窗口里双击运行，程序会跑在临时目录里，配置下次就丢。二是解压到桌面上的临时文件夹，过几天顺手删了，开机自启和快捷方式随之失效。解压到一个固定的路径，再运行。

## SmartScreen 和杀毒软件弹出提示时怎么判断

在 Windows 上装代理客户端，系统提示几乎躲不开。先弄清它们各自在说什么。

**SmartScreen 的提示**（“Windows 已保护你的电脑”一类）依据的是信誉：发布者有没有系统认可的代码签名，这个文件被下载运行的次数够不够多。它的意思是“我不认识这个程序”，而不是“我确认它有害”。开源代理客户端多由个人或社区维护，新版本刚发布时尤其容易遇到。

**杀毒软件的拦截**分两种。一种是基于行为特征的泛化提示：代理客户端会修改系统代理、监听本地端口、创建虚拟网卡，这些行为和部分恶意程序相似。另一种是明确报出了具体的威胁名称，这种要认真对待。

判断顺序建议这样走：

1. **先看来源**。文件是不是从数据表列出的官方仓库发布页下载的？不是就直接删掉重下，不用再往下判断。
2. **再看提示类型**。只是“未识别的应用”“发布者未知”，属于信誉类提示；报出具体威胁名称的，先停下。
3. **核对校验值**。发布页如果提供了 SHA256 等校验值，在本机算一遍再比对，方法见下一节。
4. **做决定**。来源和校验值都对得上，是否继续运行由你决定，按系统提示窗口里给出的选项操作即可；对不上，就不要运行。

有两件事不建议做：为了装一个客户端而整体关闭 SmartScreen 或实时防护；照着来路不明的帖子往系统里加大范围的排除项。确实需要设置排除时，范围限定在这款客户端自己的目录，并以该项目官方说明为准。

## Windows 梯子下载后，怎么确认是官方构建

这一节是你可以自己动手核对的清单，不需要相信任何人的转述。

- **核对地址**。浏览器地址栏应当是 `github.com/组织名/仓库名/releases` 的形式，组织名和仓库名与页面顶部数据表里的官方地址逐字符一致。仿冒仓库常用多一个字母、换一个连字符的写法。例如 Clash Verge Rev 的发布页是 [github.com/clash-verge-rev/clash-verge-rev/releases](https://github.com/clash-verge-rev/clash-verge-rev/releases)，v2rayN 的是 [github.com/2dust/v2rayN/releases](https://github.com/2dust/v2rayN/releases)。
- **核对版本**。发布页上标着 Latest 的是当前正式版，标着 Pre-release 的是测试版。文件名里的版本号应当和数据表显示的一致；数据表比发布页旧时，以发布页为准。
- **核对校验值**。发布说明里如果给出了校验值，在 PowerShell 里用系统自带的命令 `Get-FileHash .\安装包文件名 -Algorithm SHA256` 计算，再与发布页上的值逐位比对。
- **看数字签名**。右键文件打开“属性”，如果有“数字签名”一页，看签名者是谁。没有签名不等于有问题，很多开源项目没有购买证书；但这时更要靠前面几项。
- **装完再看一眼**。客户端的“关于”或设置页会显示版本号和内核版本，应当与你下载的一致。

同时警惕这些特征：文件名或页面上写着“汉化版”“破解版”“绿色整合包”“内置节点”的，都不是官方构建，风险见 [破解版梯子](/bikeng/pojie-kehuduan/)；打着某款客户端“官网”旗号的下载站，识别方法见 [机场假官网](/bikeng/jia-guanwang/)。

## 首次运行会遇到的权限请求

第一次打开客户端，Windows 可能连续弹出几种请求。它们各自对应一项功能，不需要全部同意。

| 请求 | 什么时候出现 | 对应的功能 | 不同意的后果 |
| --- | --- | --- | --- |
| 用户账户控制（管理员权限） | 安装、启用服务模式或 TUN 时 | 写入程序目录、安装系统服务、创建虚拟网卡 | 对应功能用不了，系统代理方式通常不受影响 |
| 防火墙放行 | 客户端开始监听网络端口时 | 允许其他设备连到这台电脑的代理端口 | 只在本机使用时一般没有影响 |
| 运行环境安装 | 系统缺少客户端依赖的组件时 | 界面或程序本身的运行基础 | 客户端打不开 |

几点补充：

- 只在本机用代理，防火墙提示里的“公用网络”可以不勾。要把代理共享给电视、游戏机时才需要放行，做法见 [局域网共享代理](/jiaocheng/juyuwang-gongxiang/)。
- 运行环境因客户端而异。有的依赖系统里的 WebView2 组件，有的依赖 .NET 运行环境，发布页一般会提供自带运行环境的安装包，具体以官方说明为准。
- 客户端打开“系统代理”后，会改写 Windows 的代理设置。你可以在“设置 → 网络和 Internet → 代理”里看到被写入的地址和端口，这是正常现象。两种接管流量的方式有什么差别，见 [系统代理](/jiaocheng/xitong-daili/) 与 [TUN 模式](/jiaocheng/tun-moshi/)。

具体到每一款怎么导入订阅、怎么开代理，分别看 [Clash Verge Rev 教程](/jiaocheng/clash-verge-rev-windows/) 和 [v2rayN 教程](/jiaocheng/v2rayn-windows/)。

## 卸载与残留：按顺序清这几处

卸载代理客户端后“上不了网”，多半是顺序错了：系统代理还指向一个已经不存在的本地端口。按下面的顺序做。

1. **先在客户端里关掉系统代理和 TUN，再从托盘图标退出**。只点窗口右上角的关闭，程序通常还在后台。
2. **卸载程序**。安装版在“设置 → 应用”里卸载；便携版退出后直接删除文件夹。
3. **检查系统代理**。打开“设置 → 网络和 Internet → 代理”，确认手动代理的开关是关闭状态。已经断网的话，修复方法见 [关闭梯子后上不了网](/paicha/guan-tizi-meiwang/)。
4. **清理配置目录**。多数客户端会把订阅和设置存在用户目录下的应用数据文件夹里，卸载时不一定删除。里面有你的订阅链接，电脑要转手或送修时务必清掉。
5. **检查服务、虚拟网卡和开机启动**。用过 TUN 或服务模式的，在任务管理器的“启动应用”和系统的网络适配器列表里看一眼有没有遗留项。

换客户端时不必急着卸载旧的，但不要让两款同时运行：它们会争抢同一个本地端口和系统代理设置，表现为其中一款启动失败，排查见 [Clash 端口被占用](/paicha/duankou-zhanyong/)。
