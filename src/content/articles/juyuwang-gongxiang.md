局域网共享代理，是让电脑上的梯子客户端对家里的局域网开放代理端口，电视、Switch 这类装不了客户端的设备，只要在网络设置里把电脑填成手动代理，就能借用电脑的线路。它不用改路由器，但电脑必须开机，设备也要有“手动代理”这一项。下面按原理、设置、验证和取舍的顺序讲。

## 局域网共享代理是怎么工作的

客户端启动后，会在电脑上监听一个本地端口。浏览器等程序把请求发到这个端口，客户端再通过节点转发出去。默认情况下，这个端口只对电脑自己开放，局域网里的其他设备连不进来。

客户端里的“允许局域网连接”开关只做一件事：让这个端口也接受局域网内其他设备的连接。打开之后，流量的路径变成这样：

```
电视 / 游戏机 → 家里的路由器 → 电脑（客户端监听端口）→ 机场节点 → 目标网站
```

设备端不装任何软件，只在 Wi-Fi 的“手动代理”里填两个值：电脑的局域网 IP，和客户端的代理端口。所以这套办法有三个前提：

- 电脑和设备在同一个局域网里，也就是接在同一台路由器下。
- 电脑开机、客户端在运行，并且已经选好了可用的节点。
- 设备的网络设置里有手动代理入口。

三条缺一条，就谈不上共享。第三条是最容易落空的，后面有一张表对照常见设备。

## 第一步：打开“允许局域网连接”，记下 IP 和端口

在电脑上按顺序做：

1. **确认网络**：电脑和设备连的是同一台路由器的同一个网络。路由器如果开了访客网络或“AP 隔离”，设备之间会互相访问不了，需要接到主网络，或者在路由器里关闭隔离。
2. **打开开关**：在客户端设置里找到“允许局域网连接”（英文界面常写作 Allow LAN）。Clash 系客户端一般叫这个名字，v2rayN 里类似的选项叫“允许来自局域网的连接”，sing-box 则是把入站监听地址从只监听本机改成对所有地址监听。菜单位置和叫法以你所用版本为准。
3. **记下端口**：Clash 系客户端通常同时提供 HTTP、SOCKS 和一个“混合端口”，混合端口既认 HTTP 也认 SOCKS。设备的手动代理多半只认 HTTP，所以优先记混合端口或 HTTP 端口。具体数字以你的客户端设置页显示为准，下文统一写作 PROXY_PORT。
4. **查电脑的局域网 IP**：用下面的命令，在输出里找到当前上网网卡的 IPv4 地址，局域网地址通常形如 192.168.x.x 或 10.x.x.x，下文统一写作 PC_LAN_IP。
5. **固定这个 IP**：在路由器后台给电脑做“DHCP 保留”（按网卡的 MAC 地址绑定 IP）。不固定的话，电脑重启或换连接后 IP 可能变化，设备里填的地址就失效了。

Windows（命令提示符）：

```
ipconfig
```

macOS（en0 常见于笔记本的 Wi-Fi，接口名以你的机器为准）：

```
ipconfig getifaddr en0
```

Linux：

```
ip -4 addr
```

有一点要分清：电脑自己的[系统代理](/jiaocheng/xitong-daili/)开关，和“允许局域网连接”是两件事。前者决定电脑上的程序走不走代理，后者决定别的设备能不能连进来。设备走的是客户端的端口，不依赖电脑是否开了系统代理；但客户端当前的模式和选中的节点，会同时作用于电脑和所有接进来的设备。

## 放行防火墙，并检查端口是不是真的对局域网开放

很多人开了开关、填了代理，设备仍然连不上，原因多半在这一层。

**Windows**：第一次让程序监听局域网时，系统防火墙可能弹窗询问，选择允许“专用网络”。如果没弹窗，或者点了拒绝，到防火墙的“允许应用通过防火墙”里，给客户端程序勾选专用网络。有些客户端把真正监听的工作交给单独的内核进程，这个进程也要放行。

**macOS**：如果开了应用防火墙，客户端或内核第一次接受传入连接时会弹窗，选择允许即可。

**第三方安全软件**自带的防火墙有独立开关，也要看一眼。

放行之后，先在电脑上确认监听地址：

Windows：

```
netstat -ano | findstr LISTENING | findstr :PROXY_PORT
```

macOS 或 Linux：

```
lsof -nP -iTCP:PROXY_PORT -sTCP:LISTEN
```

输出里的监听地址如果是 127.0.0.1，说明端口只对本机开放，要么开关没生效，要么需要重启客户端。如果是 0.0.0.0 或者你的局域网 IP，说明已经对局域网开放。

再找另一台电脑，在终端里带上代理参数访问一个网站：

```
curl -I -x http://PC_LAN_IP:PROXY_PORT https://www.google.com
```

PC_LAN_IP 和 PROXY_PORT 换成你自己的值。能返回响应头，说明电脑这一端没问题；提示连接被拒绝，说明端口没对局域网开放；一直没有反应，多半是防火墙或网络隔离。

## Switch 代理和电视代理怎么填

不同设备的入口位置不同，下表只描述功能位置，具体菜单以设备当前系统为准：

| 设备 | 手动代理入口 | 备注 |
| --- | --- | --- |
| Switch | 系统设置的互联网设置里，选中已连接的网络后可更改代理服务器设置 | 填 HTTP 代理地址和端口 |
| Apple TV | 通常在 Wi-Fi 网络详情里有“配置代理” | 有线连接时是否有该入口，以系统为准 |
| Android TV 与安卓电视盒子 | 多数在已连接 Wi-Fi 的高级选项里 | 品牌深度定制的系统可能没有这一项 |
| PlayStation | 网络设置的高级设置里有代理服务器选项 | 以主机系统版本为准 |
| 厂商自有系统的智能电视 | 差异很大 | 不少机型只能改 DNS，没有代理入口 |
| Xbox | 以主机设置里能否找到为准 | 找不到入口就只能走路由器方案 |

填写步骤各设备大同小异：

1. 进入设备的 Wi-Fi 设置，选中当前连接的网络，进入高级设置或“更改设置”。
2. 找到“代理”或“代理服务器”，选择手动。
3. 服务器地址填 PC_LAN_IP 的实际值，端口填 PROXY_PORT 的实际值。账号密码一栏留空，除非你在客户端里开了认证。
4. 保存。设备一般会重连一次网络，或者做一次连接测试。
5. 回到要用的应用里试用。

关于 Switch 代理，要有合理预期。手动代理只覆盖会读这项设置、并且走 HTTP 的请求。游戏联机、语音多使用 UDP 和点对点连接，通常不经过代理，所以不要指望填了代理就能改善联机。它能影响的，主要是设备上走 HTTP 的那部分访问。

电视的情况更复杂，要看系统类型、能不能装客户端、遥控器好不好用，这些在[电视怎么用梯子](/jiaocheng/dianshi-tizi/)里单独讲了。

## 怎么确认共享已经生效

别只看“设备连上 Wi-Fi 了”。要确认设备的流量真的到了电脑的客户端：

1. 在电脑客户端里打开“连接”或“日志”页面（名称以版本为准）。
2. 在设备上随便打开一个页面或应用。
3. 看有没有来自设备 IP 的新连接。

多数客户端的连接页会显示每条连接的来源地址。看到设备的地址，就说明设备已经走到了代理；完全没有，说明请求根本没到电脑。

| 现象 | 说明什么 | 下一步 |
| --- | --- | --- |
| 日志里完全没有设备的连接 | 设备没读这项设置，或没连到电脑 | 核对 IP、端口，再用 curl 测试 |
| 有连接，但页面打不开 | 代理这一段通了，后面的节点或规则有问题 | 在电脑上用同一节点打开同一网站对照，参考[梯子连不上的排查](/paicha/tizi-lianbushang/) |
| 有些应用能用，有些不行 | 个别应用不读代理设置，或使用了 UDP | 这是手动代理的局限，见下一节 |
| 能用一阵，过一会儿又不行 | 电脑睡眠、IP 变化或客户端被关闭 | 关闭睡眠，固定电脑 IP |

## 手动代理的局限，以及共享梯子要守的边界

**只管 HTTP 类请求。** 设备的手动代理一般只认 HTTP 代理，不认 SOCKS5，也不带 UDP 转发。有的应用即使用了系统网络设置，也会自己绕开代理，这类情况在[某个 App 不走代理](/paicha/app-buzou-daili/)里有专门的排查。

**电脑要一直开着。** 电脑睡眠或关机后，设备里保存的代理设置还在，设备就会表现为“所有网页都打不开”。这时要进设备的网络设置把手动代理改回关闭，原因和[关掉梯子后上不了网](/paicha/guan-tizi-meiwang/)是同一类。

**局域网里的所有人都能用。** 开启“允许局域网连接”后，同一网络里的任何设备都能连这个端口、使用你的线路。家里可以，合租、公司、学校、咖啡馆的网络不要开。不用的时候把开关关掉。

**共享梯子不等于可以给别人用。** 机场的套餐有设备数和使用条款，把线路分给邻居或室友，可能违反条款，也会让流量消耗变得不可控。设备数怎么算，各家规则不同，可以先看[梯子能几台设备同时用](/zhinan/duo-shebei/)。

**流量要留意。** 电视看视频消耗的流量比刷网页大得多，共享之后所有设备的消耗都记在同一个套餐上。

## 共享梯子还是上路由器：三种方案怎么取舍

| 方案 | 电脑要开机吗 | 覆盖范围 | 主要代价 |
| --- | --- | --- | --- |
| 局域网共享代理 | 要 | 只覆盖手动配置过的设备，HTTP 类流量 | 电脑常开，每台设备手动填 |
| 在设备上直接装客户端 | 不要 | 单台设备的全部应用 | 设备要能装客户端，电视上遥控器操作不便 |
| 路由器方案 | 不要 | 整个局域网里的设备 | 路由器要支持，配置门槛较高 |

挑选的思路很简单：

- 只是偶尔让一两台设备用一下，局域网共享最省事，十几分钟能配完。
- 设备能装客户端的，优先直接装，不依赖别的设备。
- 设备很多、想让全家不用逐台设置，才值得折腾路由器。路由器上能装什么插件，见[路由器梯子下载](/xiazai/luyouqi/)，装好后的导入与模式选择见[OpenClash 路由器使用教程](/jiaocheng/openclash-luyouqi/)。

## 下一步：先用一台设备跑通，再决定要不要升级

1. 先在一台设备上完成设置，按上面的验证步骤确认连接页里出现了它的地址。
2. 确认电脑 IP 已固定，防火墙只放行了专用网络。
3. 观察一两天：电脑休眠后设备会怎样，是否经常需要手动改回代理设置。如果这些让你觉得麻烦，说明该考虑路由器方案了。
4. 如果线路本身不够用，比如设备多、要看视频，先回头看看套餐的流量和节点是否合适。还没有机场的话，可以从[机场推荐](/tuijian/)开始对照。
