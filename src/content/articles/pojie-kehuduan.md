不建议。破解版梯子的前提是“正版要花钱”，这个前提对主流客户端并不成立：它们大多有公开的官方仓库，免费就能下载，没有什么需要破解的。而所谓破解版、去广告版、内置节点的修改版客户端，恰好是最容易被植入后门、窃取订阅和账号的一类软件。这篇讲清楚它们动了什么手脚，以及怎么确认自己装的是官方构建。

## 破解版梯子软件能用吗：先弄清楚它在“破解”什么

先把读者想要的和修改版声称的对照一下：

| 你想要什么 | 修改版声称提供 | 正规做法 |
| --- | --- | --- |
| 不想花钱买客户端 | 解锁付费功能的梯子破解版 | 主流客户端有公开仓库，免费下载；iOS 付费应用的价格以 App Store 页面为准，也有支持 iPhone 的其他客户端，见[iPhone 梯子下载](/xiazai/iphone/) |
| 不想买机场，想直接用 | 内置免费节点 | 内置节点的风险与公开订阅相同，见[免费节点有什么风险](/bikeng/mianfei-jiedian-fengxian/) |
| 嫌配置麻烦，想装上就能用 | 整合包，预置配置和节点 | 官方客户端加上自己的订阅，导入方法见[订阅链接怎么用](/jiaocheng/dingyue-daoru/) |
| 想要不限时长、永久会员的 VPN 应用 | 所谓破解 VPN | 会员价格以应用商店页面为准，要不要买自己判断；或改用开源客户端加自己的订阅 |

“破解”的对象通常只有两种：商业应用的会员校验，以及客户端里的节点限制。前者对主流开源客户端没有意义，后者往往是把别人的节点打包进去，问题就回到了免费节点。除此之外，使用破解软件还涉及软件版权，请遵守所在地法律法规，选梯子不提供法律意见。

## 主流客户端本来就免费，多数时候根本不需要破解

本站收录的 16 款客户端里，除了 Shadowrocket 和 Stash 两款 iOS 付费应用，其余都有公开的官方仓库，官方地址都列在[梯子下载汇总](/xiazai/)里。按系统找，可以去[安卓梯子怎么用](/zhinan/anzhuo-tizi/)或各系统的下载页。

有两个背景值得知道：

- **原版 Clash 已经停更。** 原版 Clash 内核和 Clash for Windows 的仓库已经删除，现在说的 Clash 多指 mihomo（Clash Meta）内核以及基于它的图形客户端，详见[Clash 是什么](/zhinan/clash-shi-shenme/)。网上仍在流传的旧安装包，已经没有官方的发布渠道，无法核对来源。
- **iOS 的付费应用是真的收费。** Shadowrocket 和 Stash 是 App Store 付费应用，不在中国大陆区商店上架，需要使用其他国家或地区的 Apple ID，价格以 [Shadowrocket](https://apps.apple.com/us/app/shadowrocket/id932747118) 和 [Stash](https://apps.apple.com/us/app/stash-rule-based-proxy/id1596063349) 的商店页面为准。

所以现实只有两种情况：要么软件本来就免费，不需要破解；要么是别人改过的，你不应该信任。

## 修改版客户端可能动了哪些手脚

下面是破解版梯子和各类修改版客户端有能力做到的事。注意是“有能力”，并不是每一个都会做；问题在于，你从外部分辨不出来。

| 常见改动 | 实际可能发生什么 | 怎么降低 |
| --- | --- | --- |
| 去广告、解锁功能 | 改动程序本身的人，有机会同时加入别的代码 | 不使用任何第三方改过的包 |
| 内置节点或订阅 | 你的全部流量走向对方的节点，风险同免费节点 | 只导入自己的订阅 |
| 整合包预置配置 | 配置里可能带有规则、DNS 设置、脚本或预置订阅 | 用官方客户端，自己配置 |
| 读取并上传配置 | 订阅链接和节点凭据被发送出去，造成[订阅链接泄露](/bikeng/dingyue-xielou/) | 只从官方来源获取；发现异常立即重置订阅 |
| 捆绑其他软件 | 安装时顺带装上别的程序，浏览器首页被修改 | 安装时看清选项，只装官方包 |
| 占用系统资源 | CPU 和网络长期高占用 | 用任务管理器或活动监视器定期看一眼 |

## 客户端比机场更靠近你的数据：它能碰到什么

很多人担心“机场能看到什么”，却忽略了装在自己设备上的客户端。两者能接触的东西不一样：

| 位置 | 能接触到什么 | 受到什么限制 |
| --- | --- | --- |
| 机场节点 | 目标域名或 IP、流量大小、时间，看不到 HTTPS 的加密内容 | 接触不到你设备上的其他内容 |
| 正常的客户端 | 订阅链接、节点凭据、代理设置，以及经过它的设备流量 | 受操作系统权限约束，HTTPS 内容仍然是加密的 |
| 被修改的客户端 | 上述全部，再加上它被授予的权限范围内的任何事 | 取决于授权，权限越高，可做的越多 |

权限的差别在不同系统上是这样体现的：

- **安卓。** 这类应用通过系统的 VpnService 接口建立 VPN 连接，处理设备上的网络流量，见 [Android 开发者文档对 VpnService 的说明](https://developer.android.com/reference/android/net/VpnService)。首次开启时系统会弹出确认窗口，请求授权。这个授权意味着应用有能力处理经过它的流量，所以应用本身必须可信。
- **Windows、macOS 和 Linux。** 开启 TUN 模式或安装系统服务，往往需要管理员权限，见[TUN 模式是什么](/jiaocheng/tun-moshi/)。一个被改过的程序拥有管理员权限，等于获得了更高的操作空间。

这里同样要强调：HTTPS 的内容在没有安装陌生证书的前提下仍然是加密的。所以遇到要求你安装证书、关闭安全软件、授予与代理无关的权限，比如读取短信、通讯录的，一律拒绝。

## iOS 付费应用的“共享账号”，是同一个问题换了个形式

在 iPhone 上，有人会把别人持有的 Apple ID 当作“共享账号”，用来下载付费的梯子应用。它与破解版的逻辑相同：用一个你不能控制的东西，换取免费使用。实际会发生的事情有这些：

1. **账号归对方。** 对方可以随时改密码或收回。账号被收回后，你就无法更新或重新下载这个应用。
2. **与你的设备关联。** 如果在系统设置里登录了这个账号，别人的账号就和你的设备关联起来，具体影响取决于你开启的功能。只在应用商店里登录，风险会小一些，但账号的不确定性依然存在。
3. **账号来路不明。** 来路不明的账号一旦被找回或冻结，你的下载和更新就会受影响。

降低风险的办法是准备自己的外区 Apple ID，方法见[外区 Apple ID 怎么准备](/jiaocheng/waiqu-apple-id/)。不在应用商店里、靠描述文件或第三方签名分发的梯子应用，同样不要使用。

## 怎么确认自己装的是官方构建：六步核对

下面六步都是你自己能做的。

1. **只从官方来源下载。** 打开[梯子下载汇总](/xiazai/)，进入对应客户端的下载页，再跳转到官方仓库的发布页或应用商店。例如 [Clash Verge Rev 官方仓库](https://github.com/clash-verge-rev/clash-verge-rev)和 [v2rayNG 官方仓库](https://github.com/2dust/v2rayNG)。不要在搜索结果里直接找安装包。
2. **核对项目名和作者名。** 假仓库的名字常常与真仓库只差一两个字符，和[机场假官网](/bikeng/jia-guanwang/)的近似域名同理。
3. **选对文件。** 同一个发布页里有多个系统和架构的文件，按自己的系统选择。不要下载标着“整合版”“免安装全家桶”的文件。
4. **校验文件摘要。** 很多项目的发布页会提供校验值，或者直接显示文件摘要，以该项目的页面为准。下载后在本机算一遍，再对比。三个系统的命令分别是：Windows 的命令提示符或 PowerShell 用 `certutil -hashfile 文件名 SHA256`，macOS 用 `shasum -a 256 文件名`，Linux 用 `sha256sum 文件名`。算出的值与发布页一致，说明文件在传输途中没有被改动。校验值必须取自官方页面，网盘页面上附带的校验值没有意义。
5. **看安装后的行为。** 安卓首次开启时，应当只请求 VPN 连接授权，不该要求读取短信、通讯录。电脑上不应附带其他软件，浏览器首页不应被改动，任务管理器里也不应出现异常的长期高占用。
6. **更新渠道保持一致。** 安卓系统要求更新包使用同一个签名，装新包时提示签名冲突或无法覆盖安装，说明两个包不是同一个发布者签的。也可能是同一项目的不同发布渠道，需要回官方页面确认。

关于安全软件的报警，要保持清醒：代理类软件有时会被误报，所以单凭报警不能说明有问题。但“来源不是官方、又触发了报警”，就应当直接放弃。

## 已经装过修改版，怎么处理

按下面的顺序处理，一般能把影响控制住：

1. **断网并卸载。** 安卓上卸载后，再检查“无障碍”和“设备管理应用”里有没有残留的授权。
2. **完整扫描。** 用安全软件扫描整台设备，检查开机启动项、系统代理和系统证书有没有被改动，系统代理残留的修复见[关掉梯子后上不了网](/paicha/guan-tizi-meiwang/)。
3. **换密码。** 在另一台干净的设备上，更换邮箱、支付账号和机场面板的密码，并尽量开启两步验证。
4. **重置订阅。** 在这个客户端里导入过的订阅，都应视为已经泄露，到面板里重置，做法见[订阅链接泄露了怎么办](/bikeng/dingyue-xielou/)。
5. **检查支付。** 输入过支付信息的，查看交易记录，必要时联系支付渠道。
6. **从官方来源重装。** 无法确定设备是否清理干净时，备份个人文件后重装系统。清理干净之前，不要在这台设备上登录重要账号。
