V2Ray 机场通常指提供 VMess、VLESS 等类型节点，并且能给出通用订阅的机场，用 v2rayN、v2rayNG 这类客户端就能导入。选的时候重点看三件事：机场给不给通用订阅、节点用什么协议、你的客户端认不认这些协议。下面逐项讲，并告诉你导入之后怎么自己核对。

## V2Ray 机场指什么：节点类型加订阅形式

这个词有点模糊，因为“V2Ray”本身在日常里被泛指。先分清它在这里指什么：

- **节点类型**：机场提供的节点用的是 VMess、VLESS 这一系协议，也就是 V2Ray 项目和 Xray 分支里用的协议。这些名字的来龙去脉，见[V2Ray 是什么](/zhinan/v2ray-shi-shenme/)。
- **订阅形式**：机场提供的是通用订阅，也就是由节点链接组成的列表，而不是完整的配置文件。
- **客户端**：用来导入订阅的工具，比如 v2rayN、v2rayNG 这类。

所以“V2Ray 机场”并不是一个独立的品类，而是在说**这家机场的订阅和节点，能不能被 V2Ray 系客户端直接用**。如果你想了解对应的 Clash 路线，读[Clash 机场怎么选](/zhinan/clash-jichang/)。

## V2Ray 订阅和 Clash 订阅有什么区别

选机场前最该弄清的是这两种订阅格式的差别：

| 对比项 | 通用订阅（常说的 V2Ray 订阅） | Clash 订阅 |
| --- | --- | --- |
| 内容 | 经过编码的节点链接列表，解码后每行一条 | 完整的 YAML 配置文件 |
| 是否包含规则 | 不包含，规则由客户端自己决定 | 包含策略组和分流规则 |
| 常用客户端 | v2rayN、v2rayNG、NekoBox、Hiddify、Karing 等 | Clash Verge Rev、FlClash 等 Mihomo 系 |
| 灵活性 | 路由规则可在客户端里自由设置 | 规则随订阅更新而变化 |
| 常见问题 | 客户端不识别某些协议，节点被跳过 | 内核太旧，不认识新协议 |

打个比方：通用订阅像一份“节点名单”，Clash 订阅像“名单加使用说明”。很多机场两种都提供，你按自己的客户端选。多数客户端都支持导入通用订阅，具体以所用客户端的说明为准。

订阅链接是什么、怎么导入，通用方法见[订阅链接怎么用](/jiaocheng/dingyue-daoru/)。

## 怎么确认机场给不给通用订阅

不要凭印象，下单前后按下面几步核对：

1. 在官网的帮助文档、套餐页里搜索“通用订阅”“V2Ray”“订阅”等字样。
2. 登录后台，看订阅页面的复制选项。名称各家不同，常见的有“通用”“V2Ray”“Clash”之类，以实际显示为准。
3. 有的机场用链接的后缀或参数区分格式，具体写法以官网说明为准，不要自己乱改链接。
4. 向客服问清楚：是否提供通用订阅？节点包含哪些协议？
5. 下单最短周期，导入自己的客户端验证。

找不到相关说明、客服答复含糊，都是应该多留一个心眼的信号。**订阅格式写不清楚的机场，后续排查起来也往往更麻烦。**

## V2Ray 节点的协议与客户端支持差异

通用订阅里的每个 V2Ray 节点，都以协议前缀开头。下表列出几种常见协议：

| 协议 | 节点链接前缀 | 特点（概述） | 兼容性提示 |
| --- | --- | --- | --- |
| VMess | vmess:// | V2Ray 项目的协议，自带加密，对客户端与服务器的时间差敏感 | V2Ray 系客户端普遍可识别，以当前版本说明为准 |
| VLESS | vless:// | 更轻量，通常搭配 TLS 或 Reality 等传输层方案 | 取决于内核对相应传输方式的支持 |
| Trojan | trojan:// | 设计上模仿常见的 HTTPS 连接 | 多数客户端支持 |
| Shadowsocks | ss:// | 经典的轻量协议 | 几乎所有客户端都支持 |
| Hysteria2 | hysteria2://，部分写作 hy2:// | 基于 QUIC 的协议 | 对内核有要求，是否支持取决于所用内核和版本 |

不同客户端的内核不同，支持的协议集合也不同。按本站收录的信息，对应关系大致是：

| 客户端 | 系统 | 内核 |
| --- | --- | --- |
| [v2rayN](/xiazai/v2rayn/) | Windows、macOS、Linux | Xray 或 sing-box |
| [v2rayNG](/xiazai/v2rayng/) | Android | Xray |
| NekoBox for Android | Android | sing-box |
| sing-box、Hiddify、Karing | 多平台 | sing-box |
| Shadowrocket（小火箭） | iPhone | 自有 |

关键点只有一个：**节点用什么协议，你的客户端内核就必须支持什么协议。** 某种协议是否被某个版本支持，请以客户端当前版本的官方说明，以及 [Xray 文档](https://xtls.github.io/)、[sing-box 文档](https://sing-box.sagernet.org/)为准，不要依赖旧教程。各协议的特点比较，见[机场协议怎么选](/zhinan/jichang-xieyi/)。

小火箭在 App Store 付费，价格以 App Store 页面为准，且不在中国大陆区商店上架。

## 挑 V2Ray 机场看哪几件事

把前面的内容变成一张检查表：

| 检查项 | 为什么重要 | 怎么核对 |
| --- | --- | --- |
| 通用订阅可用 | 这是 V2Ray 系客户端导入的前提 | 后台有明确选项，或客服确认 |
| 协议覆盖与你的客户端匹配 | 客户端不认的协议，节点就被跳过 | 导入后对比节点类型和数量 |
| 节点命名清晰 | 地区、线路、倍率写清楚，才能选得准 | 看节点列表，倍率含义见[流量倍率](/zhinan/liuliang-beilv/) |
| 订阅链接可重置 | 泄露后可以换新链接，减少损失 | 后台有重置入口 |
| 订阅更新稳定 | 更新失败，节点就无法刷新 | 手动更新几次观察 |

另外还要记住，这里没有“选好协议就一劳永逸”的说法。协议只决定通信方式，能不能用、稳不稳，还是取决于线路和运营，只能靠试用判断。想直接看候选，可以到[梯子推荐](/tuijian/)里按价格、线路和流量筛选。

## 导入后节点数量不对或连不上，怎么自查

按下面的顺序一步步排除：

1. **检查链接是否完整。** 复制订阅链接时有没有被截断，前后有没有多余的空格。
2. **看订阅是否更新成功。** 如果订阅域名本身打不开，节点就拉不下来，排查见[订阅更新失败怎么办](/paicha/dingyue-gengxin-shibai/)。
3. **换一个客户端导入，对比节点数量。** 数量不一致，多半是某些协议不被原来的客户端识别。
4. **查看客户端的内核设置。** 在设置里找到内核或核心的选项，确认是否是支持该协议的内核。菜单名称随客户端而异。
5. **VMess 节点先校对系统时间。** 时间差过大会导致连不上，具体见[梯子提示证书错误](/paicha/zhengshu-shijian/)。
6. **分清是个别节点还是全部节点。** 个别超时和全部超时的原因不同，见[节点超时怎么办](/paicha/jiedian-chaoshi/)。
7. **都不行时联系客服。** 说明你用的客户端、内核、出问题的节点协议和报错信息，便于对方定位。

如果你用的是 Windows，可以边看边操作[v2rayN 使用教程](/jiaocheng/v2rayn-windows/)；安卓则参考[v2rayNG 使用教程](/jiaocheng/v2rayng-android/)。

## 下一步：确认格式、选好客户端、再下单

1. 先定客户端：Windows 看[v2rayN 下载](/xiazai/v2rayn/)，安卓看[v2rayNG 下载](/xiazai/v2rayng/)。
2. 到[梯子推荐](/tuijian/)里筛出两到三个候选，逐个确认是否提供通用订阅。
3. 下单最短周期，导入后对比节点数量和协议类型。
4. 订阅链接妥善保管，万一外泄，见[订阅链接泄露了怎么办](/bikeng/dingyue-xielou/)。
5. 通过一周的试用后，再决定是否续费。

如果你搜到“V2Ray 机场推荐”的页面，不妨先用这套检查项过一遍候选，再决定要不要信那份推荐。
