“原生 IP”是一个被用得很松的词。严格地说，它指一个 IP 地址的登记地与实际使用地一致；在机场的宣传里，它常常被当成“更干净、更好用”的同义词。这是两件不同的事。下面先把概念拆开，再讲这些属性为什么会影响流媒体和 AI 服务，最后说清你能自己查什么、查不了什么。

## 原生 IP 的含义：登记地与使用地一致

互联网上的 IP 地址并不是随意使用的。它们由 [IANA](https://www.iana.org/numbers) 统筹，分配给各大区域的注册机构，再由注册机构分配给运营商、云厂商或企业。每一段地址都有登记信息，包括所属国家、持有机构的名称和所属的自治系统编号。

原生 IP 的意思是：这个地址登记在哪个国家，实际就在这个国家的机房或网络里使用。

反过来，非原生的情形也很常见。地址段可以被转让、租借，或者在别的国家宣告路由，结果是登记国家与实际所在地不同。这类地址有时被称作“广播 IP”。许多 IP 地理库依据登记信息给出国家，所以这类地址在查询页上显示的国家，可能与它的实际位置不符。

为什么这个差别会被机场拿来宣传？因为一些服务会参考 IP 的地理信息判断你来自哪里，登记地与实际位置一致时，两种信息相互印证，不一致时就有不匹配的风险。

## 原生 IP、机房 IP 和住宅 IP：三个按不同维度划分的概念

这是最容易被混淆的地方。先看一张表。

| 概念 | 按什么维度划分 | 含义 | 你能否自查 | 常见误解 |
| --- | --- | --- | --- | --- |
| 原生 IP | 地理一致性 | 登记地与实际使用地一致 | 部分可以 | 以为原生就等于住宅 |
| 非原生（广播）IP | 地理一致性 | 登记地与实际使用地不一致 | 部分可以 | 以为必然被拒绝 |
| 机房 IP | 网络类型 | 属于云厂商或数据中心的网络 | 可以 | 以为机房 IP 一定不能用 |
| 住宅 IP | 网络类型 | 属于家庭宽带运营商的网络 | 部分可以 | 以为住宅 IP 一定不会被限制 |

两个维度互相独立，可以组合出四种情形：原生的机房 IP、非原生的机房 IP、原生的住宅 IP、非原生的住宅 IP。机场卖的节点，绝大多数跑在机房里，因此多数是机房 IP，其中有的原生，有的不原生。

住宅 IP 型的服务另有说法。它们的 IP 来自家庭宽带网络，来源和授权情况各异，价格通常高于机房 IP，使用前最好了解清楚来源。这类产品和普通机场节点是两种不同的东西，价格逻辑也不同。

所以，当有人说“我们的节点是原生 IP 加住宅 IP”时，这句话包含了两个独立的承诺，每一个都应当单独追问。

## IP 纯净度是什么：共用程度和风控记录

“纯净度”不是一个标准术语，也没有统一的计量方式。它通常在说三件事：

- **共用程度**：这个 IP 同时有多少人在用。一个出口被很多账号共用，平台看到的是同一个地址上出现大量不同账号的活动。
- **名单记录**：这个地址是否出现在已知的代理、垃圾邮件或滥用名单里，这些名单由各种第三方维护。
- **平台自己的记录**：某个平台是否曾经把这个地址标记为异常，这一项只有平台自己知道。

独享 IP 和共享 IP 的区别也在这里。独享意味着只有你一个人用，共用程度最低，但价格更高，而且即便独享，地址本身的历史也不由你控制。

检测站给出的 IP 纯净度评分要谨慎对待。各家的算法和数据来源不同，同一个 IP 在两个页面上的分数可以相差很大。它能提示你一个方向，不能作为“能不能用”的依据。

## 为什么这些属性会影响流媒体和 AI 服务

平台判断一个访问是否可疑，一般会综合多种信息。下面是一般性的归类，各平台的具体规则不公开，也会变化。

| 服务类型 | 通常在意什么 | IP 属性可能起的作用 | 其他同样重要的因素 |
| --- | --- | --- | --- |
| 流媒体 | 内容授权地区、是否使用代理 | 网络类型与地理信息影响平台如何判断 | 同 IP 并发账号数、DNS 地区是否一致，见[流媒体解锁](/zhinan/liumeiti-jiesuo/) |
| AI 服务 | 所在地区是否在支持范围内、账号行为 | 地理信息决定地区判定 | 服务方官方的支持地区，见[ChatGPT 场景](/changjing/chatgpt/) |
| 搜索与邮箱 | 登录环境是否异常 | 被滥用的地址更容易触发验证 | 见[谷歌一直要验证码](/paicha/google-yanzhengma/) |
| 跨境电商后台 | 登录环境是否稳定、账号是否关联 | 登录地址频繁变化可能引起注意 | 见[跨境电商](/changjing/kuajing-dianshang/) |

有两点要说明。

第一，这些属性影响的是平台怎么看待你的出口，不影响连接速度。一个原生的家庭宽带 IP 不会让你的下载变快，也不会让节点更稳定。

第二，没有任何一种 IP 属性是通行证。平台的判断是综合的，满足了地理一致，仍可能因为共用程度过高或行为异常被限制；而不满足的 IP 也可能因为规则宽松，长期可用。选梯子不提供也不教授规避平台风控的做法。涉及“能不能用”，请遵守所在地法律法规，选梯子不提供法律意见。

Netflix 帮助中心就有专门一页说明，设备或网络被识别为 VPN 或代理时会出现提示，官方建议关闭后重试，见[官方说明](https://help.netflix.com/en/node/277)。这类提示说明：平台是否接受你的访问，不只看 IP 的“出身”，还看它的使用方式。

## 你能自己查什么，查不了什么

核对分五步，每一步都用普通工具就能完成。

1. **连上节点，查出口 IP。** 打开任意一个能显示当前出口 IP 的页面，记录地址。[Cloudflare 的连接信息检查页](https://one.one.one.one/help/)也可以用来看一部分连接信息，页面显示哪些字段以其当时为准。
2. **查登记信息。** 用 IP 登记信息查询工具，或在命令行输入 whois 加上这个地址。

```
whois 出口IP
```

3. **看几个关键字段。** 登记国家、持有机构名称、网络名称、所属自治系统编号。字段名因注册机构而异，意思相近。
4. **判断网络类型。** 机构是云服务或数据中心厂商，通常是机房 IP；是家庭宽带运营商，通常是住宅类网络。
5. **多个数据源交叉对比。** 再用两三个 IP 地理库查询页看显示的国家。如果与登记国家一致，原生的可能性较大；有分歧，说明这个地址的地理信息有争议。

各项结果与能得出的判断：

| 你查到的结果 | 能得出的判断 | 不能得出的判断 |
| --- | --- | --- |
| 登记国家与节点地区一致 | 登记地与使用地大概率一致 | 它不会被任何平台限制 |
| 持有机构是云或数据中心厂商 | 多半是机房 IP | 它一定不能用于某项服务 |
| 多次连接出口地址固定 | 可能是独享，或出口较少 | 没有其他人在使用 |
| 多个查询页国家不一致 | 地理信息有争议 | 哪个才是对的 |

**查不了的事**同样要知道：这个 IP 现在有多少人在用；平台内部的风控名单；服务商所说的“原生”“独享”是否对每一个节点都属实；这个地址未来会不会被标记。所以，宣传口径只能核对一部分，剩下的靠长期使用和服务商的透明度来判断。

## 机场说的“原生 IP”，应该怎么读

遇到宣传词，不要直接接受，也不必直接拒绝，而是把它翻译成可以追问的问题。

| 宣传词 | 更合理的理解 | 可以追问 |
| --- | --- | --- |
| “原生 IP” | 登记地与使用地一致，多为宣传口径 | 哪些节点是原生，登记在哪个机构 |
| “住宅 IP”“家宽 IP” | 出口属于家庭宽带类网络 | IP 的来源是什么，价格逻辑是什么 |
| “独享 IP” | 只有你使用 | 是固定分配还是每次随机，到期后怎么处理 |
| “纯净 IP” | 共用少、没有进入常见名单 | 纯净的依据是什么，由谁检测 |
| “全解锁” | 多个平台都能用 | 是否有可核对的记录，更新频率如何 |

一家愿意把这些问题讲具体的服务商，信息透明度通常更高；只会重复“都是原生，都是纯净”的，几乎没有提供可核对的内容。

合理的预期是：原生 IP 能降低“地理信息不匹配”这一类风险，但它不是通行证，也不会让速度变快。

## 现在可以做的三步

1. **先明确需求。** 你要用的服务是什么，对地区和 IP 类型有什么要求？先看服务方的官方说明，再决定要不要为 IP 属性多付钱。流媒体见[流媒体解锁](/zhinan/liumeiti-jiesuo/)，节点地区见[节点地区](/zhinan/jiedian-diqu/)。
2. **买之前问清楚。** 把上面表里的追问发给客服，保存回答。
3. **买之后自己查。** 用上一节的五步核对出口 IP，并在实际使用中观察，必要时对照[机场怎么选](/zhinan/jichang-zenme-xuan/)里的参数检查是否有遗漏。想直接看有哪些套餐公开了线路与节点资料，可以到[梯子推荐](/tuijian/)查看。
