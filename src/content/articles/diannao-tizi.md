faqs:
  - q: 电脑上用系统代理还是 TUN？
    a: 日常浏览网页、用读取系统代理的软件，系统代理通常够用，设置简单、冲突少。终端命令行、部分游戏和不读取系统代理的软件，就需要 TUN 或在软件里手动设置代理。TUN 需要更高的权限，也更容易与其他网络软件冲突，建议先用系统代理，不够再开。
  - q: Windows 和 Mac 用同一个客户端可以吗？
    a: 可以，多款客户端同时支持两个系统，例如基于 Mihomo 内核的几款图形客户端，以及 v2rayN、sing-box、Hiddify 等。同一份订阅可以导入多台设备，但机场通常有设备数限制，在电脑和手机上同时使用前，先确认套餐允许几台设备在线。
  - q: 开了梯子，为什么终端里的 git 或 npm 还是很慢？
    a: 系统代理主要影响会读取系统设置的程序，终端里的命令行工具大多不读，需要单独设置环境变量或工具自己的代理选项，或者开启 TUN 接管。具体做法见终端代理设置一文，设置之后用一条请求命令确认是否真的走了代理。
  - q: 电脑可以把梯子共享给手机或电视吗？
    a: 可以，但要在客户端里开启允许局域网连接，并放行防火墙，再在对方设备上手动填写电脑的局域网地址和代理端口。只在可信的家庭网络里这样做，不要在公共网络开启。如果机场有设备数限制，也可以在手机上直接装客户端使用同一份订阅。
  - q: 关闭客户端后上不了网怎么办？
    a: 多数是客户端异常退出，没有清除系统代理设置，浏览器仍然指向一个已经不存在的本地代理。到系统的代理设置里关闭手动代理即可恢复。如果问题反复出现，检查客户端是否有退出时自动清除代理的选项，必要时参考相应的排查文章。

电脑梯子要做两个决定，而且顺序固定：先选客户端，再选代理方式。客户端决定你的订阅能不能读、软件在不在维护；代理方式决定哪些程序的流量会走梯子。多数人只在第一步花时间，结果装好之后发现浏览器能用、终端不能用，问题通常出在第二步。

## 电脑梯子要决定的两件事

| 决定项 | 选项 | 它影响什么 | 先看哪里 |
| --- | --- | --- | --- |
| 客户端 | Clash 系（基于 Mihomo）、V2Ray 与 Xray 系、sing-box 系 | 能读哪种订阅、支持哪些协议、界面是否顺手 | 机场的订阅格式、你的系统 |
| 代理方式 | 系统代理、TUN | 哪些程序的流量会走梯子 | 你要用的软件类型 |

“电脑翻墙”听起来是一个动作，实际是这两个决定的组合。

选客户端时，机场给出的订阅格式是第一个约束；选代理方式时，你要用的软件类型是第一个约束。两个约束互不相关，所以可以分开决定，互不干扰。

下面先讲客户端，再讲代理方式，最后讲不同软件各自的情况。

## 电脑梯子推荐怎么看：Windows 和 Mac 的客户端

先说明：“PC 梯子”这个说法，字面上指个人电脑，搜索时多半指 Windows 电脑。Mac 虽然不叫 PC，但两个系统上能用的客户端大部分重合，所以放在一起讲。下表是本站收录、支持桌面系统的客户端。

| 客户端 | Windows | Mac | 类型与内核 | 适合谁 |
| --- | --- | --- | --- | --- |
| Clash Verge Rev | 支持 | 支持 | Clash 系图形客户端，Mihomo 内核 | 订阅是 Clash 格式的用户 |
| Clash Party | 支持 | 支持 | Clash 系图形客户端，Mihomo 内核 | 想要覆写等进阶设置的用户 |
| Clash Nyanpasu | 支持 | 支持 | Clash 系图形客户端，Mihomo 内核 | 同上，可作为备选 |
| ClashX Meta | 不支持 | 支持 | Clash 系菜单栏客户端 | 只用 Mac、喜欢菜单栏操作的用户 |
| FlClash | 支持 | 支持 | Clash 系图形客户端，Mihomo 内核 | 电脑和手机想用同一款的用户 |
| v2rayN | 支持 | 支持 | V2Ray 与 Xray 系，可切换内核 | 订阅是通用格式的用户 |
| sing-box | 支持 | 支持 | 通用内核与官方客户端 | 愿意读配置文件的用户 |
| Hiddify | 支持 | 支持 | 多平台图形客户端 | 想少折腾、导入订阅即用的用户 |
| Karing | 支持 | 支持 | 多平台图形客户端 | 同上 |
| Stash | 不支持 | 支持 | 付费客户端，兼容 Clash 配置 | 愿意为 Mac 端付费的用户，价格以 App Store 页面为准 |

表里是一般情况，具体以客户端当前版本为准。各系统的完整对照与官方地址，在[Windows 梯子下载](/xiazai/windows/)和[Mac 梯子下载](/xiazai/mac/)两页。

挑客户端可以按三步走：

1. **看订阅格式。** 机场给 Clash 格式的，选 Mihomo 内核的客户端更省事；给通用格式的，v2rayN、sing-box 系更对口。
2. **看维护状态。** 仓库长期不更新的客户端，会逐渐跟不上协议和系统的变化，只用官方仓库里仍在更新的。
3. **看操作习惯。** 喜欢图形界面还是命令行，是否需要覆写配置，这决定你用哪款更舒服。

拿不准时，用[客户端选择器](/gongju/kehuduan-xuanze/)查。至于 Clash 这个名字的来龙去脉，见[Clash 是什么](/zhinan/clash-shi-shenme/)。

### 两个系统各自的小事

**Windows。** 开启 TUN 通常需要管理员权限，并依赖虚拟网卡驱动。安全软件有时会拦截或误报，处理方式是只从官方仓库下载，再按提示放行，而不是去找来路不明的“绿色版”，风险见[破解版客户端](/bikeng/pojie-kehuduan/)。

**Mac。** 首次打开从官方仓库下载的软件，系统可能要求你在安全设置里允许；有些客户端需要输入系统密码来安装辅助工具。下载安装包时，要对照你的芯片类型选择对应版本。

## 系统代理还是 TUN：电脑上最重要的选择

这两种方式拦截流量的位置不同，因此覆盖的程序不同。

| 对比项 | 系统代理 | TUN 模式 |
| --- | --- | --- |
| 工作原理 | 在系统里写入代理地址，程序自己读取后主动走代理 | 创建虚拟网卡，系统层面接管流量 |
| 覆盖范围 | 浏览器和读取系统设置的软件 | 绝大多数程序，包括不读系统代理的命令行和部分游戏 |
| 需要的权限 | 一般不需要管理员权限 | 通常需要管理员权限或系统授权 |
| 与其他软件冲突 | 较少 | 可能与其他虚拟网卡、网络工具冲突 |
| 排查难度 | 较低 | 较高 |
| 适合 | 日常浏览、办公 | 终端、游戏、需要全局接管的场景 |

两种方式不是互斥的，可以先用系统代理，覆盖不到的再叠加 TUN。展开说明在[系统代理](/jiaocheng/xitong-daili/)和[TUN 模式](/jiaocheng/tun-moshi/)，词典条目是[系统代理](/cidian/xitong-daili/)和[TUN 模式](/cidian/tun/)。

系统代理这一机制本身，在 Mozilla 的文档里有通用说明，见[HTTP 代理与隧道](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Proxy_servers_and_tunneling)。需要注意：程序读不读系统代理，由程序自己决定。

## 电脑上的五种场景，各该怎么设

| 场景 | 系统代理够吗 | 是否需要 TUN | 要点 |
| --- | --- | --- | --- |
| 浏览器 | 通常够 | 一般不需要 | 个别浏览器有独立代理设置，要确认是否跟随系统 |
| 终端与开发工具 | 不够 | 可选 | 设置环境变量，或开启 TUN |
| 游戏 | 通常不够 | 可能需要 | 联机游戏对延迟敏感，代理不一定适合 |
| 办公与聊天软件 | 视软件而定 | 软件不读系统代理时才需要 | 先用系统代理试，不行再开 TUN |
| 共享给手机、电视 | 需要额外设置 | 不适用 | 允许局域网连接，对方手动设置代理 |

### 浏览器

Chrome 和 Edge 这类浏览器通常跟随系统代理，Firefox 有独立的网络设置，可以选择跟随系统，具体以浏览器当前设置为准。

### 终端与开发工具

命令行工具大多不读系统代理，需要自己设置。常用的做法是给当前终端设置环境变量，端口以你的客户端设置页显示为准。macOS 和 Linux 的终端这样写：

```
export https_proxy=http://127.0.0.1:端口
export http_proxy=http://127.0.0.1:端口
```

Windows 的 PowerShell 这样写：

```
$env:https_proxy = "http://127.0.0.1:端口"
```

git、npm、Docker 各有自己的代理选项，逐项说明见[终端怎么走代理](/jiaocheng/zhongduan-daili/)。开发者的 AI 编程工具有时需要单独处理，见[AI 编程工具](/changjing/ai-biancheng/)。

### 游戏

很多人以为梯子能当游戏加速器，其实两者的设计目标不同。梯子关心的是“能不能到达”，加速器关心的是“到达的延迟与抖动”。区别见[梯子和加速器](/zhinan/tizi-he-jiasuqi/)。游戏用到的流量常常是 UDP，需要 TUN 接管，并且节点要支持 UDP 转发，是否适合，要自己试。

### 共享给手机、电视和游戏机

电脑上的梯子可以通过局域网共享给其他设备：在客户端开启允许局域网连接，系统防火墙放行对应端口，再在对方设备上填电脑的局域网地址和端口。操作细节见[局域网共享代理](/jiaocheng/juyuwang-gongxiang/)，电视的几种方案见[电视怎么用梯子](/jiaocheng/dianshi-tizi/)。只在可信的家庭网络里这样做，公共网络不要开启。

## 装好之后，怎么确认电脑翻墙真的生效

按顺序做，每一步缩小一类问题。

1. **看客户端状态。** 节点已选中，连接显示为开启。
2. **查浏览器的出口。** 打开一个能显示出口 IP 的页面，确认地区是你所选节点的地区。
3. **查系统代理有没有被写入。** Windows 在系统设置的代理页面看，或在命令行用 netsh 的 winhttp 子命令查看另一层设置，说明见[Windows 代理设置文档](https://learn.microsoft.com/en-us/windows/win32/winhttp/netsh-exe-commands)；Mac 可以在网络设置的代理选项里看，或在终端用 scutil 查看。
4. **用终端测一次。** 设置好环境变量后，对一个境外网址发一次请求，看是否有响应。

```
curl -x http://127.0.0.1:端口 -I 某个境外网址
```

5. **退出客户端，再看系统代理是否被清除。** 没清除就会出现关闭后上不了网，见[关掉梯子后上不了网](/paicha/guan-tizi-meiwang/)。

需要提醒：Windows 有两处互相独立的代理设置，一处是系统设置页里的代理，一处是 winhttp 层面的设置，部分后台服务读取的是后者。两处不一致时，浏览器正常而某些程序不通，并不奇怪。

常见症状与去处：

| 症状 | 可能原因 | 去哪里看 |
| --- | --- | --- |
| 浏览器可以，某个软件不行 | 软件不读系统代理 | [某个 App 不走代理](/paicha/app-buzou-daili/) |
| 开了梯子国内网站变慢 | 分流没生效 | [国内网站变慢](/paicha/guonei-wangzhan-man/) |
| TUN 开不了 | 权限、驱动或冲突 | [TUN 模式开不了](/paicha/tun-moshi-shibai/) |
| 提示端口被占用 | 另一个程序在用同一端口 | [端口被占用](/paicha/duankou-zhanyong/) |

## 选电脑梯子推荐时，机场套餐该核对什么

客户端装好，还需要一份合适的订阅。电脑端使用与手机不同，建议多留意：

- **设备数。** 电脑加手机加平板，同时在线的数量要算进去，见[梯子能几台设备同时用](/zhinan/duo-shebei/)。
- **订阅格式。** 与你选定的客户端内核是否匹配。
- **流量。** 电脑上看视频、更新软件、下载文件，消耗通常比手机大，估算见[梯子流量多少够用](/zhinan/tizi-liuliang/)。
- **下载类用途。** 如果你需要 BT 或大文件下载，先看服务条款的限制，见[梯子能 BT 下载吗](/changjing/bt-xiazai/)。
- **协议。** 节点用的协议你的客户端内核要认得，见[机场协议](/zhinan/jichang-xieyi/)。

## 现在可以做的三步

1. **选客户端。** 在[Windows 梯子下载](/xiazai/windows/)或[Mac 梯子下载](/xiazai/mac/)里按订阅格式选一款，只从官方地址下载。
2. **选机场。** 到[梯子推荐](/tuijian/)缩小范围，第一次购买选最短周期。
3. **先系统代理，再按需 TUN。** 先让浏览器跑通，用上一节的五步验证，再决定是否需要接管终端或游戏的流量。

先让一种方式稳定可用，再去覆盖更多场景，比一开始就开启所有功能更容易找到问题所在。
