## 落地就是“最后一跳”

一次代理访问，可能经过一台或几台服务器，但真正和目标网站打交道的只有最后一台，这台就是落地节点。无论链路前面是[直连](/cidian/zhilian/)还是[中转](/cidian/zhongzhuan/)，目标网站看到的来访者，都是落地节点的 IP，而不是你自己的家庭网络，也不是中转服务器。

这也是为什么，换节点常常等于换了一个“在哪里上网”的身份。

## 它决定了哪些事

| 事项 | 与落地节点的关系 |
| --- | --- |
| 你被识别成哪个地区 | 由落地节点 IP 的归属地决定 |
| 部分服务能否使用 | 受 IP 所在地区是否受支持影响，具体以各服务官方说明为准 |
| IP 是否被网站限制 | 与该 IP 的历史使用情况和类型有关，见[原生 IP](/cidian/yuansheng-ip/) |
| 视频等内容库 | 地区库按 IP 归属匹配，见[解锁](/cidian/jiesuo/) |
| 延迟的主要组成 | 从落地节点到目标网站的那一段也计入总[延迟](/cidian/yanchi/) |

## 在套餐页和客户端的哪里会看到

套餐页会写“覆盖某些地区”，这里的地区通常说的就是落地所在地。客户端节点列表里，名称中的地区标识多半也是落地地区；如果是中转线路，名称里可能同时带入口和出口，出口那一端才是落地。

## 常见误解

1. 节点名称里的地区就是 IP 的真实归属地。名称是服务商写的，IP 归属数据库也可能有误差，两者不一定一致。
2. 同一个地区的落地节点表现都一样。同地区不同机房、不同 IP 段，面对同一个网站的结果可能不同。
3. 落地节点越多越好。更值得关心的是你用到的那几个落地节点的质量，而不是总数。

## 怎么确认你的落地 IP

连上节点后，用任意一个 IP 归属查询页面，看它显示的地区、运营商和 IP 类型。不同查询站的数据库不同，结果可能略有出入，可以多查一两个对照。如果要进一步理解机房 IP、住宅 IP 与原生 IP 的区别，读[原生 IP 是什么](/zhinan/yuansheng-ip/)；线路结构的整体背景见[中转机场是什么](/zhinan/zhongzhuan-jichang/)。
