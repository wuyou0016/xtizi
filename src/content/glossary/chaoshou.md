## 一个容易理解的类比

想象一座自助餐厅，按座位数卖出的号牌多于座位数。多数时候客人不会同时到场，餐厅运转得很好；碰上人最多的那个时段，大家就得排队。机场的超售大致类似：服务器和带宽是有限的，套餐却卖给了更多的用户，赌的是他们不会同时把资源用满。

所以超售本身不是一个“有或没有”的问题，而是一个程度问题。

## 为什么它很难避免，又为什么要警惕

共享型服务普遍会有一定程度的资源复用，完全不超售意味着成本大幅上升。真正的风险在于过度：卖出的量远远超过资源，平时看不出问题，到了[晚高峰](/cidian/wan-gaofeng/)就集中爆发。

常见的后果有这几种：

| 表现 | 可能的原因 |
| --- | --- |
| 白天正常、晚上明显卡 | 高峰期资源争抢 |
| 标榜“不限速”但实际变慢 | 宣传话术与实际资源不匹配 |
| 节点时好时坏 | 容量吃紧，运营者在调配 |
| 突发限速或临时调整规则 | 用于控制资源占用 |

“不限速”三个字应如何拆解，见[机场超售和限速是怎么回事](/bikeng/chaoshou-xiansu/)。

## 在哪里会看到

套餐页上没有“超售率”这一项，因为它属于服务商内部信息。你更常在这几个地方碰到相关线索：关于公平使用的条款、带宽或速度限制的说明、对高峰期的提示，以及用户社区里对不同时段体验的讨论。

## 怎么间接判断

1. 看价格与承诺是否匹配。资源不是凭空来的，低价配上“不限速、不限量”之类的宣传，就要多问一句成本从哪来，思路见[一元机场靠谱吗](/bikeng/dijia-jichang/)。
2. 看线路类型。[中转](/cidian/zhongzhuan/)和专线本身成本较高，如果标榜这类线路却价格很低，也值得留意。
3. 用短周期先试，并在白天、晚上各测几次，而不是只在购买当天测。
4. 看有没有明确的公平使用条款，说明得越清楚，通常越容易事后核对。

## 常见误解

- “套餐页写的带宽数字就是你能用到的”。那是上限描述，不是保障。
- “超售一定是骗局”。适度的资源复用是行业里常见的做法，关键在程度和是否如实说明。
- “换客户端或协议能解决超售”。那改变不了服务器侧的容量。

觉得服务越来越不如意时，别急着归因，先对照[梯子晚上卡是为什么](/paicha/wan-gaofeng-ka/)判断是不是拥堵，再决定是否换家。
