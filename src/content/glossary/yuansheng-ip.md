## “原生”到底指什么

互联网上的 IP 地址由区域机构分配给运营商，运营商再分配给用户，这套分配体系的总览可见 [IANA：IP 地址分配](https://www.iana.org/numbers)。每个 IP 段在登记时会带有一个归属地区。原生 IP，通常指的是这个归属地区与它实际被使用的地区一致，比如登记在某地的地址段，就由当地的服务器或宽带使用。

反过来，如果一段地址登记在甲地，却被宣告出去，拿到乙地的机房里使用，就常被称作“广播 IP”或“非原生 IP”。

## 它和 IP 类型是两个维度

很多文章把原生 IP、机房 IP、住宅 IP 混在一起。更清楚的做法是分两个维度：

| 维度 | 回答的问题 | 常见分类 |
| --- | --- | --- |
| 归属一致性 | 登记地和使用地是否一致 | 原生、非原生 |
| 网络类型 | 这个地址属于什么性质的网络 | 机房、住宅、移动等 |

一个 IP 可以是原生的机房 IP，也可以是非原生的机房 IP，两个维度互不替代。三者的详细区分见[原生 IP 是什么](/zhinan/yuansheng-ip/)。

## 在哪里会看到

- 机场套餐页或节点介绍里的“原生 IP”标注。
- 流媒体、AI 服务相关的选购讨论里，常被拿来解释为什么某个节点能或不能使用某项服务。
- IP 归属查询页面的结果里，会显示地区与网络类型。

这些标注基本是服务商或个人的自述，客户端不会替你核实。

## 常见误解

1. “原生 IP 就一定能[解锁](/cidian/jiesuo/)”。平台是否放行，受许多因素影响，包括该 IP 的历史使用情况，原生只是其中一个条件。
2. “原生 IP 就是住宅 IP”。两者是不同维度，原生 IP 完全可以属于机房。
3. “IP 查询显示的地区就是真相”。各查询站的数据库有差异，更新也不同步，出入是常见的。

## 怎么自己核对

连接节点后，用两三个不同的 IP 归属查询页面，看它们显示的国家、运营商和类型是否基本一致；再到你实际要使用的服务里试一次，观察表现。若要进一步理解服务为何时灵时不灵，读[流媒体解锁是什么意思](/zhinan/liumeiti-jiesuo/)；节点背后的出口位置，对应[落地节点](/cidian/luodi/)。
