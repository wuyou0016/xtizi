## 它并不是破解

“解锁”这个词容易让人想到破解什么，其实不是。平台判断你能看什么内容、能不能用某个服务，常常参考你的网络出口地区。你通过节点上网，平台看到的就是[落地节点](/cidian/luodi/)的 IP；这个 IP 被认定在某个地区，平台就按那个地区的规则提供服务。所谓“解锁”，是指某个节点的出口 IP 恰好被平台归入你想要的地区，并且没有被限制。

因此，解锁的结果，决定权在平台，而不在机场或客户端。

## 为什么同一个节点时灵时不灵

| 原因 | 说明 |
| --- | --- |
| IP 被平台重新评估 | 平台会更新对各 IP 段的判断 |
| 同一 IP 被很多人使用 | 使用的人多，容易被平台限制 |
| IP 类型 | 机房 IP 与其他类型的 IP 被对待的方式可能不同，见[原生 IP](/cidian/yuansheng-ip/) |
| 地区内容库差异 | 不同地区的内容库本来就不同 |
| 账号或设备因素 | 不只看 IP |

这些因素可以任意组合，所以“昨天可以、今天不行”是常态，不一定是你的操作有误。更完整的机制说明见[流媒体解锁是什么意思](/zhinan/liumeiti-jiesuo/)。

## 官方怎么说

以 Netflix 为例，其帮助中心写明：设备或网络被识别为 VPN 或代理时，会提示“You seem to be using a VPN or proxy”，官方建议关闭后重试，详见 [Netflix 帮助中心：You seem to be using a VPN or proxy](https://help.netflix.com/en/node/277)。这意味着，节点即使能打开平台，也可能在播放时被识别并拦下。各平台的态度和政策以其官方页面为准，具体到 Netflix 的情况见[奈飞梯子怎么选](/changjing/netflix/)。

请遵守所在地法律法规，选梯子不提供法律意见。

## 机场说的“支持解锁”怎么读

- 它通常只代表某个时间点、某些节点上的测试结果，不构成长期承诺。
- 节点介绍里的“支持”，没有统一的判定标准，各家口径不一。
- 选梯子目前没有自己的解锁测试数据，所以这里只能教你方法，不能替你判断某个节点的结果。

## 怎么自己验证

先用试用或短周期套餐，在你要使用的服务里实际登录、播放，并在不同时段重复几次；换同地区的另一个节点再对照一次；记录下哪个节点、什么时间、出现什么提示。需要通过[分流](/cidian/fenliu/)规则让特定服务固定走某个节点时，再去设置，而不是全局切换。这样得到的结论，才是和你的账号、你的网络真正相关的结论。
